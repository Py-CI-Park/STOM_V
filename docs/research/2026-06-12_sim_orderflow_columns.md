# 시뮬레이션 호가·오더플로우 컬럼 전수 조사 (2026-06-12)

> 출처: `_database/stock_tick_YYYYMMDD.db` / `stock_min_YYYYMMDD.db` PRAGMA + 실 데이터 샘플(`stock_tick_20260227.db`, `stock_min_20260227.db`).
> 목적: PLAN_PHASE5 §1 트랙 S ③ 호가·오더플로우 시각화의 데이터 근거. 가용 컬럼만으로 라이브 호가 압력 바 + 오더플로우 테이프를 설계한다.
> 계약: 시세 DB 는 `file:...?mode=ro` 로만 읽는다. 컬럼 부재 DB(구버전)에도 raise 없이 None 으로 흘려보낸다(하위호환).

## 1. 실측 컬럼 레이아웃

## 2. 누적/델타 검증 (min 0009K0 첫 6행)

```
idx           price  당일거래대금(cum)  분매수   분매도   분당거래대금  매수총잔  매도총잔  매수호1  매도호1
202602270900  55500  2203              8397    14853   2203        7625     8912     55300   55600
202602270901  55900  4505              23347   17675   2302        6235     11197    55900   56300
202602270902  57000  7302              28854   20308   2797        3736     9949     56500   57000
```

- `당일거래대금` 은 **누적**(2203 → 4505 → 7302) 이며 `분당거래대금` 의 running sum 과 일치(2203, +2302, +2797). → **VWAP = 당일거래대금 / 누적거래량** 으로 증분 산출 가능(누적거래량 = running sum(분당매수수량+분당매도수량)).
- `매수총잔량`/`매도총잔량` 은 스냅샷(누적 아님) → 호가 압력 비율 = 매수총잔 / (매수총잔+매도총잔).
- `초/분당매수수량 − 초/분당매도수량` = bar 순매수수량(오더플로우 델타).

## 3. 채택 설계 (가용 컬럼만)

프레임 스키마에 **하위호환** 확장(부재 시 None):

- `net_qty` = (초|분)당매수수량 − (초|분)당매도수량 — 오더플로우 테이프(순매수 색 스트립/델타 바).
- `bid1` = 매수호가1, `ask1` = 매도호가1 — 라이브 호가 압력 바의 현재가·호가1 표시.
- `vwap` = 당일거래대금(누적) / 누적거래량 — 서버 증분 계산(보조지표 라인 오버레이).
- `bb_mid`/`bb_up`/`bb_low` = 볼린저(20,2) 종가 기준 — 서버 증분 계산.
- 기존 `imbalance`(매수총잔/매도총잔), `buy_rest`/`sell_rest` 는 유지 — 호가 압력 바(매수vs매도 잔량 비율)에 재사용.

라이브 호가 압력 바: `매수총잔량` vs `매도총잔량` 비율을 좌우 분할 막대로(매수 teal / 매도 red), 중앙에 현재가·bid1·ask1 라벨.
오더플로우 테이프: 최근 N bar 의 `net_qty` 를 색 스트립(순매수>0 teal 농도 / 순매도<0 red 농도) + 델타 막대.

## 4. 무예외 계약

- 컬럼 부재(구버전 DB): `매도호가1`/`매수호가1`/금액 컬럼이 없으면 해당 파생값 None, 패널 자동 숨김(SimRestFlow 패턴 동일).
- VWAP: 누적거래량 0 이면 None(분모 보호).
- 볼린저: 윈도우(20) 미충족 구간 None(MA 와 동일 정책).
