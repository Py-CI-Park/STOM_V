## 1. 발견 방식

기존 G 레인 label mining을 반복하지 않는다. 세 개의 독립적인 경제 가설 가족을 선언하고 QMC로 저차원 문턱을 피복한다.

| 가족 | 가설 | 후보 수 |
|---|---|---:|
| `FLOW_SURGE` | 체결강도·초당거래대금 surge·매수압력 | 5 |
| `BOOK_IMBALANCE` | 호가잔량 불균형·체결강도 | 4 |
| `MOMENTUM_QUALITY` | 등락률 band·당일 위치·회전율 | 3 |

seed `20260814`, 총 budget 12다. 모든 후보는 runtime symbol·허용 함수·lookback·절·estimated work 계약을 통과했으며 source hash를 봉인했다.

## 3. 1차 판정

| 판정 | 조건 |
|---|---|
| 실행 실패 | terminal success/no_trades가 아니거나 metrics 없음 |
| 경제 실패 | `total_profit_pct <= 0` 또는 `avg_profit_pct <= 0` |
| 표본 부족 | 거래 10건 미만 |
| 위험 실패 | MDD 10% 초과 |
| 2차 진입 | 위 네 실패가 모두 아님 |

2차 진입 후보가 없으면 D1은 `NO_ECONOMIC_CANDIDATE`로 종료한다. 임계값을 완화하거나 같은 fixture를 반복하지 않는다.

## 4. 2차 판정 권한

2차 진입 후보가 있을 때만 다음을 허용한다.

1. 후보 family당 최고 1개, 전체 최대 3개
2. 동일 fixture 3회 결정성 확인
3. 수익 최대·MDD 최소·거래 수의 Pareto archive
4. 이후 별도 개발 outer fold 사전등록

Bayesian `APPROVE`, MAP-Elites fitness, denoising 모델, 신규 전진 표본은 이 screen 결과만으로 실행하지 않는다.
