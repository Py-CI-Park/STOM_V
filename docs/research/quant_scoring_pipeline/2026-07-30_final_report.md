## 0. 한 줄 결론

**파이프라인은 '수렴하는 솔버'로 작동한다.** 넓은 그물 시드에서 출발해 [백테 → 라벨 분석
→ 리프 단위 수정 명세 → 의도-일치 게이트 → 재백테 → 판정]을 사람 개입 없이 반복했고,
모든 라운드에서 손실이 단조 감소했으며, 무효 축은 자동 제외됐다. 단 이 구간(2025-04~2026-02)의
넓은 그물은 여전히 총손익 음수 — 파이프라인의 다음 병목은 반복이 아니라 **시드 계열의 원엣지**다
(직전 연구 CLW30 의 결론과 정합). **⚠ 2026-07-30 독립 감사 정정: §2.1 필독** — 개선 수치
일부가 단위 오류 경로에서 나왔고, '단조 감소'는 구조적 보장이다(성과 주장 아님).

### 2.1 정정 — 2026-07-30 독립 감사 반영 (과대해석 방지)

본 보고서 발행 직후 수행된 독립 감사(축A 조건식 생성 56/100 · 축B 결과 분석 45/100)에서
아래가 확인되어 정정한다. 상세 근거와 교정 이력은 한계 원장(§4) 2026-07-30 행 참조.

1. **단위 불일치 임계값(치명)** — 제안기 매핑 5종이 단위가 다른 절에 분위수를 기입했다.
   대표 사례 minfull R3 C2: `거래대금비율 > 246`(원 단위 분위수를 배수 절에 기입 —
   사실상 리프 차단)이 라운드 베스트로 채택되어 **min 캠페인 개선 69.9M 중 ~27.9M(≈40%)이
   이 우발 경로에서 발생**했다. 손실 리프 차단이라 결과적으로 손실은 줄었지만, 의도된
   메커니즘(데이터 근거 조임)이 아니므로 방법론 실증 증거로 쓸 수 없다. → 오류 매핑 제거·
   단위 불변식·회귀 테스트로 교정 완료(QSP2 캠페인부터 적용).
2. **'전 라운드 단조 개선'은 구조적 보장** — base 가 항상 후보 풀에 포함되고 베스트는 최댓값
   선택이므로 라운드 간 퇴행은 발생할 수 없다. 이는 안전장치(퇴행 방지)의 확인이지 성과
   주장이 아니다. 같은 이유로 진동 발산 분기는 이 루프에서 도달 불가한 규격이다.
3. **복합/시너지 주장 철회** — 리프는 거래 공간을 분할하므로 서로 다른 리프의 수정 효과는
   정확히 가산적이다(실측: 동일 후보의 Δ가 base 갱신과 무관하게 +186,030 로 불변).
   R3 리뷰의 '복합 적용' 서술은 가산성의 동어반복으로 정정한다.
4. 개선 수치는 모두 **설계 구간 내**이며 홀드아웃 검증 전이라는 기존 한계(§0)는 유지된다.
   QSP2 캠페인은 홀드아웃 동반 판정을 러너에 내장해 이 한계를 해소한다.

## 5. QSP2 제언

1. **시드 원엣지 탐색이 1순위** — 반복기는 준비됐다. anchor 다밴드류(직전 연구의 실증 승자
   계열)를 QSP HIER 골격으로 이식해 캠페인을 돌리는 것이 최단 경로.
2. CSS 패턴형 제안기(파라미터 축) — HIER 전용 한계 해소.
3. 홀드아웃 동반 판정 — 수렴 선언에 표본외 개선 동반 요건(마스터플랜 §2)을 러너에 내장.
4. LLM 복귀 시 prompt v2 배선 + 생성 주체 A/B(에이전트 vs LLM 품질 비교).
5. 매도식 축 — 현재 제안기는 매수식만. 청산 파라미터 축(H5) 추가.
