## 4. 실제 연구는 했는가

| 질문 | 답 |
|---|---|
| 실제 조건식 연구를 했는가 | 예. `<3000` G0와 구조 G1을 공식 실행했다. |
| 연구 결과는 성공인가 | 절차는 성공, 경제 후보는 실패다. |
| 지금 새 후보를 찾고 있는가 | 아니다. 사전등록 STOP 이후 새 생성·재실행을 하지 않았다. |
| 최근 작업은 연구인가 | 기존 결과의 분석과 연구 플랫폼 성숙화다. 새 경제 탐색은 아니다. |
| OOS를 했는가 | 아니다. Robust 후보가 없어 Holdout을 열지 않았다. |

```text
새 전략 탐색 ........ 중지
기존 실패 분석 ...... 완료
연구 UX·신뢰성 ...... 진행/성숙화
새 RES-04 ........... 사전등록 전 미착수
```


장기 연구 도구로 계속 사용할 때 적합하다. 전략 수익성을 직접 높이지는 않는다.

```text

→ Controls → 후보 있을 때만 OOS
```

수익 전략 발견이 목표라면 필요하다. 기존 threshold 미세조정은 금지한다.
