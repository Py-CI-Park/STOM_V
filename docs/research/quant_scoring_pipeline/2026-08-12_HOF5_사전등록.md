## 1. 가설 (반대 가설 포함)

**가설**: W7 완화 2종(`902_회전율 제거`·`905_전일비 제거`)은 당시 자본 희소
정책(총수익률 게이트)으로 REJECT 됐으나, 현행 limit 정책(자본 2,000만 · 목표
총수익금)에서는 챔피언 초과 후보다. 전 구간 실측(+291,521 / +122,754원)이 근거다.

**반대 가설**: 그 이득은 전 구간 중 특정 시기에 쏠려 있어(HOF1 의 창 확장이
그랬듯) 학습 구간만 보면 사라지거나, 검증 구간에서 뒤집힌다. 완화로 늘어난
거래는 건당 기대값이 낮아(0.36%) 구간이 나빠지면 먼저 무너진다.

**1차 = 학습 구간(달력 411일).** 판정 대상은 총수익금(limit 정책 · 사용자 확정).

| # | 조건 | 필수 |
|---:|---|:---:|
| A | 학습 총수익금 > 기준선(같은 세션 실측) | ✅ |
| B | 후보 총수익금 > 0 (헌법 12항) | ✅ |
| C | 필요자금 ≤ 2,000만원 | ✅ |
| D | 거래 수 ≥ 기준선 (완화이므로 줄면 측정 이상) | ✅ 검증용 |
| E | 건당 ≥ 기준선 | 참고 (limit 정책 — 필수 아님) |
