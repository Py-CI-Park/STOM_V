## 5. 기록 관리 규칙 (모든 라운드 공통)

1. **라운드 로그** (`rounds/`): 실측 수치·결함·판정을 실시간 기록. 필수 항목 = 게이트 판정 / 결함(원인·교정) / 커밋 해시
2. **커밋**: 작은 단위 · 한국어 제목 · `type(QSP##-단계):` 접두 · 결함은 실측 근거 포함
3. **정정**: 오류 발견 시 원문 수정 금지 → 정정 문서 발행 + 원문 머리에 무효 표시 + 이 색인 갱신
4. **원장**: 한계·결함은 `limitation_ledger.md` 에 누적 (삭제 금지)
5. **권위 3종**: 관측(진단) / 자문 / 공식 — 수치 인용 시 항상 명시
6. 채택·기준선 변경·홀드아웃 개봉은 **사람 승인** 사항
