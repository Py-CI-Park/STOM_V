# 마스터 로드맵 — 좋은 조건식을 성공적으로 개발하기 위한 전체 계획 (2026-08-07)

> **목적**: 사람 개입 없이 **챔피언보다 확실히 나은 조건식**을 만들고, 그것을
> 통계적으로 증명해 실전에 올린다.

## 0. 🧭 현재 위치 (한 문단)

파이프라인은 완성됐다 — 챔피언 재현 → 후보 생성 → 엔진 실측 → 짝지은 통계 판정 →
원장 적재 → 화면 표시까지 사람 없이 돈다. 산출물은 아직 미확정이다:
AI 후보 3종이 국면 일관성(4/4 vs 챔피언 3/4)과 MDD(−29%)를 개선했지만
**자본 대비 수익률이 챔피언 미달(71.17% vs 80.17%)** 이고 **통계적으로도 확정되지
않았다**(95% CI가 0 포함, 표본 3.1배 부족). 판정은 셋 다 **MIXED**.

### 2.2 챔피언은 **이미 파라미터화되어 있다**

`strategy.db` 에 다음이 이미 존재한다.

| 행 | 내용 |
|---|---|
| `C_T_902_905_U2_BO` | 챔피언 매수식에 `self.vars[1..24]` 를 박아 넣은 버전 |
| `C_T_902_905_U2_SO` | 챔피언 매도식에 `self.vars[25..31]` |
| `C_T_902_905_U2_OR` | `self.vars[i] = [[min, max, step], 현재값]` — 탐색 범위 32개 |

```python
# 예시 (C_T_902_905_U2_OR)
self.vars[1]  = [[6.0, 10.0, 1.0], 10.0]   # 902 등락율 상한
self.vars[27] = [[4.0,  6.0, 0.5],  6.0]   # 매도 익절 문턱
self.vars[30] = [[0.5,  0.7, 0.05], 0.7]   # 트레일링 비례 계수
```

### 2.3 그런데 격자가 천문학적이다

| 축 | 조합 수 | 엔진 6분 기준 소요 |
|---|---:|---:|
| 매도축 `vars[25..31]` | **46,875** | **1년** |
| 매수축 `vars[1..24]` | 8,358,844,170,240 | 9,542만 년 |
| 전체 32개 | 391,820,820,480,000,000 | 4.5조 년 |

**전수는 불가능하고, Optuna 로 수천 회 샘플링해도 QSP13 의 편의 함정(0.6225%p)에
그대로 빠진다.** 후보 28→58 셀만 늘려도 편의가 1.9배가 된 것이 실측이다.

### 2.4 그래서 이렇게 쓴다 — **탐색이 아니라 국소 정련**

| 금지 | 허용 |
|---|---|
| 32개 변수 동시 최적화 | **한 번에 1~3개 변수만** |
| 수천 회 시행 후 최고값 채택 | 시행 수를 **가설 예산(15회/아이디어)** 안에 |
| 설계 구간 최고점 채택 | **롤링 워크포워드**로 표본 밖 확인 후 |
| 결과를 그대로 승격 | **짝지은 검정 + 자본 대비 + 원장 등재** 후 사람 게이트 |

**핵심 규율**: 최적화는 "더 좋은 값 찾기"가 아니라 **"지금 값이 고원 위에 있는지
확인하기"** 로 쓴다. 이웃 값에서도 성적이 유지되면 그 값은 안전하고, 절벽이면
과최적이다. `optimiz_3d_visualization` 의 응답면이 정확히 그 그림이다.

## 3. 📋 실행 계획 — 5단계

### 단계 1 · 표본 확보 (P1) — **최우선**

| 항목 | 내용 |
|---|---|
| 무엇 | 설계 구간 라벨 백필 478일 (DB 952일 중 라벨 355일) |
| 명령 | `python -m ai_strategy_loop.labeling.build_labels --lane tick --start <시작> --end 20250822 --out-name design_v4` |
| 기대 | 표본 155건 → **약 416건** (필요 475건에 근접) |
| 비용 | 약 70분 (멱등 — 이미 만든 날은 건너뜀) |
| 확인 | 페이지 29 결손 597 → 119(홀드아웃만) |
| 게이트 | 백필 후 **엔진 A/B 재실행** → 짝지은 CI 가 0을 넘는지 |

> **주의**: 홀드아웃 119일은 잠겨 있다. 백필 계획기가 자동으로 채우지 않는다.

### 단계 2 · 자본 회전 교정 (P2)

B3 의 문제는 "느리다"는 것이다. 조기 청산 규칙을 **하나씩** 얹어 A/B 한다.

| 후보 | 추가 규칙 | 가설 |
|---|---|---|
| B3+시간손절 | `elif 보유시간 > 180 and 수익률 < 0: 매도` | 물속에서 오래 안 있는다 |
| B3+추세이탈 | `elif 보유시간 > 60 and 현재가 < 최저현재가(60, 보유시간): 매도` | 챔피언 ③을 빌려온다 |
| B3+손절 | `elif 수익률 <= -3.0: 매도` | 단순 하한 |

| 판정 기준 | 값 |
|---|---|
| 필수 | **총수익률 ≥ 80.17%**(챔피언) — 이걸 못 넘으면 MIXED 그대로 |
| 필수 | 최대동시보유 ≤ 1 (자본 1배 유지) |
| 필수 | 국면 ≥ 3/4 |
| 확정 | 짝지은 95% CI 하한 > 0 |

### 단계 3 · 최적화로 **국소 정련** (P3)

**단계 1·2 가 끝난 뒤에만** 시작한다(표본 없이 최적화하면 편의만 키운다).

```
3-1. 매도축 7개 변수(vars[25..31])만 대상 — 46,875 조합
3-2. Optuna 로 전수가 아니라 **200 시행**만 (가설 예산 15회 x 후보군)
3-3. rolling_walk_forward_test 로 표본 밖 확인 (STOM 내장)
3-4. optimiz_3d_visualization 으로 **응답면 고원** 확인
       · 이웃 값에서도 성적 유지 → 채택 가능
       · 절벽 → 과최적, 폐기
3-5. 짝지은 검정 + 자본 대비 → 원장 등재
```

| 금지 | 이유 |
|---|---|
| 매수축 24개 동시 최적화 | 8.4조 조합 — 편의가 성능을 삼킨다 |
| 시행 수 무제한 | 시행이 많을수록 편의가 커진다(실측 ×1.90) |
| 응답면 확인 없이 채택 | 절벽 위의 최고점은 표본 밖에서 사라진다 |

### 단계 4 · 진입 빈도 연구 (P4)

하루 1.39건 → 3건이면 표본이 2배가 된다. **기대값을 유지하면서** 절을 완화한다.

| 방법 | 내용 |
|---|---|
| 절 단위 제거 A/B | 29개 절을 하나씩 빼고 건당·거래수 변화 측정 (이미 `drop_leaf` 자산 있음) |
| 시간창 확장 | 09:05 → 09:10 (별도 시간대 전략으로) |
| 문턱 완화 | `optimiz` 로 한 번에 1개 변수만 |

**게이트**: 거래수가 늘어도 **건당이 기준선 미만이면 폐기**. 빈도를 위해 기대값을
팔지 않는다.

### 단계 5 · 홀드아웃 · 실전 (P5)

| 순서 | 내용 | 게이트 |
|---:|---|---|
| 1 | 단계 1~4 를 통과한 후보만 | 원장 판정 **PASS** |
| 2 | 홀드아웃 119일 개봉 | **사람 결정 · 1회성** |
| 3 | 감독형 소액 실전 | **사람 승인** |

## 4. 🔄 일반화 프로세스 — 앞으로 모든 라운드가 따를 절차

```
① 무엇을 고정하고 무엇을 바꿀지 선언        (조건식 기술해설 서식)
      ↓
② 후보 격자를 실행 전에 고정               (사후 확장 금지)
      ↓
③ 진입 고정 A/B 로 엔진 실측               run_engine_measure
      ↓
④ 엔진 축 심판                              run_engine_ladder
      · 합격선 = 챔피언 (절대 기준 금지)
      · 짝지은 검정 (같은 진입 1:1)
      · 자본 대비 (총수익률·필요자금)
      ↓
⑤ 원장 적재                                 run_ledger_sync → 페이지 30
      ↓
⑥ PASS 만 사람 보고 · 그 외는 다음 라운드 재료
```

### 4.1 판정 네 갈래

| 판정 | 뜻 | 다음 행동 |
|---|---|---|
| **PASS** | 챔피언 이상 + 자본 대비 이상 + 통계 확정 | 사람 보고 → 홀드아웃 |
| **PROMISING** | 챔피언 이상이나 표본 부족 | 표본 늘려 재판정 |
| **MIXED** | 어떤 축은 낫고 자본 대비는 미달 | 원인 축 교정 후 재시도 |
| **REJECT** | 챔피언 미달 | 폐기 (원장에 남김) |

### 4.2 절대 규칙 (지금까지 실패에서 나온 것)

1. **합격선은 챔피언이다.** 절대 기준을 만들면 먼저 챔피언으로 교정한다.
2. **심판은 엔진 체결 기록이다.** 지도는 탐색용이다.
3. **자본을 밝힌다.** 총수익금만 보면 자본을 더 쓴 쪽이 항상 이긴다.
4. **유의하지 않으면 유의하지 않다고 쓴다.**
5. **격자는 실행 전 고정, 전셀 보고.**
6. **홀드아웃은 사람만 연다.**
7. **진입과 매도를 동시에 바꾸지 않는다.**
8. **원장은 append-only.** 폐기 후보도 남긴다.
