## 3. 🔧 구간 제거 생성기

### 3.1 형태 → 절 매핑

| 입력 | 생성 절 |
|---|---|
| `monotone_up` / `tail_low` (하단 열위) | `elif A <= ?: 매수 = False` |
| `monotone_down` / `tail_high` (상단 열위) | `elif A > ?: 매수 = False` |
| `valley` (중앙 열위) | `elif ? < A <= ?: 매수 = False` |
| `multi_band` | `elif (A <= ?) or (? < A <= ?): 매수 = False` |
| 2D 포켓 | `elif (A > ?) and (? < B <= ?): 매수 = False` |

임계는 **`loss_profile` 이 설계 구간에서 산출한 분위 경계**에서만 온다. 생성기는 값을
만들지 않는다(규율 3).

### 3.2 레인별 삽입 지점 — 추정하지 않고 두 모양을 명시적으로 다룬다

| 레인 | 기준선 모양 | 삽입 |
|---|---|---|
| min | 계층형 (`elif 시분초 < 120000:` 앵커 존재) | 앵커 **앞** — 계층 보존(R2 와 동일) |
| **tick** | **평탄 elif 체인 (앵커 없음)** | 최상위 elif 체인 **마지막 분기 뒤** |

### 3.3 실제 생성 결과 (tick 기준선 + 2절)

```python
매수 = True

if 관심종목 != 1:
    매수 = False
elif not (0 < 현재가 <= 50000):
    매수 = False
elif not (90000 <= 시분초 <= 92800):
    매수 = False
elif not (0 < 등락율 <= 25):
    매수 = False
elif not (당일거래대금 > 100):
    매수 = False
elif 라운드피겨위5호가이내:
    매수 = False
elif (등락율 > 15.68) and (회전율 > 2.03):  # ADD_REGION G-1
    매수 = False
elif (시분초 <= 90122) and (0.3 < 회전율 <= 2.03):  # ADD_REGION G-2
    매수 = False

if 매수:
    self.Buy()
```

Python 파싱 OK · intent gate pass(삽입 4줄 외 diff 0) · 런타임 변수 화이트리스트 통과.

## 5. 🐛 실데이터가 잡아낸 결함 3건

G-0a 와 같은 패턴이 반복됐다 — **합성 테스트만으로는 부족하다.**

| # | 결함 | 증상 | 수정 |
|---:|---|---|---|
| 1 | **tick 기준선에 앵커가 없다** | 삽입 지점을 min 레인의 `elif 시분초 < 120000:` 으로 하드코딩해 `anchor_not_found` 로 전량 실패. **우선 레인인 tick 에서 후보가 0건** | `insertion_point()` — 계층형/평탄 체인 두 모양을 명시적으로 처리 |
| 2 | 큰 정수 임계가 지수표기로 잘렸다 | `거래대금증감 > -1.09332e+10` — `%g` 가 유효숫자 6자리로 잘라 **실제 계산값과 다른 임계**를 코드에 심었다 | 정수는 정수 그대로 표기 |
| 3 | 순위가 큰 제거를 먼저 골랐다 | 1절이 거래 40%를 잘라 4후보 **전부 예산 초과**. 2D 포켓은 한 번도 후보에 못 들어감 | 손실 밀도 → **한계 개선 탐욕**으로 교체(§5.1) |

### 5.1 순위 규칙을 두 번 고친 이유 (정직한 기록)

| 시도 | 결과 |
|---|---|
| ① 제거량 × 열위 | 1절이 40% 삭제 → **4후보 전부 예산 초과, 사용 불가** |
| ② 손실 밀도(건당손익) 순 | 예산은 통과하나 슬롯 4개를 거래 0.8% 짜리 미세 포켓이 차지 → 25%p 예산 중 **3.2%만 사용, 개선 +43~107원** |
| ③ **한계 개선 탐욕** (채택) | 매 단계 실제 결과 건당손익을 재서 최선 선택 → 예산 19~22%p 사용, **개선 +244~501원** |

③ 은 설계·홀드아웃 **양쪽에서 개선하지 못하는 절은 담지 않는다**. 조합이 바뀌면 이전
판정을 무효화하고 다시 잰다(겹치는 절의 한계 효용은 순서에 따라 달라지기 때문).
