# HOF3 사전 등록 — 밴드 3 전용 절 집합 (2026-08-10)

> **이 문서는 엔진 실행 전에 작성·커밋된다.** 커밋 해시가 실행보다 앞선다.
> 실행 후 이 문서의 어떤 숫자도 고치지 않는다.
> 선행: `2026-08-10_HOF2_거래부검.md` (발굴 생존 0) · 한계 `L-2026-08-10B`

## 1. 원래 HOF3 은 무효다 — 왜 재설계하는가

상세실행계획 §3 의 HOF3 은 "HOF2 생존 절의 문턱을 최적화"였다.
**HOF2 생존이 0 이므로 실행 대상이 없다.** 억지로 후보를 살려 최적화로 넘기면
그것이 지난 10라운드의 실패 방식이다. 대신 **아직 검정되지 않은 가설**로 간다.

| | 반증된 것 | 아직 검정되지 않은 것 |
|---|---|---|
| HOF1 | 밴드 2 의 절을 09:20 까지 늘려 쓰기 | |
| HOF2 | 그 산출물을 단일 피처 문턱으로 걸러내기 | |
| **HOF3** | | **09:05~09:20 전용 절 집합** |

사용자 가설("사람은 09:00~09:20 을 **밴드별 조건**으로 쓴다")은 반증되지 않았다.

## 2. 가설 — 문턱은 시각에 따라 움직여야 한다

챔피언의 두 밴드를 나란히 놓으면 **일관된 이동 방향**이 보인다.

| 절 | 밴드 1 (09:00~09:02) | 밴드 2 (09:02~09:05) | 방향 |
|---|---|---|---|
| 당일거래대금 하한 | 500 | 5,000 | **↑ ×10** |
| 전일비 하한 | 0 | 5 | **↑ +5** |
| 시가대비등락율 하한 | 0.5 | 3.0 | **↑ +2.5** |
| 당일거래대금각도(30) 하한 | 1 | 5 | **↑ +4** |
| 등락율 하한 | 1.0 | 2.0 | **↑ +1.0** |
| 초당매수수량 / 매도총잔량 | 0.20 | 0.30 | **↑ +0.10** |
| 초당거래대금 / 평균(30) | 3.0 | 2.0 | **↓ −1.0** |
| 체결강도 하한 | 100 | 50 | **↓ −50** |
| 회전율 하한 | 2.0 | 1.5 | **↓ −0.5** |
| 현재가 상한 | 50,000 | 30,000 | ↓ |

**물리적 해석**: 장이 진행될수록 **누적 활동량**(당일거래대금·전일비·시가대비등락율)은
자연히 커지므로 요구를 올려야 하고, **순간 급등**(초당거래대금 배수·체결강도)은
드물어지므로 요구를 낮춰야 한다.

**가설: 밴드 3(09:05~09:20)의 문턱은 이 이동을 한 걸음 더 간 자리에 있다.**

이것은 **이론 주도 외삽**이지 무작위 탐색이 아니다. 자유도는 **스칼라 하나(k)** 다.

## 3. 격자 — 6셀 (실행 전 고정 · 헌법 15항)

외삽 계수 `k` 하나로 전 문턱을 동시에 움직인다(k=1 은 902→905 와 같은 크기의 한 걸음).

```
당일거래대금 하한       = 5000 × 10^k
전일비 하한            = 5 + 5k
시가대비등락율 하한     = 3.0 + 2.5k
당일거래대금각도 하한   = 5 + 4k
등락율 하한            = 2.0 + 1.0k
초당매수수량/매도총잔량  = 0.30 + 0.10k
초당거래대금/평균(30)   = max(1.0, 2.0 − 1.0k)
체결강도 하한          = max(20, 50 − 50k)
회전율 하한            = max(0.5, 1.5 − 0.5k)
현재가 상한            = 30000 (고정 — 더 줄이면 표본만 준다)
```

| 셀 | 내용 | 실행 |
|---|---|---|
| **K0** | k = 0 (밴드 2 절 그대로) | **이미 측정됨** — HOF1 후보. 학습 코호트 C **+44,216원** |
| K05 | k = 0.5 | 실행 |
| K10 | k = 1.0 | 실행 |
| K15 | k = 1.5 | 실행 |
| K20 | k = 2.0 | 실행 |
| **SWAP** | 밴드 1(902) 절 집합을 밴드 3 에 그대로 적용 | 실행 (대조군) |

**엔진 실행 5회.** 밴드 1·2 는 **손대지 않는다**(헌법 7항 — 한 번에 한 축).

## 4. ★ 합격선 (실행 전 고정 · 사후 조정 금지)

판정 대상은 **학습 구간의 코호트 C(09:05~09:20) 총수익금**이다.
밴드 1·2 는 불변이므로 코호트 C 만 보면 밴드 3 의 순효과가 분리된다
(HOF1 에서 A·B 코호트가 비트 단위로 동일했음이 확인됐다).

| # | 조건 | 필수 |
|---:|---|:---:|
| A | 학습 코호트 C 총수익금 **> 0** | ✅ |
| B | 학습 코호트 C 총수익금 **> K0(+44,216원)** | ✅ |
| C | 코호트 C 거래 수 ≥ 30 (표본 하한) | ✅ |
| D | 필요자금 ≤ 2,000만원 | ✅ |
| E | 코호트 A·B 가 기준선과 동일 (밴드 3 만 바뀌었다는 증거) | ✅ 검증용 |

### 판정 규칙 (미리 정한다)

| 결과 | 다음 행동 |
|---|---|
| A~D 통과 셀이 있다 | **상위 ≤2 셀만** 검증 구간에서 재측정 |
| 검증에서도 코호트 C > 0 | 원장 `PROMISING` 등재(진입 계열 상한) + **사람 보고**. 확인 구간은 예약 |
| 통과 셀 0 | **밴드 3 방향을 닫는다**(등록부 §3). 프로그램은 HOF6(신규 거래일)로 |
| K0 만 최고 | 외삽 가설 반증 — 같은 결론(방향 닫음) |

### 4.1 ⚠️ 판정의 한계 — 미리 밝힌다

HOF2 진단에서 **검증·확인 구간의 코호트 C 총계를 이미 열람했다**(L-2026-08-10B).
그 구간이 코호트 C 에 불리하다는 것을 나는 알고 있다. 따라서:

- 검증 구간 성적은 **약한 증거**로만 쓴다. 통과해도 `PROMISING` 이 상한이다.
- **진짜 표본 밖 확인은 신규 축적 거래일(HOF6)뿐이다.** 이번 라운드에서
  실전 제안은 하지 않는다.
- 확인 구간(TEST)은 이번 라운드에서 **읽지 않는다.**

## 5. 예상 (실행 전 기록 · 사후 대조용)

| 항목 | 예상 |
|---|---:|
| 셀당 소요 | 학습 411일 · 약 7~10분 |
| 총 소요 | 약 45분 |
| 통과 셀 | 0~1 (사전 확률로는 실패가 더 그럴듯하다) |

**정직하게**: 나는 이 라운드가 실패할 가능성이 더 크다고 본다. HOF2 가 보여준
"학습 구간 코호트 C 손익 0"은 그 시간대에 애초에 잡을 우위가 얇다는 뜻이기도 하다.
그래도 검정할 값어치가 있는 이유는 **이것이 사용자 가설의 직접 검정**이고,
실패하면 넓은 창 방향을 **근거를 갖고** 닫을 수 있기 때문이다.
