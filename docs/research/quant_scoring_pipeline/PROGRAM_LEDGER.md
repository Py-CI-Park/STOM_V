## 4. 갱신 규칙

1. 라운드 종료마다 §1 해당 프로그램 행의 "결과" 를 갱신하거나 행을 추가한다.
2. 방향이 닫히면 §3 에 근거·날짜와 함께 1행을 추가한다. 근거 없는 폐쇄는 금지.
3. **새 프로그램을 열 때 이 문서를 먼저 읽고, 차터에 "§2·§3 확인함"을 명기한다.**
4. append-only. 지우지 않고 정정 행을 덧붙인다.
