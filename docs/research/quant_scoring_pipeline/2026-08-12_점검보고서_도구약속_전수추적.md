# 점검 보고서 — 최적화·백파인더 약속의 전수 추적과 연구 체계 평가 (2026-08-12)

> 사용자 질문: "과거 계획의 최적화·백파인더는 사용됐나, 연구됐나, 놓쳤나?
> 현 계획에 누락은 없나, 타당한 단계인가? 체계적으로 연구·관리하고 있나?"
> **방법: 계획 문서 6종 × 도구 10종을 전수 대조**했다. 결론 먼저:

| 질문 | 답 |
|---|---|
| 백파인더는 사용됐나 | **과거 자율 루프에서 실사용됐다**(A-5 배선·band_seeds.json 실존 — 승격 0). HOF 에서는 2회 조용히 대체(실수 #17). **G1 에서 직접 조립으로 재사용 예정** |
| 최적화(옵튜나)는 | 사용 0회 — 단 **W6 의 대체는 명시돼 있었다**(50시간 vs 36초 산수). 조건부 지위로 정리 |
| 현 계획에 누락은 | **실질 누락 2건 발견** — ① G1 채굴에 관심종목 교집합 제약 없음(치명) ② G2 매도식 미정 |
| 체계적인가 | 채점표(§4): 사전등록·원장·재현성은 **강함**. 계획-실행 일치가 **약점**(침묵 대체 3건) — 교정 장치는 신설됐고 효과는 다음 라운드가 증명한다 |

## 1. 도구 약속 전수 추적 (계획 6종 × 도구 10종)

### 1.1 백파인더 — 3개 시대의 이력

| 시대 | 사용 형태 | 결과 |
|---|---|---|
| 자율 루프 (06월) | **실사용** — `mine_band_seeds.py` 로 채굴 → `band_seeds.json` → 생성 프롬프트 힌트 주입(A-5 배선 · 기본 OFF 플래그) | 프로그램 전체 승격 0 (무규율 시대 — 전 구간 판정) |
| QSP~W (07말~08-10) | 조사만 2회 (등록부 중복 4) | 미사용 |
| HOF (08-10~12) | 계획에 2회 등재 → **2회 조용히 대체**(실수 #17) — HOF2 는 결과 테이블 `B_*` 스냅샷으로, HOF4 는 자체 절-판정으로 | 대체물 자체는 유효했으나 **약속 위반** |

**판정: "놓친 것"이 맞다.** 단, 이번 재편(G1)에 반영됐고 이제는 **대체 금지**가 명문화됐다.
과거 실사용의 교훈도 챙긴다: 힌트 간접 주입(자율 루프)은 실패했다 — G1 은 **직접 조립 +
분할 판정**이라 형태가 다르며, 그래서 기대치도 §3 에 정직하게 적는다.

## 2. 재발 방지 — 도구 지위 등록부 신설 (PROGRAM_LEDGER §5)

"이 도구를 왜 안 쓰나"는 질문에 **한 번만, 영구히** 답하도록 도구별 상설 지위를
등록부에 신설했다: `채택 / 조건부(발동 조건 명시) / 대체됨(대체물 명시) / 비채택(사유)`.
이후 라운드는 지위 변경 시에만 등록부를 갱신한다(체크리스트 11 과 연동).

## 3. 현 계획(G 레인) 타당성 점검 — 전수검사가 찾은 누락 2건

### 3.1 누락 ① (치명) — 관심종목 교집합 제약이 없다

`backfinder_principle` 은 **raw tick DB 전체**에서 캔다. 그런데 HOF4 실측:
놓친 승자의 **69%가 관심종목 밖**이다. 제약 없이 채굴하면 시드의 다수가
**실전에서 매수 자체가 불가능한** 종목·시점에서 나온다 — 설계 성적만 좋고
실행 불가능한 조건식을 낳는 지름길이다.
→ **G1 사전등록에 "우주 = design_v5 관심종목=1 교집합" 제약을 필수로 넣는다.**

### 3.2 누락 ② — G2 의 매도식이 미정이다

새 골격의 매수식만 정의돼 있고 매도식 선택(챔피언 매도 vs 조립기 배리어 매도)이
계획에 없다. 헌법 7항(동시 변경 금지)상 **G4 판정은 매도 고정**이 필요하다.
→ G2 사전등록 항목으로 명시: 1차는 챔피언 매도 고정(비교 가능성),
배리어 매도는 후속 라운드.

### 3.3 타당성 판정 (누락 2건 반영 조건부)

| 검점 | 판정 |
|---|---|
| QSP "지도 함정"(닫힌 방향 2)과 다른가 | 다르다 — 지도는 **순위·채택**에 쓰여 닫혔고, G1 은 시드 생성 전용 + 판정은 분할 엔진(헌법 9항 정합) |
| 과거 백파인더 실패와 다른가 | 다르다 — 간접 힌트(LLM)가 아니라 직접 조립 + 당시 없던 분할 판정 |
| 기대치 | **성공 확률은 여전히 낮다** — 생성원이 lookahead 분포라 설계 성적은 부풀 것이고 검증 구간이 심판이다. 정직 추정: 검증 통과 시드 ≥1 확률 ~20~30% |
| 대안 대비 | 유일한 미시도 조합(생성×규율) + 실패해도 셋업 분포 지도가 남는다 |

## 4. 연구 체계 평가 — 정직 채점표

| 축 | 평가 | 근거 |
|---|:---:|---|
| 사전 등록 규율 | **A** | HOF1~5 전부 실행 전 커밋(해시) · 사후 조정 0건 |
| 판정 재현성 | **A** | 기준선 4회 정확 재현(드리프트 0) · 부호 반전 검출 |
| 기록 관리 | **B+** | 원장 25종 67행 append-only · 확정 지식 13 · 닫힌 방향 12 · 실수 17건 발견자별 기록. 오염 1건 발생했으나 프로토콜이 검출·정정 |
| **계획-실행 일치** | **C** | 침묵 대체 3건 + backfinder 2회 반복. 체크리스트 11 신설 — **효과는 다음 라운드가 증명해야 한다** |
| 자가 검출 능력 | **B** | 추세 개선(최근 3건 프로토콜 자가 검출: C중복·원장오염·min배선) — 그러나 사용자 검출도 3건(도구·관찰·backfinder) 지속. **목표: 라운드당 사용자 검출 0** |
| 목표 정렬 | **B−** | 목표(수익 조건식) 대비 실전 후보 0. 다만 "안 되는 것의 지도"(닫힌 방향 12)와 판정 인프라가 누적됐고, 이제 생성 단계 진입 |

