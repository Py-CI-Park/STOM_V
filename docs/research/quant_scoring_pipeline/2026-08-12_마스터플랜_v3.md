## 1. 목표와 목적

### 1.1 최종 목표 (사용자 정의)

> **존재하는 DB 와 백테스트 시스템으로, 실전에서 수익 나는 조건식을 만든다.**

### 1.2 성공의 정의 — 4관문 (모두 통과해야 "성공")

| 관문 | 기준 | 심판 |
|---|---|---|
| ① 설계 | 학습 구간에서 합격선(챔피언 또는 절대 흑자) 초과 | 엔진 A/B |
| ② 검증 | 검증 구간에서도 유지 (편의를 라운드 안에서 걸러냄) | 엔진 A/B |
| ③ 표본 밖 | 신규 축적 거래일 또는 min OOS(60일·잠금)에서 생존 | 엔진 + 🔒사람 |
| ④ 실전 | 감독형 소액 실전에서 생존 | 🔒사람 |

현재 위치: **①②를 통과한 실전 후보 0종.** ③의 tick 표본은 소진, min OOS 는 보유.

### 1.3 왜 아직 실패하는가 — 한 문단 요약

넓은 탐색은 무규율이라 편의에 전멸했고(자율루프·QSP), 좁은 탐색은 규율은 있었으나
천장이 낮았으며(W: +0.37%p < 편의 0.54~0.62%p), HOF1~5 는 챔피언 국소 변형 공간이
비어 있음을 확정했다. **인간 명전과의 격차는 데이터가 아니라 "새 골격을 생성하는
단계"의 부재다** — 그래서 v3 의 중심은 생성 레인(G)이다.

## 5. 전체 로드맵 — 단계별 목표·방법·예상 효과

### 5.0 한눈 지도

```
[G1 채굴] → [G2 조립] → [G3 관찰] → [G4 판정] ──통과──> [③ 표본 밖] → [④ 실전🔒]
 tick 학습     다밴드      차트 확인    학습→검증          min OOS🔒 /
 관심종목 교집합  시드≤8     헛것 차단     합격선=챔피언       신규 데이터(수집 재개 시)
      │
      └──(G4 후 같은 구조)──> [G-min] min 생성 레인 (합격선 = 절대 흑자)
```

### 5.1 G1 — 승자 셋업 채굴 (tick)

| 항목 | 내용 |
|---|---|
| 연구 목표 | "곧 오를 종목의 진입 직전 모습"의 **데이터 실측 분포** 확보 — 시간대(5분)×시총 세그먼트별 분위(q25/50/75)·precision·lift·negative 대조 |
| 방법 | `backfinder_principle` **직접 실사용(대체 금지)** · 학습 구간(달력 411일)만 · **우주 = 관심종목 교집합**(점검보고서 누락① 반영 — 아니면 실행 불가 조건식 양산) |
| 산출 | 세그먼트별 셋업 분포 + 시드 후보 ≤8 (헌법 15항) |
| 예상 효과 | 챔피언 밖 골격의 **재료**. 직접 수익 아님(시드 전용 — lookahead 편향) |
| 성공/실패 기준 | 성공 = lift 유의 세그먼트 ≥1. 실패 = 전 세그먼트 lift≈1 → "셋업 예측 불가" 확정, 등록부 등재 |
| 비용 | 0.5~1일 |

### 5.2 G2 — 조립

| 항목 | 내용 |
|---|---|
| 연구 목표 | 분위 → 밴드 시드 → **다밴드 조건식** (확정 지식: 다밴드 이산분기가 이기는 구조) |
| 방법 | `band_compiler` + `assembler` · **매도식 = 챔피언 매도 고정**(누락② 반영·헌법 7항) |
| 예상 효과 | 실행 가능한 새 골격 후보 ≤8 |
| 비용 | 0.5일 |

### 5.3 G3 — 관찰 검증

| 항목 | 내용 |
|---|---|
| 연구 목표 | 시드가 실제로 잡는 표본을 **차트로 확인** — 채굴이 통계 허깨비를 쫓는지 눈으로 차단 |
| 방법 | HOF4 파이프라인 (시드 매칭 표본 층화 ≥20건) |
| 예상 효과 | 헛것 시드 조기 탈락 → G4 엔진 비용 절약 + 인과 서술 축적 |
| 비용 | 0.5일 |

### 5.4 G4 — 판정

| 항목 | 내용 |
|---|---|
| 연구 목표 | 새 골격이 **챔피언을 넘는가** |
| 방법 | 학습(411일) 전 시드 → 통과 상위 ≤2 만 검증(203일) · 게이트: 총수익금>챔피언 ∧ 흑자 ∧ 자금≤2,000만 · 확인 구간 예약 |
| 예상 효과 | 통과 시 **최초의 비-챔피언 실전 후보군**(PROMISING) · 실패 시 "생성×규율로도 tick 5분 창은 챔피언이 상한"이라는 강한 결론 |
| 정직 확률 | 검증 통과 시드 ≥1: **~20~30%** (생성원이 lookahead 라 설계 성적은 부풀 것) |
| 비용 | 1~1.5일 (엔진 ≤10런) |

### 5.5 G-min — min 생성 레인 (G4 후)

| 항목 | 내용 |
|---|---|
| 연구 목표 | 흑자 챔피언이 없는 min(213일·6.5시간 세션)에서 **최초의 흑자 골격** |

| 예상 효과 | 통과 시 min OOS 60일(잠금)이라는 **진짜 표본 밖 심판**을 쓸 자격 획득 |
| 정직 확률 | 낮음 (~15%) — 기준선 −3,754만원·승률 25%인 어려운 지형 |
| 비용 | 1~2일 |
