# SQ01B1 실제 job 결과 분석 경로 품질 적용

부모1933e7fb. branch codex/process-research-sys-05-analysis-quality.
전체 SQ01B 전파를 한 번에 변경하지 않고 첫 경로인 `/bt/result?job_id=`를 연결한다.

1. 실제 결과 route 회귀: 정상 공식 CSV·부분 파싱·누락·count 불일치·ERROR/NO_TRADES terminal을 구분한다.
2. 기존 full_analysis에는 검증된 NormalizedTrade 배열을 전달하는 선택적 keyword seam만 추가한다. 기존 직접 CSV facade·지표 산식은 유지한다.
3. job 결과가 발견돼도 자료/실행이 준비되지 않았으면 metrics/analysis를 null로 반환한다. 품질 영수증과 실행 상태는 표시한다. 정상 무거래·오류를 구분한다.
4. BtResultArea에 같은 품질 카드를 연결하고 미충족 시 차트·몬테카를로 요청을 만들지 않는다. 기존 source request guard는 유지한다.
5. 기존 최소 CSV 시험 fixture는 공식 owner 헤더로 확장하되 원래 손익·행수·경로 assertion은 보존한다. run/gen·report·compare·개별 분석 endpoint 전파는 후속 SQ01B 원자로 남긴다.

수용: 한 snapshot만 파싱, 불량 자료로 full_analysis 호출 없음, 정상 손익/구간 수치 동일, source 기록/프로세스 진단 보존, 품질 UI/API·독립 검토. StageF/경제/DB쓰기/병합/원격작업 없음. rollback은 이 job-path seam·배선만 역변경한다.
