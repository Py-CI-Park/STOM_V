## 5. ⬅ 다음 한 걸음 — 엔진 실측 (가장 값어치 큼)

지도와 워크포워드가 같은 방향을 가리키므로 **엔진이 심판할 차례**다. 지도 축과
엔진 축을 같은 자로 재는 유일한 방법이다.

```
1) 매도식 렌더 — trailing(arm+3%/give1.5%) 를 엔진 DSL 로
   · 무장: 최고수익률 >= 3.0
   · 청산: 최고수익률 - 수익률 >= 1.5
   · 참고: assembler / run_p5_hierarchy 의 렌더 경로 재사용
2) 진입 = 챔피언 902/905 원본 그대로(Tick_B_902_905 계열, strategy.db 등록분)
3) 엔진 설계 구간 실측 → 챔피언 원본(+3,479원/건 · CAGR +33.24% · MDD 18.68%) 대조
4) 전이율 기록 → 페이지 12 원장(`/bt/transfer-ledger`)에 자동 등재
5) 통과 시 → 검증 사다리 3종(ladder.py) → **사용자 승인** → 감독 소액 실전
```

**주의**: 지도가 좋다고 엔진이 좋은 것은 아니다 — QSP12 에서 이미 부호가 뒤집힌 적이
있다(전이율 −1.18). 다만 이번에는 진입 단위 교정 · 트레일링 정확값 · 워크포워드를
모두 통과한 상태다.
