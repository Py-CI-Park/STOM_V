### 2.1 넓은 시간 = 수익 용량 (피드백 1 검증)

| 시나리오 | 건수(2년) | 건당 | 총손익(2년) | 배율 |
|---|---:|---:|---:|---|
| 902/905 실측 | 182 | +3,479원 | +633,131원 | 1× |
| 와이드 그물, 건당 **+500원**만 달성 | 86,390 | +500원 | **+43,195,000원** | **68×** |
| 와이드 그물, 건당 +1,000원 | 86,390 | +1,000원 | +86,390,000원 | 136× |

**"넓은 시간의 좋은 조건식이 필요하다"는 직관은 정확하다.** 좁은 창의 높은 건당보다
넓은 창의 낮은 건당이 총수익에서 압도한다. 단, 건당 +500원이 실제 도달 가능한지는
**Phase S-0 프런티어 실측**이 답한다 — 추측하지 않는다.

## 3. 🗺️ QSP8-R 프로그램

```
Phase B (벤치마크)  ┐
Phase S-0 (프런티어) ┤→ Phase S-1 (매도 후보) → Phase T (패턴 전이) → Phase W (시간 지도) → Phase U (통합)
```

### Phase B — 명예의 전당 벤치마크 (엔진 N회 · 낮은 난이도)

| 항목 | 내용 |
|---|---|
| 목적 | "명예의 전당 인간 수익만큼"의 **목표 수치를 실측**으로 정의 + 교사 풀 확보 |
| 방법 | 대시보드 `pro_hof` 표면의 인간 전략들을 v2 구간(20240304~20260227)으로 전수 백테스트 |
| 산출 | 벤치마크 표(전략·건수·승률·손익비·건당·CAGR·MDD·MFE/MAE·세션 폭) |
| 판정 | 관측 전용 — 여기서 채택 없음 |

### Phase S-0 — 매도 프런티어 실측 (엔진 0회 · 오프라인)

| 항목 | 내용 |
|---|---|
| 기질 | 와이드 그물 86,390건 트레이드 경로 (tick DB 09:00~09:30 전체 보유 → 실제 청산보다 **늦은** 청산도 092800까지 재생 가능) |
| 도구 | `autopsy/exit_counterfactual.py` (필드: `hold_seconds`·`net_return_pct`·`gross_return_pct`·**`giveback_pct`(트레일링)**·`price`) + `autopsy/sell_dsl_replay.py` |
| 산출 | ① 보유시간×MFE/MAE 격자 ② giveback(트레일링) 폭별 손익비 곡선 ③ **손익비–거래수 파레토 프런티어** |
| **결정 게이트** | 프런티어 최고 손익비가 **2.082 미만**이면 → 이 진입 집합은 어떤 매도로도 못 구한다. Phase S-1을 건너뛰고 **Phase T(진입 재편)부터** 진행 |

### Phase S-1 — 매도 후보 생성 → 엔진 검증

| 항목 | 내용 |
|---|---|
| 문법 | 트레일링(giveback) · 시간단계 청산 · MFE-armed stop · **사용자 6개 건강 매도 규칙 구조 이식**(등락율각도×잔량, 최고수익률 게이트 — 손실 2규칙 구조는 반면교사) |
| 선별 | 리플레이 스크리닝(순위용) → 상위 3~5개만 엔진 16 실측 |
| 판정 | v2 프로토콜 · promotion-gate `2job_split` · **주지표 = 손익비, 병기 = 건당** · 설계·홀드아웃 양쪽 개선 |
| 축 규율 | 매도 축 라운드 — 매수식은 와이드 그물 고정 |

### Phase T — 사람 패턴 전이 (매수 축)

| 항목 | 내용 |
|---|---|
| 교사 | 902/905 매수식 + Phase B에서 확보한 명예의 전당 인간 전략들 |
| 방법 | `pattern_cards.py`로 골격 추출(상수 마스킹) → 와이드 창 분위 격자 위 임계 **재적합** → `region_proposer.py` 삽입 경로 재사용 |
| 목표 | 거래수 축소가 목적이 아니다 — **MFE/MAE 형태 개선(0.62 → 1.0+)**. "위로 갈 자리에서 사는" 진입으로 재편 |
| 성격 | 뺄셈(제거)이 아니라 **덧셈(선별 강화)** — QSP1~7과 반대 방향 |

### Phase W — 시간 일반화 지도

| 항목 | 내용 |
|---|---|
| 질문 | 902/905의 엣지는 **절**에서 오나, **시간대(09:02~05)**에서 오나? |
| 방법 | 902/905 골격을 창 이동 {09:00~03, 09:02~05, 09:05~08, …}으로 슬라이드 → 창별 엣지 지도 |
| 확장 | tick은 09:00~09:28이 물리적 한계(tick DB) — 진짜 "넓은 시간"은 **min 레인(전일장)** 에서 같은 지도를 작성 |
| 산출 | "넓은 시간의 좋은 조건식"이 성립하는 창 목록 → Phase T 후보의 적용 범위 결정 |

### Phase U — 통합

최고 매도(S-1) × 최고 매수(T/W). 한 라운드 한 축 유지 · promotion-gate · **채택은 사람 승인**.
