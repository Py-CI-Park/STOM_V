## 1. 진입 조건식 `Tick_B_902_905` — 4곳 모두 동일

### 1.1 설계 사상

**장 시작 5분 안에, 시가총액 3,000억 미만 소형주가 "거래대금 급증 + 매수 우위 +
고가권 유지" 상태일 때만 산다.** 시간대를 둘로 쪼개 앞 2분(902)과 다음 3분(905)에
서로 다른 문턱을 쓴다 — 장 초반 2분은 변동성이 달라서다.

### 1.2 공통 파생 지표 (4개)

```python
전일종가       = 현재가 / (1 + (등락율 / 100))                  # 원
시가등락율     = ((시가 - 전일종가) / 전일종가) * 100            # %  갭 크기
시가대비등락율 = ((현재가 - 시가) / 시가) * 100                  # %  시가 이후 상승분
초당순매수금액 = (초당매수수량 - 초당매도수량) * 현재가 / 1e6     # 백만원  순매수 압력
```

> **왜 이렇게 계산하나** — 엔진은 `등락율`(전일 대비)만 주고 `시가등락율`은 안 준다.
> 전일종가를 역산해서 만들어야 "갭으로 오른 것"과 "장 중에 오른 것"을 나눌 수 있다.

### 1.3 공통 게이트 (모든 시간대)

| 절 | 조건 | 무엇을 막나 |
|---|---|---|
| 1 | `관심종목 == 1` | 수집 대상 밖 종목 제외 |
| 2 | `고저평균대비등락율 > 0` | 당일 중간값 아래 종목 제외 |
| 3 | `현재가 < VI가격 - VI호가단위*5` | **VI(변동성완화장치) 발동 직전 진입 차단** |
| 4 | `not 라운드피겨위5호가이내` | 심리적 저항선(10,000원 등) 바로 아래 매수 회피 |

### 1.4 시간대 A — 09:00:00 ~ 09:02:00 (902 전략, 14개 절)

```python
if not (1000 < 현재가 <= 50000):                 매수 = False   # 가격 밴드
elif not (1.0 < 등락율 <= 8.0):                  매수 = False   # 전일비 상승폭
...
if 시가총액 < 3000:                                             # 소형주만
    if not (1.0 <= 시가등락율 < 4.0):            매수 = False   # 갭 1~4%
    elif not (0.5 <= 시가대비등락율 < 6.0):      매수 = False   # 시가 이후 +0.5~6%
    elif not (1 < 초당순매수금액 < 1000):        매수 = False   # 순매수 100만~10억
    elif not (현재가 > 고가 - (고가-저가)*0.20): 매수 = False   # 고가권 상위 20%
    elif not (전일비 > 0 and 전일동시간비 > 0):  매수 = False   # 거래량 증가
    elif not (회전율 > 2):                       매수 = False
    elif not (당일거래대금 > 500):               매수 = False   # 5억원
    elif not (1 < 당일거래대금각도(30) < 30):    매수 = False   # 완만한 증가만
    elif not (초당거래대금/초당거래대금평균(30) > 3.0): 매수=False # 급증 3배
    elif not (초당매수수량 > 매도총잔량*0.20):   매수 = False   # 매수 압력
    elif not (매도총잔량*0.10 < 매수총잔량 < ... ): 매수 = False # 호가 균형
    elif not (100 <= 체결강도 <= 300):           매수 = False
else: 매수 = False                                              # 대형주 제외
```

### 1.5 시간대 B — 09:02:00 ~ 09:05:00 (905 전략, 15개 절)

902 와 **같은 뼈대에 문턱만 다르다.** 차이가 나는 곳만:

| 항목 | 902 (0~2분) | 905 (2~5분) | 왜 |
|---|---|---|---|
| 가격 상한 | 50,000원 | **30,000원** | 뒤로 갈수록 저가주 위주 |
| 등락율 | 1.0 ~ 8.0% | **2.0 ~ 15.0%** | 이미 오른 종목을 받는다 |
| 시가등락율 | 1.0 ~ 4.0% | **0.0 ~ 8.0%** | 갭 조건 완화 |
| 시가대비등락율 | 0.5 ~ 6.0% | **3.0 ~ 8.0%** | 시가 이후 상승 요구 강화 |
| 거래대금 급증 | 3.0배 | **2.0배** | 완화 |
| 매수 압력 | 매도총잔량 20% | **30%** | 강화 |
| 체결강도 | 100 ~ 300 | **50 ~ 300** | 완화 |
| 추가 절 | — | `누적초당매수수량(30)*0.5 < 누적초당매도수량(30) < *1.0` | 과열 배제 |
| 선행 필터 | — | `초당거래대금 > 초당거래대금N(1)` | 직전 초 대비 증가 |

**09:05:00 이후는 무조건 매수 안 함.**

### 1.6 이 조건식의 성격

- 절이 **29개**(공통 4 + 902 14 + 905 15)로 매우 선별적
- 그 결과 **355 거래일에 161건**(하루 1.39건) — 통계 검정에 필요한 표본의 1/3
- 이 선별성이 흑자의 원천이자 **표본 부족의 원인**이다

## 2. 매도 조건식 A — `Tick_S_902_905` (챔피언 원본, 8종 규칙)

```python
시가대비등락율 = ((현재가 - 시가) / 시가) * 100
매도 = False

# ① 상한가 직전 차익 실현
if 등락율 > 29.5:                                                        매도 = True

# ② 시가 밑 + 손실 2% + 최근 60초 최저가 이탈 → 추세 붕괴 손절
elif 시가대비등락율 < 0 and 수익률 <= -2.0 and 현재가 < 최저현재가(60, 보유시간):
                                                                          매도 = True
# ③ 60초 넘게 들고 있는데 최근 60초 최저가 이탈 → 시간 손절
elif 보유시간 > 60 and 현재가 < 최저현재가(60, 보유시간):                  매도 = True

elif 시분초 < 93000:                                     # 09:30 이전에만 적용
    # ④ 고정 익절/손절
    if 수익률 >= 5 or 수익률 <= -5.0:                                     매도 = True
    # ⑤ 트레일링 — 최고 6% 넘긴 뒤 60% 지점까지 되돌리면
    elif 최고수익률 > 6 and 최고수익률 * 0.6 >= 수익률:                    매도 = True
    elif 시가총액 < 10000:                               # 시총 1조 미만만
        # ⑥⑦⑧ 매도 압력 3단계 — 등락율각도(추세 기울기) 구간별로 문턱을 바꾼다
        if   등락율각도(30) >= 10 and (초당매도수량-초당매수수량) >= 매수총잔량*0.5 \
             and (현재가/현재가N(1)-1)*100 < -0.5:                        매도 = True
        elif 5 <= 등락율각도(30) < 10 and ... >= 매수총잔량*0.7 and ... < -0.7: 매도 = True
        elif 0 <= 등락율각도(30) < 5  and ... >= 매수총잔량*0.8 and ... < -0.5: 매도 = True
        # ⑨ 이동평균 이탈
        elif 4.5 < 최고수익률 and 현재가N(1) >= 이동평균(60,1) and 이동평균(60) > 현재가:
                                                                          매도 = True
if 매도: self.Sell()
```

### 2.1 규칙별 성격

| # | 규칙 | 유형 | 사람의 의도 |
|---:|---|---|---|
| ① | 등락율 > 29.5 | 익절 | 상한가 직전 확정 |
| ② | 시가 밑 + −2% + 최저가 이탈 | 손절 | **추세가 깨졌다** |
| ③ | 60초 초과 + 최저가 이탈 | 시간 손절 | 오래 들고 있는데 신저가면 나온다 |
| ④ | ±5% | 고정 익절/손절 | 단순 상하한 |
| ⑤ | 최고 6% 후 60% 되돌림 | **비례 트레일링** | 오른 만큼 지킨다 |
| ⑥⑦⑧ | 매도 압력 3단계 | 미시구조 손절 | **추세 기울기별로 문턱을 바꾼다** |
| ⑨ | 60초 이동평균 이탈 | 추세 손절 | 평균선 아래로 떨어지면 |

**⑤가 이미 트레일링이다.** 다만 **비례식**(최고 × 0.6)이고, AI 후보는 **차분식**
(최고 − 수익률 ≥ give)이다. 이 차이가 이번 A/B 의 실질이다.

| | 챔피언 ⑤ | AI 후보 |
|---|---|---|
| 무장 | 최고수익률 > 6% | 최고수익률 ≥ arm (3% 또는 5%) |
| 청산 | 최고 × 0.6 ≥ 수익률 | 최고 − 수익률 ≥ give (1~2%p) |
| 성격 | 비례 — 많이 오를수록 많이 내준다 | **차분 — 오른 폭과 무관하게 일정폭만 내준다** |
| 예: 최고 10% | 6%까지 버팀(4%p 반납) | 8%에서 청산(2%p 반납) |
| 예: 최고 20% | 12%까지 버팀(8%p 반납) | 18%에서 청산(2%p 반납) |

## 3. 매도 조건식 B — AI 생성 트레일링 (`W4_S_TRAIL_*`)

렌더러: `ai_strategy_loop/labeling/assembler.render_trailing_sell_expression`

```python
# W4_S_TRAIL_5_2 — 트레일링 청산 (무장 +5% / 되돌림 2%p / 지평 600)
매도 = False

if 최고수익률 >= 5 and (최고수익률 - 수익률) >= 2:   매도 = True   # 트레일링
elif 보유시간 >= 600:                                매도 = True   # 만기(10분)
elif 시분초 >= 92800:                                매도 = True   # 전체청산
if 매도: self.Sell()
```

**규칙이 3개뿐이다.** 챔피언의 8종 대비 극단적으로 단순하다.

### 3.1 세 후보의 차이

| 후보 | 무장(arm) | 되돌림(give) | 실제 청산 분포 |
|---|---:|---:|---|
| B1 `TRAIL_3_1p5` | 3% | 1.5%p | — |
| B2 `TRAIL_3_1` | 3% | 1%p | — |
| **B3 `TRAIL_5_2`** | **5%** | **2%p** | **만기 115건 / 트레일링 40건** |

> **B3 의 74%가 트레일링이 아니라 만기(600초)로 청산된다.** 무장 문턱 5%에 도달하는
> 거래가 40건뿐이기 때문이다. 즉 B3 는 사실상 **"10분 보유 후 청산 + 크게 오르면 트레일링"**
> 전략이고, 이것이 평균 보유를 373초 → 540초로 늘려 **자본을 2배 쓰게 만든 원인**이다.

### 3.2 지도 커널과의 동치

렌더된 DSL 이 연구용 지도 커널(`labeling/trailing.py`)과 **같은 규칙**임을 실행으로
고정했다(`tests/unit/test_w4_trailing_sell_render.py`): 18개 경로 × 격자 조합에서
청산 시각과 수익률이 일치한다.

**남는 차이 2가지**(숨기지 않고 전이율로 흡수):

1. 지도는 매수=매도호가1 / 청산=매수호가1 로 스프레드를 명시적으로 낸다.
   엔진 `수익률` 은 **현재가** 기준이라 보유 중 값이 약간 높게 읽힌다 → 엔진이 조금 일찍 무장.
2. 엔진 `최고수익률` 은 0 에서 시작한다(음수 최고가 없다).

### 4.2 왜 자본을 2배 쓰나 — 인과 사슬

```
무장 문턱 5% 도달 거래가 40건뿐  →  나머지 115건은 만기(600초)까지 보유

                                 →  최대 동시보유 1종목 → 2종목
                                 →  필요자금 100만원 → 200만원
                                 →  총수익률 80.17% → 71.17%
```

**챔피언의 8종 규칙은 대부분 "빨리 나오는" 규칙이다**(②③⑥⑦⑧⑨가 전부 손절/추세이탈).
AI 후보는 그 조기 청산 규칙이 하나도 없어서 오래 들고 있게 된다.

## 5. 앞으로의 비교 서식 (이 문서가 표준)

새 A/B 를 할 때마다 아래를 **먼저** 채운다.

| 항목 | 내용 |
|---|---|
| 무엇을 고정했나 | (예: 진입 `Tick_B_902_905`) |
| 무엇을 바꿨나 | (예: 매도만) |
| 기준선(합격선) | (예: `Tick_S_902_905` — 사람 챔피언) |
| 후보 목록 | 이름 · 규칙 원문 · 파라미터 |
