## 3. 🔑 이번 세션의 결정적 지식

### 3.1 판정 기준 자체가 틀려 있었다 (내 오판 4건)

| 오판 | 교정 |
|---|---|
| 합격선을 "국면 4/4"로 — **챔피언이 3/4** | 합격선 = **챔피언** |
| **지도 축**으로 심판 (지도 344건 vs 엔진 체결 155건) | 심판 = **엔진 체결 기록** |
| "총수익 1.77배" 보고 — **자본 2배 누락** | 자본 지표 필수 동반 |
| 새 심판에도 `>` 로 챔피언 대 챔피언 REJECT | `>=` · 테스트로 고정 |

챔피언은 이미 파라미터화되어 있다(`C_T_902_905_U2_BO/SO/OR`, 변수 32개).

→ **한 번에 1~3개 변수만, 가설 예산 안에서, 응답면 고원 확인 후.**

## 5. 📐 헌법 (절대 규칙 8항)

1. **합격선은 챔피언이다.** 절대 기준을 만들면 먼저 챔피언으로 교정한다.
2. **심판은 엔진 체결 기록이다.** 지도는 탐색용이다.
3. **자본을 밝힌다.** 총수익금만 보면 자본을 더 쓴 쪽이 항상 이긴다.
4. **유의하지 않으면 유의하지 않다고 쓴다.**
5. **격자는 실행 전 고정, 전셀 보고.**
6. **홀드아웃은 사람만 연다.**
7. **진입과 매도를 동시에 바꾸지 않는다.**
8. **원장은 append-only.** 폐기 후보도 남긴다.
