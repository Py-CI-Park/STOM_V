## 1. 🧭 한 줄 결론

형태 인식 프로파일러가 동작하고 **2D 손실 포켓 5건을 처음으로 찾았다**. 다만 실데이터

## 2. 🔬 무엇을 만들었나

| 기능 | 구현 | 규율 |
|---|---|---|
| 10분위 경계 | 설계에서만 산출 → 홀드아웃에 동일 적용 | 누출 금지 |
| 분위 통계 | 건수·총손익·건당손익 + 표본 부족 표시 | 분위당 `max(100, 전체×0.5%)` |
| 형태 6종 | flat 가드 → **multi_band** → valley → tail_* → monotone_* → flat 폴백 | multi_band 우선 |
| 제거 구간 | 인접 **2칸 이상 연속**만 | 고립 1칸 금지 |

| 2D 포켓 | 상관 \|r\|<0.6 쌍 · 칸당 최소 표본 · Welch t + BH-FDR(q≤0.10) · 4-이웃 병합 · 직사각형 낭비 ≤30% | 다중비교 보정 |

### 3.3 2D 손실 포켓 — **프로그램 최초 검출 5건**

사용자가 요구한 "시간대 × 시총 × 기타 변수 조합의 손실 영역"이 처음으로 수치로 잡혔다.

| 쌍 | 칸 | 구간 | 제거율 | 설계 건당 | 홀드 건당 | 낭비 | max q |
|---|---:|---|---:|---:|---:|---:|---:|
| 시분초 × B_등락율 | 3 | 시분초 ≤ 90122 **and** 6.34 < 등락율 ≤ 15.68 | 2.06% | **−8,703** | **−9,857** | 0.00 | 0.088 |
| B_등락율 × B_체결강도 | 2 | 등락율 > 11.32 **and** 체결강도 ≤ 61.86 | 0.85% | **−10,349** | **−9,451** | 0.00 | 0.023 |
| 시분초 × B_등락율 | 2 | 91807 < 시분초 ≤ 92501 **and** 등락율 > 15.68 | 2.35% | −7,321 | −5,558 | 0.00 | 0.030 |
| 시가총액 × B_체결강도 | 2 | 3785 < 시총 ≤ 9990 **and** 체결강도 ≤ 61.86 | 2.54% | −6,708 | −6,435 | 0.00 | 0.027 |
| B_등락율 × B_체결강도 | 3 | 등락율 > 11.32 **and** 94.56 < 체결강도 ≤ 111.36 | 4.23% | −7,800 | −6,404 | 0.25 | 0.090 |

전체 평균이 설계 −5,341 / 홀드 −4,843 인데, **1위 포켓은 거래의 0.85% 만 차지하면서
건당 −10,349 / −9,451** 이다. 양쪽에서 평균의 두 배 가까이 나쁘다. 이것이 §2.1 에서
"시간대×시총 20칸 전부 손실이라 못 자른다"고 했던 문제의 해답이다 — **축을 바꾸면 잘린다.**

> 주의: `시가총액`·`시분초` 는 이 표에서 진단 축으로만 썼다. `시가총액` 원열은 `proposable=False`
> 이므로 조건식 후보 축에서는 `B_시가총액` 을 쓴다.

## 4. ⚠️ 설계서와 어긋난 실측 — 숨기지 않고 기록

### 4.1 체결강도 다중 밴드가 v2 창에서는 `confirmed` 가 아니다

설계서 §2.3a 는 "체결강도를 multi_band 로 정확히 잡으면 표본밖 +682원(valley 오분류 대비 2.2배)"
이라고 적었다. 그 수치는 **v1 구간**(설계 2022-04~2024-03 / 표본밖 2024-04~2026-02, 120,118건)
에서 산출한 것이다. **v2 구간(최신 2년)에서 다시 재면 결과가 다르다.**

| 항목 | 값 |
|---|---|
| 형태 | `multi_band` ✅ (설계서 예측대로) |
| 나쁜 구간 | D1 고립 1칸 + **D4~D8 연속** |
| 선택된 제거 구간 | `86.27 < 체결강도 <= 138.55` (설계 거래의 50.0%) |
| 설계 건당 | −5,702.81 (전체 −5,341.23 보다 나쁨 ✅) |
| **홀드아웃 건당** | **−4,792.57 (전체 −4,843.11 보다 좋음 ❌)** |
| 판정 | **`confirmed = False` · `holdout_not_bad`** |

**해석**: 체결강도 중간 밴드의 열위는 2022~2024 구간에서는 성립했지만 최신 2년 홀드아웃
(2025-08~2026-02)에서는 사라졌다. 게이트가 정상 작동해 후보에서 배제했다.

**조치**: 설계서 §2.3a 의 "+682원" 을 v2 기준 실적으로 오해하지 않도록 §10 기대치를
재산정해야 한다(G-1 기준선 확보 후). 형태 판정 순서 수정 자체는 여전히 옳다 —
multi_band 판정 수가 5 → 13 으로 늘었고, 그 13건 중 4건이 `confirmed` 다.

### 4.2 핸드오프 검증 기준선 "146 passed" 가 틀렸다

핸드오프 §1.2·§5 에 적힌 집중 테스트 명령을 그대로 실행하면 **1,023 passed** 다(6분 28초).
"146" 이 어디서 나온 수치인지 확인되지 않는다. 회귀 판정 기준선을 **1,023 → (G-0a 후) 1,050**
으로 정정한다.

## 5. 🐛 실데이터가 잡아낸 결함 4건 (합성 테스트는 통과했었다)

합성 곡선 21건은 첫 실행에서 전부 통과했지만, 실데이터를 넣자 결함 4건이 드러났다.
**단위 테스트만으로는 부족했다**는 기록으로 남긴다.

| # | 결함 | 증상 | 수정 |
|---:|---|---|---|
| 1 | 다중 밴드 분리 판정이 과했다 | 체결강도가 `flat` 으로 떨어짐 — 설계서 예측과 정반대 | 스프레드 대비 마진 규칙 제거, 설계서 §4.1 문구대로 "비연속 2구간 + 제거 가능한 연속 구간 1개 이상" |
| 2 | 형태 폴백이 손실 구간을 버렸다 | 형태 이름을 못 붙이면 `worst_span=None` — **거래 34%를 담은 D4~D8 연속 손실 구간이 통째로 소실** | 형태가 아니라 **구간 존재 여부**로 분기 |
| 3 | 2D 포켓이 FDR 이후에 병합됐다 | 30칸 포켓이 유의한 칸 2개만으로 통과, `max q = 0.985` 로 보고 | **FDR → 통과 칸만 → 연결 성분** 순서로 변경. 재실행 후 전 포켓 `q ≤ 0.090` |
| 4 | 파생 `시분초` 가 `B_시분초` 와 중복 | 같은 축이 두 번 계산·두 번 노출 | 원열이 있으면 파생을 만들지 않음 |

수정 후 결함 4건 각각에 회귀 테스트를 추가했다(27건 중 6건이 이 목적).
