## 2. 무엇이 부족하고 무엇으로 극복하나 — 한 장 요약

```
부족한 것                          극복 수단                            웨이브
──────────────────────────────────────────────────────────────────────────
안정된 뇌                       →  Claude 직접 수행 + GPT OAuth 백업     W0✓·W1
논리 있는 조건식 생성            →  p5 프롬프트(구조 가설·단일 변경) 배선  W1
부검→수정의 자동 인과 귀속       →  분석 카드 → Claude 판독 → 1절 수정    W1
루프 안의 진실 판정              →  워크포워드 게이트 + 가설 원장 예산     W2
매도 축 표현력                  →  봉투 기반 청산 평가기 (재현 게이트)     W3
숫자 과최적                    →  OptimizeConditions/GA + 응답면 고원    W3

시간이 지나도 썩는 후보          →  백필 + 상설 재검증 + 소액 실전         W5
```

## 3. 전체 웨이브

### W1 — 뇌 배선 (자율 루프의 심장, 1세션)

| 작업 | 내용 | 완료 기준 |
|---|---|---|
| Claude-direct provider 정식화 | `claude_candidate_batch_eval` 경로를 provider 계약으로 승격 — Claude(CLI 세션)가 생성·판독 담당 | 루프가 Claude 산출물로 1세대 완주 |
| p5 프롬프트 배선 | 구조 가설 템플릿 + 단일 변경 변이(부검 숫자 {autopsy_summary} 주입) — 기본 ON | 생성물에 절별 이유 주석 존재 |
| 분석 카드 → Claude 판독 | 카드(root_cause·mutation_axis)를 Claude 가 읽고 수정 1절 결정 — **사람 검토 아님** | 카드→수정 결정 로그 |
| GPT OAuth 백업 체인 | failover: Claude → gpt_auth(이식 완료) → codex_proxy | 백업 경로 스모크 |

### W2 — 심판 규율 (과적합 축적 차단, 1세션)

| 작업 | 내용 | 완료 기준 |
|---|---|---|
| 루프 내 워크포워드 | hypothesis 채택/기각을 `walkforward.py` 폴드 델타로 — holdout 재사용 금지 | WF 판정 로그 |
| 가설 원장 예산 | 아이디어당 수정 상한(~15회) 원장 강제 — 초과 시 폐기 기록 | 원장 파일 |
| 판정 차감 | 성적 판독에 선택 편의 0.62%p 차감 규칙 내장 | 리포트 표기 |

### W3 — STOM 자산 편입 (재료·숫자·매도축, 1~2세션)

| 작업 | 내용 | 완료 기준 |
|---|---|---|
| 백파인더 시드 | `backfinder_principle` 채굴 결과를 구조 가설 프롬프트의 시드 재료로 | 시드→조건식 초안 1건 |
| 숫자 보정 | 구조 고정 후 `OptimizeConditions`/GA 값 스윕 + 3D 응답면 고원 검사 (스윕 수 원장 기록) | 응답면 리포트 |
| **매도축 평가기** | 봉투(30초~10분) 기반 청산 규칙군 평가 — **재현 게이트: 챔피언 902/905 엔진 성적(+3,479원/건) 부호·크기 재현 전 탐색 금지** | 재현 게이트 통과 |

### W4 — 자율 루프 가동 (첫 시료, 1~2세션)

| 시료 | 근거 |
|---|---|
| ① "첫 5분 소수 종목" **풀 디테일** 조건식 (매수 5~7절 + 매도 규칙군) | 사용자 아이디어의 공정한 시험 — 108셀은 뼈대만 봤음 |
| ② 챔피언 902/905 매도축 개선 (±1절) | 유일 실증 양성 경로(B1) × 수익원 실측 |

흐름: `시드 → Claude 조건식 → 엔진 → 부검 카드 → Claude 1절 수정(원장) → 재엔진 → … → WF 게이트 → 통과분만 사람 보고` — **끝까지 사람 개입 없음**.

### W5 — 상설화 (상시)

| 작업 | 내용 |
|---|---|
| 데이터 백필 | 신규 거래일 자동 편입 → 라벨 증분 빌드 |

## 5. 규율 (전 웨이브 공통 헌법)

1. 사람 게이트는 **실전 투입 1곳** — 루프 내부 검토는 Claude 가 수행.
2. 격자·수정은 실행 전 원장에 고정, 전량 보고. 성적은 편의 0.62%p 차감 후 판독.
3. 홀드아웃 재개봉 금지 — 판정은 워크포워드.
4. 지도/부검 수치는 반드시 엔진 실측·전이율 기록을 거친다.
5. 백파인더 채굴 등 in-sample 재료는 **시드 전용** (심판 금지).
6. 실패 전량 기록 · 정정 문서 규칙 유지.
