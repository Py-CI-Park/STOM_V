## 6. ⬅ 다음 — HOF3 의 원래 설계는 무효다

상세실행계획 §3 의 HOF3 은 "**HOF2 생존 절의 문턱을 최적화**"였다.
**생존 절이 0 이므로 그대로는 실행할 수 없다.** 여기서 후보를 억지로 살려
최적화로 넘기면 그것이 정확히 지난 10라운드의 실패 방식이다.

### 6.1 살아 있는 가설 — 아직 검정되지 않았다

사용자 가설("사람은 09:00~09:20 을 밴드별 조건으로 쓴다")은 **반증되지 않았다.**
우리가 반증한 것은 **"밴드 2 의 절을 15분 더 늘려 쓰기"** 뿐이다.
**밴드 3 전용 절 집합은 한 번도 시험되지 않았다.**

### 6.2 권고 — HOF3 재설계 (사전 등록 문서로 별도 제출)

| 항목 | 내용 |
|---|---|
| 가설 | 09:05~09:20 에는 **그 시간대 전용 문턱**이 필요하다 |
| 방법 | 밴드 1→2 문턱 이동 방향을 **외삽**해 밴드 3 문턱을 만든다(이론 주도 · 무작위 탐색 아님) |
| 예산 | **≤ 6 셀** 사전 등록(헌법 15항 · 예산 100/300 을 다 쓰지 않는다) |
| 판정 | 학습 구간 1차 → 상위 ≤2 만 검증 구간 → 확인 구간은 예약 |
| 비용 | 셀당 엔진 약 13분 → 총 1.5시간 |
