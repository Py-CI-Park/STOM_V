**사전 등록을 하나로 묶는다.** 가설 예산·게이트는 v3 대로 유지한다.

**시총이 작을수록·시각이 이를수록 승자 비율이 높다** — 단조 구조가 뚜렷하다.

### 1.1 ★ 조립 전에 확인한 것 — 승자 IQR 밴드는 판별력이 없다

G1 시드는 **승자의 분위**다. 그 밴드가 승자를 골라내는지 학습 구간 21일 표본으로 쟀다:

| 변형 | 09:00~09:05 잔존 | 전방 `trail_5_2` 평균 | ≥5% 비율 |
|---|---:|---:|---:|
| **V3 세그먼트만**(초소형) | 24,490 | **+0.262%** | 11.82% |
| V2 하한만(≥q25) | 10,928 (44.6%) | −0.115% | 12.14% |
| V1 전밴드(q25~q75) | 1,233 (5.0%) | −0.005% | 11.27% |

**밴드를 씌울수록 나아지지 않는다.** G1 의 lift 는 **세그먼트(초소형×이른 시각)** 에서
왔지 피처 밴드에서 오지 않았다. 이것이 "승자 분포로 조건을 만들면 된다"는
순진한 가정에 대한 이 라운드의 첫 반증이다.

> ⚠️ 이 표는 **조립 가능성 점검**이지 판정이 아니다(학습 구간·전방 라벨).
> 그래서 세 변형을 **전부** 엔진에 올려 사전 등록 게이트로 판정한다.

## 2. 가설 (반대 가설 포함)

**가설**: 초소형(시총<1000)의 이른 시각 진입은 챔피언과 **다른 골격**의 우위를 갖는다.
챔피언은 `시가총액 < 3000` 안에서 17절로 좁게 고르지만, G1 은 **시총만으로도**
승자 비율이 5.19배인 영역을 지목했다. 최소 골격(세그먼트+안전절)이 엔진에서 흑자면
새 계열의 출발점이 된다.

**반대 가설**: 전방 라벨의 lift 는 **비용·체결·보유 제약을 무시**한 것이라,
엔진에 올리면 초소형의 스프레드·슬리피지·거래 불가가 우위를 전부 먹는다.
그렇다면 "lookahead 채굴로는 실행 가능한 골격을 만들 수 없다"가 확정된다.

## 4. 조립 — 격자 3셀 고정 (가설 예산 · 헌법 15항)

세 변형 모두 **동일한 3-시간밴드 구조**(09:00~05 / 09:05~10 / 09:10~15)와
**동일한 안전절**을 쓰고, 피처 밴드만 다르다.

```
안전절(전 변형 공통 · 실행 가능성 확보용이지 전략이 아님)
  관심종목 == 1 · 1000 < 현재가 · 현재가 < VI아래5호가 · not 라운드피겨위5호가이내
세그먼트  시가총액 < 1000 (초소형)
시간밴드  90000~90500 / 90500~91000 / 91000~91500
```

| 셀 | 피처 밴드 | 이름 |
|---|---|---|
| **V3** | 없음 (세그먼트+안전절만) | `G2_B_SEG_ONLY` |
| **V2** | 밴드별 `피처 >= q25` (하한만) | `G2_B_LOWER` |
| **V1** | 밴드별 `q25 <= 피처 < q75` (모듈 규약) | `G2_B_IQR` |

피처 6종: 등락율·체결강도·당일거래대금·회전율·초당거래대금·고저평균대비등락율
(시분초는 시간분기로 이미 쓰였고, 시가총액은 세그먼트로 쓰였다 — 중복 배제)

**매도식 = 챔피언 매도 `Tick_S_902_905` 고정** (헌법 7항 · 점검보고서 누락② 반영).

## 5. G3 관찰 (판정 전 필수)

각 변형이 **실제로 사는 종목의 궤적 차트**를 변형당 ≥6건(층화) 확인한다.
채굴이 통계 허깨비를 쫓는지 눈으로 차단하는 단계다. 관찰 결과는 결과 문서에 서술로 남긴다.
**관찰로 후보를 고르지 않는다** — 판정은 §6 게이트다.

## 6. ★ 게이트 — 실행 전 고정

**1차 = 학습 구간(411일).** 판정 기준은 **절대 흑자 + 챔피언 대비**다.

| # | 조건 | 필수 |
|---:|---|:---:|
| A | 총수익금 **> 0** (헌법 12항 절대 조건) | ✅ |
| B | 총수익금 ≥ 챔피언 학습 실측(**1,316,746원**) | ✅ |
| C | 거래 수 ≥ 30 (표본 하한) | ✅ |
| D | 필요자금 ≤ 2,000만원 | ✅ |
| E | 건당 · MDD | 참고 |

**2차 = 검증 구간(203일).** 1차 통과 상위 ≤2 셀만. 같은 게이트(B 는 검증 챔피언 실측 637,513원).

### 판정 규칙 (미리 정한다)

| 결과 | 다음 |
|---|---|
| 1·2차 모두 통과 | 원장 `PROMISING`(진입 계열 상한) + **사람 보고**. 확인 구간(208일)은 예약 |
| 1차 통과·2차 실패 | `REJECT` — "학습 전용" 기록, 생성 레인의 재료를 바꾼다 |
| 1차 전멸(A 실패) | `REJECT` — **반대 가설 성립**: lookahead 채굴로는 실행 가능 골격 불가. 등록부 등재 후 G-min 이전에 재료 재검토 |
| 엔진 타임아웃 | 조건이 너무 넓음 — 그 자체를 결과로 기록(사후 완화 금지) |

## 7. 예상 (사후 대조용)

| 항목 | 예상 |
|---|---|
| 거래 수 | 셀당 800~2,500 (보유 ~300초 × 3밴드 900초 × 411일) |
| 1차 통과 | 0~1셀 (V3 가 가장 유력 — §1.1 근거) |
| 소요 | 셀당 15~40분 · 총 1~2시간 |
| 필요자금 | 200~600만원 (동시보유 증가 예상) |

**정직한 사전 전망**: 초소형은 스프레드·슬리피지가 크고 챔피언의 정교한 절이 없으므로
**1차에서 A(흑자)조차 실패할 가능성이 상당하다.** 그래도 돌리는 이유는 G1 의 lift 5.19 가
실행 가능성 앞에서 얼마나 남는지가 **생성 레인 전체의 값어치를 결정**하기 때문이다.
