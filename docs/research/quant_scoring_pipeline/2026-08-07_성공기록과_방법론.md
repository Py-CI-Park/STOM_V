## 2. 📐 통한 방법 — 다음 라운드가 그대로 쓸 것

### 방법 1. **진입 고정 A/B** (가장 큰 효과)

두 팔이 **같은 진입**을 쓰게 하고 매도만 바꾼다.

| 왜 | 효과 |
|---|---|
| 차이가 매도에서 온 것임이 분명해진다 | 해석 모호성 제거 |
| 거래를 1:1 로 **짝지을 수 있다** | 필요 표본 1,421건 → **475건 (3배 효율)** |

> 비유 — 같은 밭 같은 씨앗에 비료만 다르게 준다. 밭이 달라지면 비료 효과를
> 알 수 없다.

### 방법 2. **합격선은 챔피언이다** (절대 기준 금지)

| 하지 말 것 | 할 것 |
|---|---|
| "국면 4/4 양수" 같은 절대 기준 | 챔피언을 같은 기준에 대 보고 그 값을 합격선으로 |
| 기준을 만든 뒤 후보만 재기 | **기준을 만들면 먼저 챔피언으로 교정** |

**챔피언이 떨어지는 기준은 후보가 아니라 기준이 틀린 것이다.**

### 방법 3. **심판은 엔진 체결 기록** (지도는 탐색용)

지도는 챔피언 진입 344건을 전부 세지만 엔진은 자본 한도로 155~161건만 체결한다.
지도가 세는 187건은 **엔진이 사지도 않는 거래**다.

| 축 | trailing(5/2) 국면 양수 |
|---|---|
| 지도 | 2/4 → 오판 |
| **엔진 실거래** | **4/4** |

### 방법 4. **자본을 밝힌다** (총액 비교 금지)

| 지표 | 챔피언 | B3 | 우세 |
|---|---:|---:|---|
| 총수익금 | 805,166원 | 1,422,175원 | B3 |
| **필요자금** | **1,004,275원** | **1,998,220원** | **챔피언** |
| 총수익률 | **80.17%** | 71.17% | 챔피언 |
| CAGR | **56.30%** | 49.98% | 챔피언 |
| MDD | 14.82% | **10.48%** | B3 |
| Calmar | 3.80 | **4.77** | B3 |

**총수익금만 보면 자본을 더 쓴 쪽이 항상 이긴다.** B3 의 "1.77배"는 자본 2배를
빼먹은 비교였다 — 철회한다.

### 방법 5. **불확실하면 불확실하다고 말한다**

판정을 세 갈래로 나눈다.

| 판정 | 뜻 |
|---|---|
| **PASS** | 챔피언 이상 + 통계적으로 확정 → 사람 보고 |
| **PROMISING** | 챔피언 이상이나 표본 부족 → 표본 늘려 재판정 |
| **REJECT** | 챔피언 미달 → 폐기 |

현재 B1·B2·B3 는 전부 **PROMISING** 이다.

### 방법 6. **후보를 줄이면 편의가 준다** (실측)

| 후보 수 | 표본 밖 | 편의(간극) |
|---:|---:|---:|
| 28셀 | +0.1506% | +0.1805%p |
| 58셀 | +0.0886% | +0.3424%p |
| 변화 | **−41%** | **×1.90** |

## 3. 🔴 왜 "계속 실패"처럼 보였나 — 구조적 원인

### 3.1 표본이 근본적으로 모자란다

```
하루 1.39건 × 거래일 116일 = 161건
두 전략의 우열을 가리려면(짝지은 검정, 검정력 80%) → 475건
                                              → 3.1배 부족
짝짓지 않으면                                  → 1,421건 (8.8배)
```

**355일 데이터로는 "A가 B보다 낫다"를 증명할 수 없는 구조다.**
QSP1~13 이 반복해서 "표본 밖에서 뒤집혔다"고 한 것도 같은 뿌리다.

### 3.2 그런데 데이터는 이미 있다

`standing.backfill_plan` 실측:

| 항목 | 값 |
|---|---:|
| DB 보유 거래일 | **952일** |
| 라벨 생성분 | 355일 |
| **결손** | **597일** (설계 478 + 홀드아웃 119 🔒) |

**라벨만 만들면 표본이 2.3배가 된다** (155건 → 약 416건). 필요 475건에 근접한다.

## 4. ➡ 더 성공한 조건식을 만드는 방법 (우선순위)

| 순위 | 방법 | 기대 효과 | 비용 |
|---:|---|---|---|
| **1** | **설계 구간 라벨 백필** (478일) | 표본 155 → 약 416건 · 확정 가능선 도달 | 라벨 빌드 약 70분 |
| **2** | **거래 빈도를 올리는 진입 연구** | 하루 1.39 → 3건이면 표본 2배 | 진입 조건 완화 실험 |
| **3** | 짝지은 설계를 **표준 절차로** 고정 | 필요 표본 1/3 | 이미 구현됨 |
| **4** | 분산을 줄이는 청산 | B3 σ=4.62 > 챔피언 3.23 · σ 줄이면 필요 표본 급감 | 청산 규칙 연구 |
| **5** | 적응형 청산 (국면별 arm/give) | 국면 4·구간 편차 축소 | 신규 연구 |
| **6** | 홀드아웃 개봉 (119일) | 최종 판정 | **사람 결정 · 1회성** |

### 4.1 표본을 늘리는 것이 왜 1순위인가

지금 상태에서 아무리 좋은 조건식을 만들어도 **"좋다"고 증명할 수 없다.**
증명할 수 없으면 실전에 올릴 수 없고, 실전에 못 올리면 연구가 끝나지 않는다.
**측정 가능성이 성능보다 먼저다.**

### 4.2 하지 말아야 할 것

| 금지 | 이유 |
|---|---|
| 후보를 늘려 더 좋은 셀 찾기 | 후보 2배 → 편의 1.9배 (실측) |
| 나쁜 구간 제외 후 재측정 | 무엇이든 좋아진다 |
| 지도 수치만으로 판정 | 엔진이 심판이다 |
| 총수익금만으로 비교 | 자본을 더 쓴 쪽이 항상 이긴다 |
| 유의하지 않은 우위를 우위라고 보고 | 이번 라운드에 실제로 저지른 오류 |
