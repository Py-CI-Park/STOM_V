## 4. 🔬 왜 여전히 MIXED 인가 — 자본 회전 하나뿐이다

```
B3 총수익금 3,706,986원  =  챔피언의 1.53배   ← 이겼다
B3 필요자금 1,996,660원  =  챔피언의 1.99배   ← 여기서 진다
                              ↓
        총수익률 185.66%  vs  241.16%
```

원인 사슬은 실측으로 닫혀 있다.

```
되돌림 2%p 로 늦게 팔린다  →  평균 보유 464 → 540초  →  09:0X 진입이 겹친다
   →  최대동시보유 1 → 2   →  필요자금 2배   →  총수익률 −55%p
```

**건당 우위(+0.3582%p)는 확정됐고, 남은 결함은 보유시간 하나다.**
이것이 단계 3(자본 회전 교정)이 정확히 겨냥하는 지점이다.
