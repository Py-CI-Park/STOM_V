# QSP9 — 맵 퍼스트(지도 우선) 연구 방법론: 전문가라면 이렇게 한다

> 작성일: 2026-08-04 · 성격: **프로그램 정본** — [QSP8-R 계획](./2026-08-04_qsp8r_손익비우선_넓은시간_계획.md)의
> Phase 체계를 흡수·대체한다 (S-0/S-1→M-4, T→M-3, W→M-1).
> 계기: 사용자 질문 — *"DB·백테스트·조건식 언어가 다 있다면, 돈을 벌고 싶은 퀀트 전문가로서
> 좋은 조건식을 어떻게 연구·개발하겠는가?"*
> ⚠️ **Phase B(명예의 전당 벤치마크) 철회** — HOF에는 스크린샷만 있고 조건식이 없다.
> 목표 수치는 스크린샷 판독으로만 정하고, 조건식 복원은 시도하지 않는다.
> 안전 경계: 운영 DB 쓰기·실거래 반영·전체청산 이후 시세·홀드아웃 재학습·후보 자동 채택 금지

## 0. 🧭 결론 먼저 — 전문가의 답

**조건식을 탐색하지 않는다. 돈이 실제로 있던 자리의 지도를 먼저 만들고,
조건식은 그 지도를 문법으로 옮겨 적는 마지막 단계다.**

| 아마추어의 순서 | 전문가의 순서 |
|---|---|
| 조건식을 만들고 → 백테스트로 확인 | **시장을 라벨링하고 → 현상을 찾고 → 조건식으로 인코딩하고 → 백테스트는 검증만** |
| 어떤 전략의 체결 거래에서 배운다 (선택 편향) | **전 종목 × 전 시점의 앞으로 수익률(forward return)에서 배운다** |
| 백테스트 = 탐색 도구 (수백 회) | 백테스트 = **최종 시험** (라운드당 3~5회) |

QSP1~7의 구조적 한계가 바로 이것이었다: **어떤 기준선이 체결한 거래에서만 배웠다.**
기준선이 나쁘면(와이드 그물) 배울 재료도 나쁘다. 라벨 기반으로 바꾸면 기준선 의존이
사라지고, 사용자가 원한 **"넓은 발굴"**이 구조적으로 가능해진다.

## 1. 📐 제1원칙 — 라벨 먼저, 조건식 나중

### 1.1 라벨(정답지) 정의

tick DB(09:00~09:30, 1초 스냅샷, 수집 종목 한정)에서:

```
모든 (종목, 거래일, 초 t)  —  t ∈ 09:00:00 ~ 09:20:00 (사용자 지정: 20분까지만 매수)
라벨 fr(t, h) = (P(t+h) − P(t)) / P(t) − 왕복비용(0.21%)
h ∈ {30초, 60초, 120초, 300초, 09:28 종료가까지}
```

- **조건식 0개, 엔진 0회**로 만든다 — 순수 데이터 가공(일 단위 parquet, 설계 구간만)
- 실현가능성 필터: 유동성 하한(초당거래대금)·상한가/VI 근접 제외·스프레드
- 이 라벨 위에서 "**어느 시점·어느 상태가 비용 차감 후 +였나**"를 지도로 그린다

### 1.2 왜 이것이 결정적인가

| 문제 | 거래 기반(QSP1~7) | 라벨 기반(QSP9) |
|---|---|---|
| 선택 편향 | 기준선이 산 것만 보임 | **안 산 자리의 기회도 보임** |
| 발굴 폭 | 기준선 근방 국소 | **전 상태 공간** |
| 백테스트 소모 | 후보마다 1런(10분) | 지도는 0런, 최종 후보만 실측 |
| 매도 연구 | 실현 손익에 매도가 얽힘 | **진입 품질(MFE 원천)과 분리** |

## 2. 🔬 실물 해부 — 사용자 902/905는 이미 전문가 문법이다

strategy DB(read-only)에서 확보한 실코드. **좋은 조건식의 조립 문법이 그대로 들어 있다.**

### 2.1 매수식 구조 (`Tick_B_902_905_Study_2`)

```python
# 파생 지표를 먼저 정의한다 (재사용)
전일종가       = 현재가 / (1 + (등락율 / 100))
시가등락율     = ((시가 - 전일종가) / 전일종가) * 100
시가대비등락율 = ((현재가 - 시가) / 시가) * 100
초당순매수금액 = (초당매수수량 - 초당매도수량) * 현재가 / 1_000_000

VI아래5호가 = VI가격 - VI호가단위 * 5
매수 = True
if not (관심종목 == 1): 매수 = False          # ① 유니버스 게이트
elif 시분초 < 90200:                           # ② 시간창 분기 (902 전략)
    ...품질 필터: 1000<현재가<=50000 · 1.0<등락율<=8.0 · VI아래5호가 · 라운드피겨 제외
    if 시가총액 < 3000:                        # ③ 국면 게이트 (소형주)
        ...신호: 초당거래대금/초당거래대금평균(30) > 3.0   ← 수급 서지
        ...신호: 초당매수수량 > 매도총잔량 * 0.20          ← 수요 압력
        ...맥락: 현재가 > 고가 - (고가-저가)*0.20          ← 고가 근접(눌림 20% 이내)
        ...밴드: 체결강도 50~300 · 당일거래대금각도(30) 5~30
elif 90200 <= 시분초 < 90500:                  # ② 시간창 분기 (905 전략, 임계 재조정)
    ...같은 골격, 다른 임계 (등락율<=15.0, 시가대비등락율 3~8, 서지 배율 2.0, ...)
else: 매수 = False                             # 09:05 이후 진입 금지
if 매수: self.Buy()
```

### 2.2 조립 문법 (이 문서의 핵심 재사용 자산)

| 층 | 역할 | 902/905의 실례 |
|---|---|---|
| **파생 지표** | 원시 변수 조합을 이름 붙여 재사용 | 시가등락율·시가대비등락율·초당순매수금액 |
| **① 유니버스** | 대상 한정 | 관심종목·가격 밴드·시가총액 |
| **② 시간창** | 시초 국면별 분기, **창마다 임계가 다름** | 902 창 vs 905 창 (서지 배율 3.0→2.0) |
| **③ 국면 게이트** | 종목 유형별 다른 논리 | 시가총액 < 3000 |
| **④ 신호** | 진입 트리거 (수급 서지) | 초당거래대금 배율·초당매수수량 vs 잔량 |
| **⑤ 품질 필터** | 시초 고유 리스크 차단 | VI 5호가·라운드피겨·상한가 근접 |
| **⑥ 밴드** | 과열/침체 양쪽 컷 | 체결강도 50~300·각도 5~30 |

### 2.3 매도식 구조 (`Tick_S_902_905_Study`) — 8규칙

익절(수익률≥5·최고수익률 트레일링 0.6배)·수급 반전 매도(등락율각도 구간별 잔량 압력)·
이평 이탈 — **살아있는 매도**다. 단, 손실 2규칙(`최저현재가` 신저가 컷)이 손실 전부를
만든다는 실측은 [근본 진단 §9.2](./2026-08-04_qsp7_근본진단_왜_수익이_안나는가.md) 참조.

## 3. 🗺️ QSP9 프로그램 — M-0 ~ M-6

```
M-0 라벨 공장 → M-1 시초 지형도 → M-2 변수 정보력 → M-3 조건식 조립 → M-4 매도 설계 → M-5 검증 사다리 → M-6 공장화
(엔진 0회)      (엔진 0회)         (엔진 0회)          (엔진 3~5회)      (리플레이+엔진)     (엔진 2~3회)      (라운드 반복)
```

### M-0. 라벨 공장 (진입 지도의 원료)

| 항목 | 내용 |
|---|---|
| 입력 | tick DB 설계 구간(20240304~20250822), 일 단위 처리 |
| 출력 | 일별 parquet: (종목, 초) × {fr_30·fr_60·fr_120·fr_300·fr_close, 스냅샷 변수 전부} |
| 필터 | 초당거래대금 하한·상한가/VI 근접 제외 — **실현 불가능한 라벨은 처음부터 오염원** |
| 봉인 | **홀드아웃(20250825~) tick 은 M-5 전까지 열지 않는다** |

### M-1. 시초 30분 지형도 (사용자 강조: "시초의 특성을 잘 연구")

분 단위 미시구조 프로파일 — **왜 902/905(09:02~05)가 작동했는지를 시장 구조로 설명**한다.

| 구간(가설) | 측정 |
|---|---|
| 09:00~01 시가 결정 직후 | 스프레드·갭 방향 지속률 |
| 09:01~05 갭 해소 드라이브 | 모멘텀 유효성(수익률 자기상관 +) |
| 09:05~10 첫 눌림 | 반전 vs 지속 분기 조건 |
| 09:10~20 지속/소멸 | 추세 잔존 엣지 |
| 09:20~28 | **신규 진입 금지** — 청산 전용 (전체청산 092800) |

산출: 분×상태 격자의 E[fr] 지도. **다른 시간대에 다른 유형의 엣지**가 있으면 여기서 드러난다.

### M-2. 변수 정보력 순위

- DSL 변수 전수(체결강도·초당거래대금·등락율각도·잔량비·회전율·전일비·…)를 라벨 대비
  10분위 분석 — 단조성·분위 스프레드·**BH-FDR q≤0.10**
- 2D 조합: `loss_profile.py`의 2D 포켓 엔진을 **이익 포켓 탐색으로 부호 반전 재사용**
- 산출: 변수·조합 랭킹표 + 각 상위 항목의 "돈이 있던 분위 구간"

### M-3. 조건식 조립 (§2.2 문법으로 인코딩)

- 시간창(M-1) × 국면 게이트 × 신호(M-2 상위) × 품질 필터(902/905 검증 관행 이식)
- 임계는 **분위 격자 위에서만** · 목표 **MFE/MAE ≥ 1.3** · 설계 ≥ 2,000건
- 후보 5~10개 작성 → **여기서 처음 엔진**(16, 후보당 1런 ≈10분)

### M-4. 매도 설계 (손익비 확정) — QSP8-R S-0/S-1 흡수

- 새 진입 집합의 경로에서 `exit_counterfactual.py`(트레일링 `giveback_pct`·시간단계·MFE-armed) 리플레이
- 승률대가 40%대면 손익비 1.5+ 를 유형 정합 목표로
- 902/905 건강 6규칙 구조 이식, 손실 2규칙(신저가 컷) 구조는 반면교사

### M-5. 검증 사다리 (전부 통과해야 승인 요청)

| # | 검사 | 기준 |
|---:|---|---|
| 1 | 설계/홀드아웃 (v2, 경계 20250825) | 양쪽 건당 + 손익비 개선 |
| 2 | **임계 고원** | 이웃 분위 임계도 흑자 — 절벽이면 과최적 |

### M-6. 공장화 (라운드 루프)

라운드마다: 지도 갱신 → 후보 → 실측 → 원장 기록. **AI가 격자·라벨 노동, 사람이 현상의

## 4. 📊 현실적 기대치 (전문가의 정직)

| 항목 | 현실적 범위 | 근거 |
|---|---|---|
| 건당 순엣지 | **+0.1~0.3%** (진입 100만원 기준 +1,000~3,000원) | 왕복 0.21% 비용·시초 변동성 |
| 승률 × 손익비 | 40~55% × 1.2~1.8 | 902/905 실측(48.9%×1.355)이 이 영역 |
| 빈도 목표 | **하루 10~30건** | 182건/일(그물)과 0.4건/일(902/905)의 사이 |
| 연 수익 규모 | 하루 20건 × +1,500원 ≈ **연 +750만원/시드 100만** | 산수 — 시드·동시보유 확대는 별도 단계 |

건당 +5,000원짜리 마법 조건식을 찾는 게 아니라, **+1,000~2,000원짜리 견고한 엣지를
빈도로 쌓는 것**이 시초 단타의 현실적 승부다.

## 7. 📥 피드백 반영 보강 (2026-08-05)

### 7.1 용어 표준화 — "순엣지" 폐기

| 폐기 | 표준 용어 | 뜻 |
|---|---|---|
| 순엣지 | **건당 실수익률(%)** / **건당 실수익(원)** | 수수료·세금·슬리피지 다 뺀 뒤 **거래 1건당 평균적으로 남는 것** |

902/905 실측 = 건당 실수익 +3,479원, 진입 평균 ~99만원 → **건당 실수익률 +0.35%**.
"0.1~0.3%는 작다"는 인상은 자연스럽지만, **사용자 자신의 흑자 전략이 정확히 이 범위**이고
그것이 CAGR +33%를 만들었다. 단타 수익 = 건당 실수익률 × **하루 회전수** — 회전이 곱해진다.

| 건당 실수익률 | 하루 회전 | 일 수익률(시드 대비) | 비고 |
|---:|---:|---:|---|
| +0.35% | 0.4회 | +0.14% | 902/905 실측 (연 +33%) |
| +0.30% | 10회 | **+3.0%** | 목표 영역 — 복리 시 연 수백% (체결 용량 한계 전 이론치) |
| +0.30% | 20회 | +6.0% | 상한 시나리오 — 슬리피지 증가로 실현 곤란 가능 |

### 7.2 3D·4D·ND 지도 — 한다. 단, 정면 격자가 아니라 **계층 + 트리**로

표본 밀도가 차원을 결정한다 (10분위 격자 기준):

| 차원 | 칸 수 | 거래 기반(86,390) | 라벨 기반(수백만~수천만 점) |
|---|---:|---|---|
| 2D | 100 | 칸당 ~864 ✅ | 풍부 ✅ |
| 3D | 1,000 | 칸당 ~86 ⚠️ | 가능 ✅ (5분위면 125칸으로 여유) |
| 4D | 10,000 | 칸당 ~8.6 ❌ 잡음 | 조건부만 ⚠️ |
| ND 정면 격자 | 10^N | ❌ | ❌ 차원의 저주 |

전문가의 ND 방식 (M-2 에 통합):

| # | 방법 | 내용 |
|---:|---|---|
| 1 | **계층 탐색** | 1D 랭킹 → 2D 포켓 확정 → **확정된 포켓 안에서만** 3번째 변수 스캔(조건부 3D) → 필요시 4번째. 전역 4D 격자를 그리는 전문가는 없다 |
| 2 | **얕은 결정트리(깊이 3~4) = ND 지도이자 조건식** | 트리 경로 = `A>x and B<y and C>z` — **그대로 STOM DSL 절**. ND 구조를 찾으면서 해석·인코딩 가능. 임계는 트리 제안 후 분위 격자로 스냅 |
| 3 | 시각화는 **파셋 히트맵** | 사람용 3D = 3D 서피스가 아니라 **3번째 변수 3분할별 2D 히트맵 3장 나란히**(실무 표준). 4D = 행×열 파셋. UI 페이지 22 후보 "지형도(파셋)" |

금지: random forest/GBM/딥러닝을 **최종 산출물**로 쓰는 것 — 조건식으로 번역 불가능한
블랙박스는 이 시스템에서 무가치(랭킹 보조로만 허용).

### 7.3 행렬·다차원 연산 — 도움 되는 곳 3곳, 안 되는 곳 1곳

| 적용처 | 내용 | 판정 |
|---|---|---|
| **벡터화** | M-0 라벨 공장의 심장 — 수천만 (종목,초)×horizon forward return 을 루프가 아니라 numpy 행렬로 | ✅ 필수 |
| **상관행렬** | 변수 전수 랭킹 전 상관 클러스터링(\|r\|<0.6 규칙 확장)으로 대표 변수만 — FDR 예산 절약 | ✅ |
| PCA/직교화 | 수급 변수군을 소수 팩터로 요약 — 단 팩터는 DSL 로 못 옮기므로 **탐색 나침반으로만** | ⚠️ 보조 |
| 행렬분해·딥러닝 | 조건식으로 번역 불가 | ❌ |

### 7.4 손익비 우선 — "이익 길게, 손절 빠르게"의 데이터 검증

방향은 정확히 맞다 (M-4 설계 목표 그대로). 단, 실측이 주는 경고 — **"빠른 손절"은
지금까지 역효과였다**:

| 실측 | 수치 |
|---|---|
| 손절 5,654건의 MAE 평균 | −2.00% = 실현 −2.00% → **바닥에서 잘림** |
| 손절 거래의 MFE 평균 | +0.69% — 잘리기 전 이익 구간이 있었다 |
| 902/905 신저가 컷 2규칙 | 59건 · **−1,520,591원 = 손실 전부** |
| 902/905 트레일링(최고수익률×0.6) | 건당 **+34,842원** — 8규칙 중 2위 |

그래서 "빠르게"가 아니라 **"체계적으로"** (M-4 문법):

| # | 원칙 | 구현 |
|---:|---|---|
| 1 | 시간단계 손절 | 시초 1~2분은 변동성 커서 **넓게**, 이후 좁게 |
| 2 | 상태 조건부 손절 | 가격 신저가만으로 자르지 않는다 — **수급 반전 증거 동반 시만** |
| 3 | MFE-armed 트레일링 | 최고수익률 도달 후 x% 반납 시 청산 — 902/905의 `최고수익률×0.6` 이 이미 이 구조 |
