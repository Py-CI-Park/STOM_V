# SYS05 B4b 원본 피처 품질 실행계획

부모5f1e7ca901845a0dc396fec56e6d7c057f5b6f20. branch codex/process-research-sys-05-feature-quality.
B4a 전체 Gate는 integration worktree에서 고정 HEAD로 실행 중이며, 본 branch는 별도로 개발한다.

1. leaf_matrix/feature_map/revision_proposals 직접 API에 불량 CSV·실행실패·누락의 계산 및 전략 조회 차단 red를 추가한다.
2. CsvSnapshot headers/rows를 csv.writer/StringIO로 전달하고 기존 label_dataset.load_csv/enrich를 재사용한다. dtype/NA/quoting 의미를 유지하며 path를 다시 열지 않는다. 원본 bytes 복원이 아니며 원본 snapshot SHA만 계보로 유지한다. DataFrame 행 수도 snapshot과 대조한다.
3. 기존 pandas 소유 코드를 유지하라는 사용자 지침에 따라 스택/의존성을 교체하지 않는다. 새 adapter와 leaf/map/revision 투영을 책임별로 분리한다. existing numeric/catalog/threshold/계산식은 그대로다.
4. B4a admission과 readonly generation을 재사용하고 원본 record를 보존해 revision의 전략명 조회에 재사용한다. 전략 DB 조회는 CSV admission 뒤로 옮긴다. 기존 전략 loader는 mode=ro이며 실제 운영 DB를 시험하지 않는다.
5. feature_map x/y는 기존 B_/D_ 변수 카탈로그에 포함되는지 확인한다. S_/R_/수익률은 원본에 보존하지만 진입 피처 축으로 사용하지 못하게 한다. MAE/MFE 등 기존 결과 진단은 별도 화면에 유지한다.
6. Leaf/FeatureMap/EntryAutopsy에 품질 사유 표시와 source/baseUrl/query 변경 시 이전 자료/제안 제거, 늦은 응답 무시를 적용한다.
7. 실제 생산 API+공식 CSV/원본필드 parity/합성 browser/독립검토/receipt/commit→no-ff merge→통합 Gate.
