# 의도-일치 자가검토 체크리스트 (v2 증보 초안 G2)

> 생성/수정된 조건식을 **내보내기 전에** 생성자가 스스로 판정한다.
> 하나라도 FAIL 이면 내보내지 말고 스스로 고친 뒤 재검한다.

## A. 의도 일치 (수정 과제일 때)

- [ ] 수정 명세의 리프/절 **만** 변경되었는가? (diff 를 직접 나열해 확인)
- [ ] 명세에 없는 경계값·절·주석 변경이 하나도 없는가?
- [ ] 골격(시간밴드·시총단계 분기, elif 사다리 순서)이 원본과 동일한가?
- [ ] 변경 절 수 ≤ 3 인가?

## B. 문법·어휘 (생성 공통)

- [ ] `elif` 오타(elelif 류)·들여쓰기 붕괴가 없는가? (사다리를 위에서 아래로 소리내 읽기)
- [ ] 사용한 모든 이름이 variables_reference 화이트리스트에 있는가?
- [ ] 매수식에 매도 전용 변수(수익률·보유시간·매수가 등)가 없는가?
- [ ] 호출은 `self.Buy()` / `self.Sell()` 뿐인가? (GUI 다인자 금지)

## C. 타임프레임 정합

- [ ] tick 이면 초당*/틱 함수만, min 이면 분당*/분봉* 만 썼는가?
- [ ] 보유시간 단위를 올바르게 썼는가? (tick=초, min=분)
- [ ] 시간창: tick 매수 93000 미만·매도 93000 강제 / min 151800 상한이 있는가?

## D. 짝 정합

- [ ] 매수식 수정이 매도식 전제(손절·익절 경로)를 깨지 않는가? (CSC-07)
- [ ] 데이터길이 가드가 모든 구간함수 호출을 커버하는가?

## 출력

체크 결과를 `[SELF-REVIEW] A:4/4 B:4/4 C:3/3 D:2/2 → PASS` 형식으로 코드와 함께 출력한다.
FAIL 항목이 있으면 사유와 수정 내용을 명시한 뒤 재검 결과만 내보낸다.
