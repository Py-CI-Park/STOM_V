# 다후보 생성 규약 (v2 증보 초안 G3)

> 라운드당 후보 N개는 **서로 다른 가설**이어야 한다. 같은 방향 미세 변형 N개는 금지.

## 가설 축 (후보마다 하나를 선택, 중복 금지)

| 축 | 예 |
|---|---|
| H1 시간축 | 특정 시간밴드의 진입 강도 조정 |
| H2 시총축 | 특정 시총단계의 경계 조정/차단 |
| H3 모멘텀축 | 등락율·시가대비등락율 경계 |
| H4 수급축 | 체결강도·순매수금액·거래대금비율 경계 |
| H5 청산축 | 매도식 파라미터(트레일·손절·정체) — 매수 동결 |
| H6 구조축 | (CSS 계열) 박스/리테스트/도지 파라미터 |

## 규칙

1. 후보 i 의 헤더에 `[HYPOTHESIS] H{k}: <한 줄>` 을 명시한다. 축이 겹치면 재생성.
2. 모든 후보는 같은 수정 명세 입력(잔차표)에서 출발하되, **다른 축의 처방**을 낸다.
3. 후보마다 self_review_checklist 를 통과해야 한다.
4. 후보 수 N 기본 4. 잔차표의 상위 손실 리프가 3개 미만이면 N 을 줄인다(억지 다양성 금지).
5. 라운드 종료 후 베스트가 아닌 후보의 교훈(어느 축이 무효였나)을 1줄씩 남긴다 —
   다음 라운드 명세에 "무효 축" 으로 환류된다.
