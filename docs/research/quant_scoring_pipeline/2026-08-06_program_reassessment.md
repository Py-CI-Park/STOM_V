## 2. 프로세스 정리 — 무엇이 규율로 굳었나

연구가 반복 실패하는 동안 **판정 인프라**는 계단식으로 강해졌다. 각 규율은 실제 사고에서 나왔다.

| 규율 | 생긴 계기 | 강제 수단 |
|---|---|---|
| 비용 차감 후만 판정 | 초기 과대평가 | 라벨 L1 |
| 일 클러스터 검정 | 겹침 표본 가짜 유의성 | converge/frontier + 회귀 테스트 |
| 전 지평·전 배리어 패널 | QSP9 렌즈 오류 | 화면 구조 (페이지 22) |
| **진입 단위 정합** | QSP12 부호 반전 (4.7배 부풀림) | `entries.py` 기본 ON |
| 목적 함수 = 판정 기준 | 편중 해 선택 | `objective="day_mean"` |
| 고원 검사 절별 이동 | 동시 이동이 전 후보 오탈락 | `ladder.py` |
| **워크포워드 내장** | 홀드아웃 소진 사건 | `walkforward.py` |
| **사전 고정 격자 전수 보고** | 선택 편의 측정 | 본 문서 108셀 방식 |

**프로세스 판정**: 측정·판정 체계는 이제 신뢰할 수 있다. 문제는 그 위에서 돌린 **탐색의 구조**였다.

## 5. 🔬 근본 연구 — 왜 "인간처럼 조건식을 찾는 시스템"이 계속 실패하는가

### 5-1. 표면적 이유가 아니라 산수

- 유효 표본은 행 수가 아니라 **일수 = 355** (하루 안 거래는 강상관 — QSP12 실측: 상위 5일 기대값이 전부 동일).
- 일 수익률 표준편차 ≈ 1.2%p (워크포워드 실측 부근). 단일 가설이면 +0.2%p/일 엣지 검출에 ~100일이면 족하다.
- 그러나 가설 M개를 시험하면 문턱이 √(2 ln M) 배로 오른다. M = 수백만이면 z ≈ 5.5 →
  **식별 가능 최소 엣지 ≈ 5.5 × 1.2 / √355 ≈ 0.35~0.6%p**. QSP13 이 실측한 선택 편의 0.6225%p 와 정합한다.
- 이 우주의 진짜 엣지 상한(관측 최고 +0.43%)이 이 문턱 아래에 있다. **탐색을 아무리 잘해도 원리적으로 식별 불가.**

### 5-2. 인간(902/905)과 시스템의 구조 대비 — 진짜 차이

| | 인간 (902/905 를 만든 과정) | 시스템 (QSP10~13) |
|---|---|---|
| 스텝당 가설 수 | **몇 개** (절 하나 조정) | **수백만** (격자 전수) |
| 검증 표본 | **매일 새 데이터** (실전 = 매일이 표본 밖) | 고정 355일 재사용 (표본 안) |
| 선택 편의 | 스텝당 ≈ 0 (가설이 적고 표본이 새것) | **0.62%p** (측정값) |
| 피드백 주기 | 하루 | 라운드 (수 시간) — 그러나 같은 데이터 |
| 수익 구조 | **매도 8규칙** + 진입 | 진입 + 고정 배리어 |
| 개선 방식 | 국소 등반 (챔피언 ± 1절) | 전역 재탐색 (매번 백지) |

**핵심**: 인간이 이기는 것은 직관이 뛰어나서가 아니라 **탐색 구조가 통계적으로 유리**해서다.
작은 가설 공간 × 항상 새로운 표본 = 선택 편의가 쌓일 수 없는 구조. 시스템은 정반대로
큰 가설 공간 × 같은 표본 재사용 = 선택 편의가 지배하는 구조를 택했다. 알파랩의 결론
("챔피언은 절 단위 국소 최적, 개선은 추가(B1)뿐")이 같은 사실의 다른 표현이다.

### 5-3. 부수 원인 (구조 원인에 종속)

| 원인 | 내용 |
|---|---|
| 청산 모델 표현력 | 고정 배리어는 실제 수익원(상태 조건부 매도)을 표현 못 함 — 지도 적정성 검증으로 확정 |
| 비용 대비 신호 | 왕복 0.208%(엔진)~1.2%(실전 슬리피지 포함) vs 초 단위 신호 크기 |
| 우주의 적대성 | 거래대금 상위 시초 = 가장 붐비는 곳 — 무필터 기대값 깊은 음수 |
| 비정상성 | 355일 안에서도 국면 변화 — 고정 임계는 인간처럼 적응하지 못함 |

### 해석 — 세 가지가 동시에 확인됐다

1. **사용자 직관의 방향은 데이터와 일치한다**: 선별할수록(top-1 > top-3 > 무선별), 손익비가 높을수록(rr 3 > 1.5 > 1) 덜 나쁘다. 기울기가 전부 사용자 예상 방향이다.
2. **그러나 단독 축으로는 부호를 못 바꾼다**: 최선 조합(top-1 × ~5분 × rr3)조차 −0.365%/일. 우주 기저(−0.5%)에서 +0.14%p 개선에 그침 — 필요 개선폭의 1/4 수준.
3. **결론은 §5 와 정합**: 진입 쪽 어떤 단순 축도 답이 아니다. 남은 미개척 축은 **매도(청산)** — 챔피언이 실제로 돈을 버는 곳 — 뿐이다.

> 이 108셀은 "브레인스토밍이 틀렸다"가 아니라 **"그 직관들은 이미 우주에 반영해도 부족하다"는
> 것을 3시간 안에, 홀드아웃 소모 없이** 확정한 것이다. 재평가된 프로세스가 의도대로 작동한 첫 사례다.

## 7. 🛠️ 해법 — 목적(실전 흑자 조건식)을 달성하는 전략 4기둥

| 기둥 | 내용 | 실패 원인과의 대응 |
|---:|---|---|
| **1. 가설 예산제** | 라운드당 사전 등록 격자 ≤ 수백 셀 · 전셀 보고 · 워크포워드 내장 · 판정 시 선택 편의 0.62%p 차감 | §5-1 산수를 뒤집는 유일한 길: M 을 줄인다 |
| **2. 챔피언 근방 탐색** | 902/905 ± 1절 자동 심사 (B1 패턴의 시스템화) — 후보 생성→워크포워드→사용자 게이트 | 인간의 국소 등반을 기계화 · 유일하게 실증된 양성 경로 |
| **3. 매도 축 연구** | 봉투(30초~10분) 데이터로 트레일링·시간단계·상태 조건부 청산 평가 — 진입은 챔피언 것 재사용 | 수익원이 매도임이 실측됨 · 데이터 이미 보유 |
| **4. 시간을 데이터로** | 신규 거래일 자동 백필 → 상설 워크포워드 재검증 → 후보 숙성 → 감독 소액 실전 | 인간의 "매일 새 표본" 구조를 이식 — 선택 편의가 쌓이지 않는 유일한 표본 |

**우선순위**: 3 → 2 → 4 → 1(1은 전 기둥에 상시 적용되는 헌법).
기둥 3이 먼저인 이유: 데이터·도구가 완비돼 있고, 챔피언의 수익 구조를 지도가 재현하는지가
다른 모든 것의 전제이기 때문.

## 8. 📊 성숙도 재평가

| 단계 | 내용 | 상태 |
|---|---|---|
| L1 인프라 | 라벨 공장 · 집행 우주 · 엔진 정합(체결·창·비용) · UI | ✅ 완료 |
| L2 측정 규율 | 통계 스택 · 진입 단위 · 워크포워드 · 선택 편의 예산 | ✅ 완료 (이번 세션) |
| **L3 가설 공간 설계** | 어디를 팔지 아는 것 — 진입축 소진 증명 ✅ · **매도축 미착수** | ⬅️ **현재 위치** |
| L4 알파 생산 | 표본 밖 생존 후보 | ❌ (B1 1건 — 시스템 외부 출신) |
| L5 운용 | 실전 정합 · 포트폴리오 | 미착수 |
