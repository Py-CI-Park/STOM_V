## 0. 🎯 목적과 성공 기준

**목적 (한 문장)**: 도달 기반 라벨(v2) 위에서, 넓은 시드로부터 수렴 루프를 돌려
**손익분기를 넘는 (진입 조건 × 익절/손절/시간) 조합**을 찾아 엔진·홀드아웃·사다리를
통과시키고 사람 승인 후보로 만든다 — **902/905 비의존**.

| 단계 | 성공 기준 |
|---|---|
| 1차 (지도) | 설계 구간에서 기대값 > 0 (손익분기 돌파) 조합 ≥ 1 — 일 클러스터 유의·표본 하한 |
| 2차 (공식) | 그 조합이 엔진 실측 + 홀드아웃 + 검증 사다리 6종 통과 |
| 3차 (실전) | 감독형 소액 실전에서 백테스트와 정합 (사용자 판정) |
| 상한 없음 | "좋으면 좋은 것" — 벤치마크 천장을 두지 않는다 |

**출발점 실측** (2026-08-05, 최적화 0회): 거친 필터 4개로 결정 건 승률 25.9%→**37.0%**
(손익분기 40.3%, 하루 98건). 미사용 도구 = TP/SL 그리드 선택·시간대 조건·전 변수
100분위 탐색·봉투 기반 트레일링 → **돌파 여지는 크나 보장은 없다** (정직).

## 1. 🗺️ 전체 구조 (6단계 + 관통 트랙 2개)

```
P1 라벨 v2        →  P2 우주 뷰·큐브   →  P3 도달 지도·수렴 루프  →  P4 슬라이더 UI
(봉투+도달시각)       (L1/L2 표준화)       ◆게이트: 손익분기 돌파?      (사람+AI 실시간 탐색)
                                              ↓ 돌파
                                          P5 엔진 검증·사다리  →  ◆사람 승인  →  P6 실전 트랙
                                          (전이율 기록 의무)                    (감독 소액→정합 확인)

관통 트랙 A: 기록 관리 (라운드 로그·원장·INDEX — 매 단계)
관통 트랙 B: UX/UI (P2·P3·P4 에 페이지 병행 — §3)
```

## 2. 📋 단계별 상세

### P1 — 라벨 v2 "도달 지도의 원료" (예상 1세션 · 재빌드 ~45분 포함)

| 항목 | 내용 |
|---|---|
| 작업 | ① `label_spec` v2: 체크포인트 {30,60,120,300,600초 / min: 5,10,30,60분} · 배리어 그리드 {+1,+2,+3,+5,−1,−2,−3}% ② `label_factory`: **MFE/MAE 봉투**(체크포인트별 누적 최고/최저) + **배리어 도달 시각**(bid 경로 최초 교차 초) — TDD ③ 양 레인 재빌드 + QA 재실행 |
| 신규 QA | **불변식 검사**: MFE(h₂)≥MFE(h₁) (h₂>h₁) · frB(h) ≤ MFE(h) · 도달시각(+1%) ≤ 도달시각(+2%) — 합성+실데이터 |
| 산출 | `state/labels/*_v2/` parquet (+~2.5GB) |
| 게이트 | 불변식 + QA 3종 전부 PASS (실패 시 P2 진행 금지) |
| 예상 효과 | 임의 (TP,SL,T) 청산 규칙의 탁상 평가 성립 — **순서 미상 소멸** |

### P2 — 집행 우주 뷰 + 통계 큐브 (예상 0.5세션)

| 항목 | 내용 |
|---|---|
| 작업 | ① `universe.py`: 집행 우주 필터 정본화(관심종목==1·경과≥워밍업·가격밴드·스프레드) + 버전 태그 — **모든 분석의 유일한 입구** ② 큐브 생성기: (변수 20종 분위 × 시간대 × TP/SL 조합) 별 {표본수·확정승률·기대값·봉투 분위} ③ **동시신호 군집도** 지표(자본 경로 §4.1) |
| 산출 | `_cube.parquet` + 조회 함수 (표본수 병기 강제) |
| 게이트 | 큐브 값 ↔ 원본 재계산 표본 대조 일치 |
| 예상 효과 | 이후 모든 질문이 "쿼리 1초"가 됨 · 신기루(집행 불가 영역) 구조적 차단 |

### P3 — 도달 지도 재판독 + 수렴 루프 (예상 1~1.5세션) ◆ 핵심 게이트

| 항목 | 내용 |
|---|---|
| 작업 | ① 새 목표 함수 = **(TP,SL,T) 기대값** 으로 변수 랭킹·2D 포켓·트리 전면 재실행 (구 지도 폐기) ② **수렴 루프**: 탐욕 필터 스태킹 × TP/SL 그리드 × 시간대 조건 → 승률·하루 기회 파레토 프런티어 ③ 통계 규율: 일 클러스터·FDR·임계 100분위·표본 하한 |
| 산출 | 도달 지도 리포트 + 파레토 표 + 돌파 후보 목록(계보 포함) |
| **게이트** | **기대값 > 0 조합 ≥ 1** (설계 구간). 미돌파 시: min 레인 동일 재판독 → 그래도 없으면 정직 보고 후 방향 재논의 |
| 예상 효과 | 37.0%→40.3%+ 돌파 시도 — 이 단계가 프로그램의 승부처 |

### P4 — 슬라이더 UI (예상 1~1.5세션 · P3 와 부분 병행 가능)

§3 UX/UI 참조. 예상 효과: 조건 1개 평가 7~10분(엔진) → **1초** · 사용자가 직접 탐색
가능(사람+AI 협업) · 단일 렌즈 분석이 화면 구조상 불가능.

### P5 — 엔진 검증 + 사다리 (예상 0.5세션 + 런 수십 분)

| 항목 | 내용 |
|---|---|
| 작업 | ① 돌파 후보 → `assembler` 매수식 렌더 + **배리어 매도식 렌더**(TP/SL/T → DSL 신규) ② 엔진 16 설계 런 → **전이율 기록**(지도 추정 vs 실측 — 군집도 높으면 보수 계수) ③ 통과 후보만 전체 구간 연속 런 → 2job 분할 게이트(**홀드아웃 개봉은 여기가 처음**) → 사다리 6종(고원·비용×1.5·국면 절단 포함) |
| 게이트 | 사다리 전부 통과 → **사람 승인 요청** |
| 예상 효과 | 자본 경로 의존성 실측 반영된 공식 성적 |

### P6 — 실전 트랙 (사용자 결정·수행)

전략 DB 등록 → 감독형 소액 실전 → 실전-백테 정합 확인 → 불일치 시 한계 원장 → 라벨 보정 환류.

## 3. 🖥️ UX/UI 전략 (항상 병행 — 전담 트랙 B)

기존 21페이지 유지 + 신규 3면. 원칙: **표본수 병기 · 전 지평×전 배리어 기본 패널 ·
권위 배지(탐색용/공식) · 후보 저장 시 근거 계보 자동 기록**.

| 페이지 | 이름 | 내용 | 구축 시점 |
|---|---|---|---|
| **22** | **도달 지도 패널** | 시간대×변수 파셋 히트맵 — 셀 = (TP/SL 승률·기대값·표본수), 지평·배리어 전환 탭 기본 노출 | P3 산출과 동시 |
| **23** | **슬라이더 작업대** | 변수 슬라이더(100분위 스냅) → **1초 내** {표본수·하루 기회·확정승률·기대값·손익비·군집도} 갱신 → "후보 저장" → P5 로 전달 | P4 |
| **24** | **검증 현황판** | 후보별: 지도 추정 → 엔진 실측 → **전이율** → 사다리 6종 체크리스트 → 승인 배지 | P5 와 동시 |
| 12 (강화) | 캘리브레이션 | 전이율 누적 원장 (군집도별 보수 계수 학습) | P5 |

백엔드: `/bt/map/*` API 4종(universe·slider-query·cube·candidate-save) — 보안 분류표
등록(HTTP_CAPABILITIES) + Origin·세션 규율 준수.

## 4. ⚖️ 규율 (확립분 통합 — 이 프로그램의 헌법)

| 분류 | 규율 |
|---|---|
| 라벨 | 비용 차감 후만(L1) · 홀드아웃 봉인(L2, 개봉은 P5 사다리에서 1회) · 사전 고정 그리드(체크포인트·배리어) |
| 우주 | **모든 분석은 집행 우주 뷰를 통해서만** (관심종목·워밍업·가격밴드) |
| 통계 | 일 클러스터(tick) · +종목 셔플 대조군(min) · FDR q≤0.10 · 임계 100분위 · 표본수 병기 |
| 렌즈 | **전 지평·전 배리어 패널이 기본** — 단일 지표 판정 금지 (렌즈 오류 재발 방지) |
| 검증 | 지도=탐색 · 엔진=심판 · 소액 실전=최종 그물 · 전이율 기록 의무 · 군집도 사전 예고 |
| 절차 | 한 라운드 한 축 · 사람 승인 · 실패 전량 기록 · 정정 문서 규칙(INDEX §5) |

## 5. 📊 예상 효과 총괄 (정량)

| 항목 | 현재 | QSP10 후 |
|---|---|---|
| 조건 1개 탐색 평가 | 엔진 7~10분 | **1초** (400~600배) |

| 지식 축적 | 문서 산재 | INDEX + 큐브 + 계보 — 다음 연구가 이전 지도 위에서 시작 |
| 사람 참여 | 결과 보고 수신 | **슬라이더로 직접 탐색** (사람 직관 + AI 검증의 실시간 협업) |
