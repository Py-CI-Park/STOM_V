# 프로세스 v2 + 시드 전체 재연구 계획 (2026-06-12 밤 — 사용자 지시 전수 반영)

> 사용자 지시: ① 2026 데이터는 추후(리스트 제외) ② **지금 데이터로 충분히
> 찾을 수 있다 — 그 능력이 새 데이터가 와도 제일 중요** ③ OOS가 타이트하면
> 횡보 전략을 부당 기각한다 — 고려해 프로세스 재설계 ④ 시드 조건식·초기
> 범위 설정 전체 재연구.

## 1. 지시 ②의 검토 — 동의 + 근거

기각 17계열은 '구조 후보'의 소진이지 **공간의 소진이 아니다**. 미탐사로
남아 있는 것: 시드 조건별 기여도(한 번도 부검 안 함), 시드 고정 상수들
(가격대 1000~50000·등락율 2~20·시간창 등 — 축으로 푼 적 없음), 2-D 결합
(cap×take 1회뿐), 최소 골격에서의 전진 선택. **즉 지금까지는 "완성된 구조
주변"만 팠고 "구조의 내부"는 안 팠다.** 이것이 재연구의 본체다.

## 2. 지시 ③ — OOS 판정 v2 (사전선언 개정, 소급 적용 금지)

문제: p0 §5의 "전 OOS 창 흑자 필수"는 9건 표본에서 좋은 전략의 17~27%를
우연히 기각하고, **횡보(보합)를 실패로 오분류**한다.

개정 v2 (신규 동결부터 적용):

| 구분 | v1 (기존) | **v2 (개정)** |
|---|---|---|
| 절대 수익 | 전 OOS 창 흑자 필수 | **가점** — 필수 아님 |
| 핵심 게이트 | — | ① **시드 대비 비열등**(같은 창 동시 재측정 — 시장 운 상쇄) ② **MDD 한도**(시드×1.5) ③ **무붕괴**: 손실이 -시드손실×1.5 이내(횡보·소폭 손실 = HOLD-OK 통과) |
| 소표본 창 | 거래<20도 동일 기각력 | **거래<20 창은 단독 기각 금지**(advisory 강등) — 판정력은 V4 walk-forward(164건급)가 1차 |
| 횡보 후보 | REJECT | **HOLD-OK** → V4·CI로 추가 증거 → 통과 시 후보 유지 |

정합성 검증: 기존 기각 4건(C7·EXIT2C·EXIT2NA·g9)은 전부 시드 열위 또는
MDD 위배 — **v2로도 전원 기각**(소급 번복 없음 — 규율 일관).

## 3. 지시 ④ — 시드 전체 재연구 5단계 (기존 도구만 사용, 신규 데이터 불요)

| 단계 | 내용 | 방법 | 산출 |
|---|---|---|---|
| **R1 조건 부검(ablation)** | 시드 매수 조건을 한 줄씩 제거한 N-1 변형 전수 측정 | 빌드 스크립트 + 배치(같은 자) | "어느 조건이 알파를 만드는가" — 사상 첫 실측 |
| **R2 초기 범위 전축화** | 고정 상수(가격대·등락율 밴드·시간창·체결강도 등) 전부를 θ 축으로 | 시드 풀템플릿 v2 빌드 + 스윕 | 진짜 전체 응답 지도 |
| **R3 2-D 결합 확대** | R1·R2 상위 축들의 2-D 격자(기존 cap×take 1회뿐) | --grid | mesa 후보 |
| **R4 미니멀 전진 선택** | 조건 3~4개 골격에서 시작, 조건을 '더해가며' 측정(기존은 빼기 방향만) | 빌드+배치 | 과적합 최소 구조 |
| **R5 동결·검증** | R3/R4 승자를 **v2 판정**으로 동결→OOS+V4 | 기존 체인 | 차기 챔피언 후보 |

n_trials 정직 합산 유지(R1~R4 전부 시도로 등재). min 시드도 동일 절차
(R1m~). LLM 루프는 R1 부검 결과(조건 기여도)를 컨텍스트로 받아 재개하면
가설 질이 오른다 — 루프 2차 배치는 R1 이후가 경제적.

## 4. 다음 해야 할 것 (2026 데이터 제외 — 우선순위순)

1. **R1 시드 조건 부검** — 즉시 가능, ~1시간(변형 ~10개 × 150초 + 분석)
2. R2 풀템플릿 v2 + 본 스윕(~3시간) → R3 격자(~2시간)
3. v2 판정 규칙의 select/OOS 도구 반영(코드+테스트)
4. R4 미니멀 전진 선택(~2시간)
5. LLM 루프 2차 배치(R1 컨텍스트 탑재 후)
6. ★V6(사용자) · 페이퍼+M4 — 병행 가능
