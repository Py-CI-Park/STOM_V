# 전향 데이터 수집 스펙 (갭4·S5·S4 — 2026-06-12 사전선언)

> 목적: 사용자가 추가할 2026 신규 데이터가 도착하는 날, 사람 판단 없이
> 1-커맨드 체인으로 ① 챔피언 확장 OOS(V3′) ② 패자부활 배치(S4) ③ 유니버스
> 연구(N3)가 실행되도록 **지금** 스펙과 절차를 고정한다.

## 1. 현황 (2026-06-12 실측)

- back DB: `_database/stock_tick_back.db` 29.7GB, **2022-03-23 ~ 2026-02-27**
- 유니버스: moneytop 기록(수집 당시 상위 종목), 시간 09:00:00~09:30:00
- 구조: 종목별 틱 테이블 + `moneytop`([index]=YYYYMMDDHHMMSS) + `stockinfo`
- 제약: **기록되지 않은 종목·시간은 영원히 연구 불가** — 수집 폭이 곧
  미래 연구의 상한이다(갭4의 본질).

## 3. 도착 시 실행 절차 (사전선언 — 도착 당일 1세션)

1. **병합·감사**: 신규 구간 일자 수·moneytop 범위 확인(MIN/MAX [index])
2. **설정 사전선언**: `oos-2026ext-config.json` 생성 — `oos-2026-config.
   template.json` 사본에 bt_full_start=20260301, bt_full_end=<신규 끝> 만 변경
3. **V3′ 챔피언 확장 OOS**: pairs-oos.json(THETA+시드 — 복원돼 있음)으로
   `claude_candidate_batch_eval --config-json oos-2026ext-config.json
   --run-id theta_oos_2026ext_<날짜>`
4. **S4 패자부활 배치**: `pairs-revival.json`(시드+THETA+기각자 전원)으로
   같은 config 1회 — 선별 없음(체리피킹 불가)
5. **기록**: 결정 카드 추록 + 핸드오프 갱신 + 커밋

## 4. 사전선언 판정 규칙 (도착 전 고정 — 변경 금지)

- **V3′(챔피언)**: p0 §5 + 시드 상대 비교. 통과 시 V6 재료 강화,
  미달 시 사유 공시(여전히 advisory — V1~V5 본 검증은 이미 종결).
- **부활(기각자)**: 신규 창에서 ① 흑자 ② 시드 우위 ③ maxMDD ≤ 시드×1.5
  **전부** 충족 시에만 '재동결 후보' 복귀(곧장 승격 아님 — 정규 동결→
  잔여 검증 절차 재진입). 하나라도 미달이면 레지스트리 잔류.
- 신규 데이터는 이 실행 전까지 어떤 선택·튜닝에도 사용하지 않는다
  (OOS-blind 유지 — 사용 즉시 그 구간은 train으로 오염).

## 5. 갭1(시간 확장) 연구와의 결합

신규 수집이 09:30 이후를 포함하면: 기존 템플릿의 window_end 축 상한을
93000 너머로 여는 **새 빌드**(기존 템플릿 무수정 — 별도 이름)로 사전선언
스윕. 그 전까지 시간 확장 연구는 09:00~09:30 내부 축(F04·F18에 탑재됨)으로
한정된다 — 이것이 현 데이터의 정직한 한계다.
