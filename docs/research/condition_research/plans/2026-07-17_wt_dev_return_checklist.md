## C. 지식 이관 — wt-dev 생성 루프의 문법·예산 개선 (가장 실질적 가치)

wt-dev 루프(생성→백테 점수)의 탐색 공간에서 **봉인된 자로 확정된 오답 축을 제거**해 백테스트 예산을 절약한다. 반영 형태: 루프의 시드/문법/필터 설정(구체 파일은 wt-dev 측 확인 필요 — 생성기 설정 계층).

| # | 확정 지식 | 루프 반영 규칙(제안) | 근거 판정 |
|---|---|---|---|
| C-1 | 압력 절 4족이 유일한 실증 양(+) 부품 | 생성 문법에서 압력 절(초당순매수금액·라운드피겨 밖·VI아래5호가·초당매수수량vs매도총잔량) 우대 가중 | D1 (+0.13~0.20%p, 전 관문) |
| C-2 | 현재가 대역 절은 **압력 절 동반 시에만** 의미 | 결합 규칙: 대역 절 단독 생성 금지, 압력 절과 짝으로만 | 2절 시너지 (16×37 +0.129 / 16×38 +0.157) |
| C-3 | 돌파·갭·온셋 변형은 진입으로도 회피로도 무가치 | 시초 30분 돌파/갭 추격형 시드 생성 배제 (온셋 축 변형 탐색 배제) | O-3(전 단위 음)·O-1G(0/144)·D5(재포장)·**audit 랩 G003(회피 필터로도 −845만 실측)** |
| C-4 | 얕은 절 조합(2~6절)은 비용 벽 미달 | 후보 최소 깊이 하한(저자-가지 수준 20절+) 또는 얕은 후보 조기 폐기 | O-4 (158후보 전원 음수) |
| C-5 | 챔피언 절 제거는 입·출구 모두 손해 | 챔피언 계보 시드의 절 삭제 변형(뮤테이션) 생성 배제 | 매도식 D1(load-bearing 5절) + **X1(엔진 실측)** |
| C-6 | 출구 개선은 "추가"만 유효 | 매도식 뮤테이션은 절 추가형만 (B1 저활력 절단이 실증 전례) | B1(+154만/2년) vs 매도식 D1(제거 전멸) |
| C-7 | 비용 벽 = 왕복 0.61~1.21%(연도 세율) | 루프 채점에 연도 키 세율 반영(2024 상수 0.18% 단일 사용은 발견창 과소평가) | W3-R 재봉인 |

## F. 복귀 실행 순서 (승인 후)

1. **[사용자]** B1 소액 운용 개시(A-1 — 레인 무관, 지금 가능) 
2. **[사용자]** P4 go 여부 + 기존 V4 대시보드 PR 처리 방침(병합/폐기/재작성) 결정 
3. **[go 시]** B-1~B-4 파일 이식 → P4 구현(집행 모델 — 계약 §7 검수 7항) 
4. **[선택]** C-1~C-7을 wt-dev 루프 설정에 반영(작은 PR 단위 — 루프 실측으로 예산 절약 검증) 
5. **[별도]** audit 랩 병합 여부 결정(E 참조) 
6. wt-alpha는 **동결 보존**(연구 재개 시 핸드오프 v3 → 실행 계획 정본 순으로 복원)
