## 0. 결론 먼저

**챔피언 매수식(sha `348c5181…`)에서 D1이 "역생산"으로 판정한 절 중 시너지 보호절을 뺀 후보 4개를, 각 절만 삭제한 변형 매수식으로 만들어 발견창(2022-2023) 엔진 A/B를 돌려, 그 절을 빼면 총수익이 오르는지("더 많이 사서 더 번다")를 직접 검정한다.** 매도식 D1이 "출구는 뺄 것이 없다(추가만 유효 — B1)"로 끝났으니, 본 연구는 대칭 질문 — **"입구는 뺄 것이 있는가"** — 를 오프라인 프록시가 아니라 엔진 실측으로 묻는다.

기준런(A) = 챔피언 페어링(매수 `ALP_V4_RR8_12` + 매도 원본 `8ef01e0e`)의 발견창 A/B로, **B1 실전 검증의 A_2022/A_2023을 그대로 재사용**한다(추가 엔진 0). 후보별 변형런(B) = 절 삭제 매수식 + 동일 매도 원본. 판정은 B1 kill-5를 준용하되 **방향 반전을 반영**한다(삭제는 거래를 늘리므로 거래수 ±20% 밴드 대신 **상한 규칙**).

**이 연구가 결정하는 것**: 총수익이 개선되고 MDD가 비악화(사전 허용폭 내)인 후보가 **하나라도** 나오면 그 변형이 **X1 후보**가 되어 U-4 감독형 소액 실전으로 승격한다(B1 전례). **전 후보가 악화면** "매수측도 절 단위에서 뺄 것이 없다"가 확정되어 매도식 D1과 **대칭 확정 지식**(입출구 모두 절 단위 국소 최적, 개선은 오직 추가·조합)이 남는다. 어느 쪽이든 봉인된 자로 잰 확정 지식이다.

### 0.1 왜 엔진 실측인가 (오프라인 프록시로는 결정 불가)

D1은 각 절의 Δ = mean(L3 | 만족) − mean(L3 | 미만족)를 서지 온셋 위에서 쟀다. 후보 4절은 전부 Δ<0(역생산 = "만족측이 더 나쁜 EV로 정렬")이라 **삭제가 유리할 방향을 시사**한다. 그러나 이 오프라인 Δ는 결정 근거가 될 수 없다:

1. **유입 집합 ≠ 미만족 전체**: 절 c를 삭제하면 실제로 새로 매수되는 온셋은 "c 미만족 ∧ **나머지 전 가드 통과**"인 깊은-AND 교집합뿐이다. D1의 mean_unsat은 c 미만족 **전체**의 주변 평균이라(대부분 다른 가드에서 탈락) 유입 집합의 EV가 아니다 — 느슨한 방향 힌트일 뿐.
2. **프레임 갭(B-트랙 교훈)**: 엔진은 1일 1진입·순위 진입·warmup·경과틱 타이밍으로 실제 진입을 고른다. 온셋 EV는 이 프레임을 담지 못한다 — 실제 유입은 프레임이 고른 작은 부분집합이다.
3. **상호작용(2절 교훈)**: 단일-절 Δ는 절 간 시너지(16×37·16×38)를 못 본다. 역생산 가드 하나를 빼면 남은 가드들이 더 나은(또는 나쁜) 하위 영역으로 응집할 수 있다 — 단일-절 오프라인으로는 불가시.

세 이유 모두 "온셋 지도"와 "엔진 총수익" 사이의 갭이다. **총수익(사용자 목적함수)은 엔진만이 잰다.** 그래서 본 연구는 오프라인 판정을 하지 않고, 방향 가설만 D1에서 빌려와 엔진으로 심판한다.

## 0.5 쉬운 설명 (그물코 비유)

챔피언 매수식은 아주 촘촘한 그물이다 — 통과하려면 열몇 개 조건을 전부 만족해야 한 마리(온셋)가 걸린다. 사용자의 바람은 "그물코를 조금 넓혀(조건 몇 개를 빼) 더 많이 잡자"는 것이다.

- D1이 "이 그물코(역생산 절)는 오히려 좋은 고기를 튕겨낸다"고 지목한 코가 6개 있었다. 그중 2개(현재가 대역 #16·#17)는 **다른 코와 짝을 이뤄야 제 역할을 하는 코**(압력 절과의 시너지 — 혼자 빼면 짝이 무너짐)라 건드리지 않는다. 남은 4개를 후보로 삼는다.
- 각 후보 코를 하나 빼고 **실제로 그물을 던져 본다(엔진 백테)**. 더 많이 잡으면서 **총어획량(총수익)이 늘고** 배가 뒤집힐 위험(MDD)이 안 커지면, 그 코는 "빼도 되는 코"(X1 후보)다.
- 주의: 오프라인 지도는 "저 코 밖에 좋은 고기가 있을 것 같다"까지만 말한다. **정말 그 고기가 그물의 나머지 코까지 다 통과할지, 잡고 보니 원가(왕복 비용 0.6~1.2%)도 안 되는 잔챙이인지는 실제로 던져 봐야 안다.** 그래서 지도가 아니라 바다(엔진)에서 판정한다.

**정직한 예상**: 후보 4개의 오프라인 "미만족 평균"은 전부 아직 **음수(−0.77~−0.96%p, 원가 미달)**다 — 넓힌 코로 들어올 고기가 평균적으로 잔챙이일 개연을 시사한다. 그래서 사전 기대는 매도식과 대칭인 **"매수측도 뺄 것 없음"**으로 기운다. 그럼에도 검정하는 이유: ① 사용자가 명시적으로 원했고 ② 깊은-AND 유입·프레임·상호작용은 오프라인이 못 보므로 엔진만이 정직한 심판이며 ③ 역생산 코를 빼면 남은 코가 더 좋은 영역으로 응집할 실낱 가능성은 엔진으로만 확인된다.

## 2. 가설

**H0(후보별)**: 챔피언 매수식에서 역생산 절 c를 삭제한 변형은 발견창 엔진 총수익을 개선하지 않는다 — Δ총수익 = 총수익(변형 B) − 총수익(원본 A) ≤ 0, 또는 개선하되 MDD 악화·거래수 폭증(식 붕괴)을 동반.

**H1(후보별)**: Δ총수익 > 0 (2022·2023 동방향) ∧ MDD 비악화(사전 허용폭 내) ∧ 거래수 증가가 상한 이내 ∧ 무오류 → 절 c는 **삭제가 유리한 역생산 절(X1 후보)**.

**측정량**: 후보당 A/B 2런(연도별). 판정량 = 연도별 Δ총수익(원)·거래수 변화율·MDD 변화·상태(success). 목적함수 = **총수익(원) 최대**(사용자 v3-2), MDD는 킬스위치 제약(§7).

**방향 주의(엔진이 답한다)**: 매수식 절 삭제 = "그 절 미만족 온셋도 매수" → 새로 사는 유입 집합의 실현 EV가 관건. 유입이 원가(왕복 0.61~1.21%)를 넘는 양의 EV면 총수익↑, 못 넘으면 총수익↓. 오프라인은 유입 EV를 못 재므로(§0.1) 엔진 A/B가 유일 판정.

**후보 봉인 규약**: 후보 = 4(DROP5·DROP15·DROP29·DROP31). 양 가지 공통 절(DROP5·DROP15)은 **양쪽 다 제거 = 1후보**(가지별 분해는 예비 예산·§13-F7). 이 4후보와 시너지 보호 제외 2절은 **엔진 실행 전 봉인**하며, 결과를 보고 후보를 바꾸지 않는다.

## 4. 변형 생성 규약 (절-타입별 · sha 봉인 · bit-diff · scratch DB)

원본 = stockbuy `ALP_V4_RR8_12`(sha `348c5181…`, read-only 로드·검증). 변형 = **해당 절 라인을 제거**(주석 처리 아님 — byte 명확성). 절 구조가 3종이라 제거 방식이 다르다:

| 절 타입 | 후보 | 제거 방식 | bit-diff 기대 |
|---|---|---|---|
| 단순 가드 `elif not(P): 매수=False` | DROP15(양 가지)·DROP29(905) | 그 2줄(elif + body) 삭제 | 삭제 N줄·추가 0 |
| **게이트 `if P: <body> else: 매수=False`** | DROP5(양 가지) | 게이트 무력화: `if 시가총액<3000:` → 항진식으로 대체(또는 if/else 래퍼 제거 + body dedent) + `else: 매수=False` 제거 | 삭제/편집 다수(dedent) — **가장 침습, §13-F5 규약 필수** |
| **복합 라인 `elif not(A and B): 매수=False`** | DROP31(902, #31∧#30) | 라인 내 편집: `매도총잔량 > 매수총잔량*0.10 and 매도총잔량 < 매수총잔량*2.0` → `매도총잔량 < 매수총잔량*2.0`(#30 보존) | 삭제 1·추가 1(편집) |

**검증 3중(B1 `d5r_b1_patch_verify.py` 전례 미러 — 역방향=삭제)**: ① 기계 생성 후 변형 sha 봉인 ② **bit-diff**: 원본 대비 삭제/편집이 **정확히 그 절뿐**(그 외 1바이트 불변 — DROP5는 dedent 편집을 화이트리스트로 명시) ③ **엔진 변환/컴파일**: `GetBuyStg`/`SetBuyCond` 재현 후 `compile()` 무오류 + 남은 절 attribution 정상 ④ **ground_grammar 검증**(`ground_grammar_map.json` 대비 변형이 유효 문법인지). 변형명 = `ALP_X1_DROP<절번호>`(예: `ALP_X1_DROP5`). **등록은 scratch strategy.db에만**(실 `_database/strategy.db` 미접촉 — B1 register 전례, INSERT-only, U-4 승인까지 실 DB 금지).

## 5. 방향 스케치 (D1 mean_unsat — 정직한 한계 병기)

D1 판정에서 후보 4절의 만족/미만족 평균 L3(%p, 서지 온셋):

| 후보 | mean_sat | mean_unsat(유입 방향) | Δ | 유입 상한 n | 오프라인 방향 힌트 |
|---|---|---|---|---|---|
| DROP5 | −1.084 | **−0.959** | −0.125 | 528,237 | 유입 평균 음(원가 미달) — 개선 회의적, 유입 대 |
| DROP15 | −1.060 | **−0.940** | −0.120 | 377,733 | 동상 |
| DROP29 | −1.009 | **−0.841** | −0.167 | 3,687 | 유입 덜 음이나 희소 → Δ≈0 개연 |
| DROP31 | −1.008 | **−0.770** | −0.238 | 2,122 | 유입 가장 덜 음이나 희소 |

**정직한 해석**: mean_unsat은 미만족 **전체**의 주변 평균(유입 집합=깊은-AND 교집합의 EV가 아님 — §0.1)이며, **네 후보 모두 음수(−0.77~−0.96%p)로 왕복 비용(0.61~1.21%)에 미달**한다. 즉 오프라인 방향 힌트는 "삭제로 들어올 온셋이 평균적으로 원가 미달" → **개선 회의적(매도식과 대칭 kill로 기움)**. 그러나 이 힌트는 결정이 아니다: 실제 유입은 프레임이 고른 깊은-AND 부분집합이라 이 주변 평균과 다를 수 있고, 남은 가드의 응집 효과도 있다. **부호·크기의 최종 판정은 엔진 Δ총수익만.** 본 스케치는 사전 기대의 투명한 공개일 뿐 판정 입력이 아니다.

## 7. 판정 기준 (B1 kill-5 준용 + 삭제 방향 반전)

후보별 A/B가 다음을 **모두** 충족하면 **X1 후보**(→ U-4):

| 기준 | 봉인 문턱 | B1 대비 변경 |
|---|---|---|
| **C1 총수익 부호** | 연도별 Δ총수익 = 총수익(B) − 총수익(A) **> 0** ∧ 2022·2023 **동방향(+)** | 동일(kill-5 C1) |
| **C2 거래수 상한(식 붕괴 방어)** | 삭제는 거래 증가 → 밴드 아님 **상한만**: 거래수 증가율 (N_B−N_A)/N_A **≤ +300%**(예시값·§13-F2). 초과 = **"식 붕괴"**(더 이상 선택적 매수식 아님) kill. 하한 없음 | **반전**: kill-5의 ±20% 밴드 → 상한 규칙 |
| **C3 MDD 비악화** | MDD(B) ≤ MDD(A) × (1 + 허용폭) 또는 절대 상한(§13-F3) — 킬스위치 제약 | **신설**(B1 ab_judge 미포함, 삭제는 MDD 위험↑) |
| **C4 무오류** | A·B status == "success" | 동일(kill-5 C3) |

**해석 사다리**:
- X1 후보 ≥1(C1~C4 통과) → 그 변형을 **U-4 감독형 소액 실전**(정본 페어링 = 변형 매수 + 매도 원본)으로 승격, scratch→실 DB 등록·운용 개시는 **사용자 승인**(B1 전례 절차서). 30거래일 채점 전 성공 주장 금지.
- 전 후보 미충족 → **kill(§10)**: "매수측도 절 단위 삭제로 개선 안 됨" — 매도식 D1과 대칭 확정 지식.
- 경계(Δ총수익>0이나 MDD 악화 또는 거래수 상한 초과) → 채택 불가·보고만(사후 문턱 완화 금지).

**연도 얇음 명기**: 발견창 2개 연도뿐이라 winner's curse 방어를 연도 반복성으로만 한다(§1). 점추정 신뢰 금지 — 부호·동방향·크기대역만.

## 13. 미결 결정 목록 (메인 세션이 봉인 시 결정 — 각 권고 + 근거)

1. **F1 후보 확정(희소 유입 포함 여부)**: 권고 = **4후보 전부 유지**(DROP5·DROP15·DROP29·DROP31). 근거 = D1 Δ가 전부 floor 통과·FDR 생존. 단 DROP29/31은 유입 희소(3,687/2,122)라 엔진 Δ가 잡음 수준일 개연 명기 — "무효과" 판정도 확정 지식(삭제 무해·무익). 대안 = DROP29/31 제외하고 2후보만(유입 대형만 — 엔진 예산 절약, 단 D1 최대 음 Δ 절을 미검정, 비권고).
2. **F2 거래수 상한(식 붕괴 문턱)**: 권고 = **+300%**(N_B ≤ 4×N_A) 초과 = 식 붕괴 kill. 근거 = 챔피언 일평균 0.5~0.8거래라 4배도 여전히 희소 선택적. 대안 = +100%(2배, 보수 — DROP5 대형 유입 조기 차단) 또는 절대 상한(예: 일평균 ≤3거래). 하한은 두지 않음(삭제=증가 자명).
3. **F3 MDD 허용폭**: 권고 = **MDD(B) ≤ MDD(A)×1.5** 또는 절대 상한(예: ≤15%). 근거 = 사용자 목적함수는 총수익, MDD는 킬스위치 제약(v3-2) — 소폭 악화는 총수익 개선과 교환 가능하나 무제한 불가. 대안 = 비악화 엄격(MDD_B≤MDD_A — 보수) 또는 킬스위치 절대선만(예: ≤20%).
4. **F4 판정 우선순위·집계**: 권고 = **연도별 C1~C4 각각 통과 필수**(B1 ab_judge 미러) + 집계(ΣΔ총수익·양년 동방향) 병기. 근거 = 2개 연도 동방향이 winner's curse 방어 핵심. 대안 = 집계 우선(ΣΔ>0면 통과 — 한 해 악화 허용, 얇은 표본에 관대, 비권고).
5. **F5 게이트 절(DROP5) 변형 규약**: 권고 = 게이트 무력화를 **항진식 대체**(`if 시가총액<3000:` → `if True:`) + `else: 매수=False` 제거로 규정하고, bit-diff에서 이 편집(항진식·else 제거·dedent 불요)만 화이트리스트. 근거 = dedent 없이 최소 편집으로 "시총 요건 무효화" 의미 달성·재파스 안정. 대안 = if/else 래퍼 제거 + body dedent(더 침습·diff 큼, 비권고).
6. **F6 복합 라인(DROP31) 편집 규약**: 권고 = 라인 내 편집으로 #31만 제거·#30 보존(`A and B`→`B`), bit-diff 삭제1·추가1 화이트리스트. 근거 = #30은 역생산 아님(로드-베어링/중립) — 함께 빼면 다른 절 오염. 대안 = #30·#31 동시 제거(잔량비 족 전체 — 별도 후보, 본 라운드 미포함).
7. **F7 양-가지 공통 절 분해(DROP5·DROP15)**: 권고 = **양쪽 다 제거 = 1후보**(가지별 902-only·905-only 분해는 예비 예산 2런). 근거 = 사용자 의도는 "그 조건 제거"(가지 무관)·예산 절약. 대안 = 가지별 3변형(양쪽·902·905) 각 후보 — 예산 초과, 예비로 보류.
