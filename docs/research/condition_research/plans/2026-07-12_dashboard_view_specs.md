## 0. 쉬운 요약

전시실(대시보드)에 방을 5개 만든다. ① **연혁실**(V1): 어떤 실험이 언제 어떤 판정을 받았는지 연대표. ② **지도실**(V2): "여기 파지 마시오"가 적힌 함정 설명 지도 — 단, 지도의 눈금은 챔피언도 못 알아봤으므로 "참고용"이라는 큰 도장이 항상 찍혀 있다. ③ **부품실**(V3): 매수식을 분해한 절들의 성적표 — 잘 드는 부품 5개는 금테, 역효과 부품 6개는 경고색. ④ **표본실**(V4): 86만 개 관측을 미리 요약해 둔 서랍만 열어 본다(현장에서 새로 계산하지 않는다). ⑤ **시험 감독실**(V5): 실전에 나간 B1 학생의 30일 채점표와 감독관의 손실 한도계. 모든 방의 공통 규칙은 하나 — **전시품을 다시 깎지 말 것, 딱지를 떼지 말 것.**

### 1.2 워터마크 상시 (계획 §4 ② 원문: "설명 지도/RR8_12 조건부/audit-grade")

- 원천: 뷰가 문구를 창작하지 않는다 — `cells.label_tag`·`assets.status_tag`(판정 딱지) **원문**을 그대로 쓴다. `label_tag` 실측 4종은 P3-1 §4.3 끝에 고정돼 있다(예: `"함정 설명 전용(S-v1 칸-조준 kill-2)·자동 veto 금지"`).
- 위치: 차트 캔버스 **내부** 우하단(스크린샷·캡처에도 반드시 남도록 DOM 오버레이가 아니라 캔버스/SVG에 렌더). 닫기 버튼 없음(non-dismissible).
- R4 요약형("RR8_12 조건부")은 캔버스 워터마크로, `label_tag`/`status_tag` 전체 원문은 범례·툴팁으로 병기.

### 1.3 단위 표기 규칙 (P3-1 §4.3 단위 계약의 표시 측)

| 원천 필드 | 저장 단위 | 표시 규칙 |
|---|---|---|
| `cells.mean_net`·`ci_*`·`q*_net`·`mfe_mean`·`mae_mean` | 소수 비율(−0.0104 = −1.04%) | ×100 후 `%` 라벨, 소수 2자리 |
| `clauses.delta_pp`·`ci_*_pp`·`mde_pp` | %p 숫자(0.134 = +0.134%p) | 그대로 + `%p` 라벨, 소수 3자리 |
| 원화 금액(V5) | 원 | 천 단위 구분자 + `원` |
| 비율 지표(실현율·소진율·발동률) | 소수 | ×100 후 `%`, 분모·분자 툴팁 병기 |

두 단위(비율 vs %p)의 혼동은 100배 오표시 사고다 — 모든 수치 요소는 단위 라벨 필수, 단위 없는 숫자 렌더 금지.

### 1.5 금지 기능 목록 (요청이 있어도 P4 범위에서 구현 금지)

## 2. V1 — 연구 파이프라인 보드

**목적**: 판정 체인(커밋·결과·원장 행)을 타임라인으로 — "지금까지 무엇이 죽고 무엇이 살았나"를 한 화면에서.

**데이터 계약**: `GET /research/judgments?include_ledger=1`(P3-1 §4.2). 원천: `judgments`(7계열)·`ledger_mirror`(53+행).

**렌더링 규칙**:
- 세로 타임라인, **응답 순서 그대로**(정렬 `rowid` = 빌더 적재 순서 = 판정 체인 순서 — 클라이언트 재정렬 금지).
- 카드 = 판정 1건: `series` 제목, `verdict` **원문 전문**, 결과 칩, `produced_commit`(8자 — null이면 `note` 문구 표시), `key_metrics` 원문 수치, 원장 행 번호(`ledger_rows`·`n_ledger_rows`), `report_path` 참조 문자열.
- 결과 칩: `verdict` 원문의 선두 토큰(첫 ` — ` 이전)을 칩 라벨로 그대로 쓰고, 색은 **고정 매핑표**로만: `KILL`·`KILL-2`·`KILL(0/2)` 접두=적색 / `양성` 접두=녹색 / `무가치` 접두=회갈색 / `생존` 접두=청색 / `PASS(` 접두=청록(단 B1 카드는 R9 문구 병기: "엔진 A/B는 사전 확인 — 실전 성과 보장 아님"). 매핑에 없는 접두=중립색. 서버는 분류하지 않는다(P3-1 §4.2).
- 전 카드 잠금 표시(R10). `ga_path_flag=1`이면 경고 배지(R7). 게이트 언급은 "재현성 게이트" 라벨(R8).
- 카드 펼침: `ledger[]` 원문 행(`row_num`·`ts`·`trial_type`·`target`·`result`)을 그대로 표시 — 재요약 금지.
- "진행 중 연구" 레인: 카탈로그에 진행 중 카드가 없으므로(P3-1 §8-2) **레인 골격+안내 문구만** 둔다("진행 중 연구는 카탈로그 확장 후 표시 — 현재는 핸드오프 문서 참조"). 임의 하드코딩으로 채우지 않는다.

**상호작용**: `series` 선택 필터, `q` 검색, 카드 클릭=펼침, 원장 행 클릭=`raw_json` 원문 모달. 편집·코멘트 없음.

**수용 기준**:
1. 7계열 카드가 전부 표시되고 `verdict` 문구가 카탈로그 원문과 바이트 동일.
2. 모든 카드에 원장 행 번호(비연결 계열은 0행 표기)와 리포트 경로가 보인다.
3. 어떤 카드에서도 수정 UI가 활성화되지 않는다(R10).
4. 칩 매핑표에 없는 verdict가 중립색으로 안전 강하한다(고의 미지 값 시험 1회).

## 3. V2 — 함정 지도 히트맵

**목적**: O-1G 144셀 + S-v1/V2-A 셀을 인터랙티브 히트맵으로 — "피해서 다닐 구역"의 **설명** 시각화(veto 아님, R3).

**데이터 계약**: `GET /research/cells?source=...`(P3-1 §4.3). 파티션 실측: `sv1_l0`(288)·`sv1_l1`(288)·`v2a_full`(192)·`v2a_pilot`(192)·`o1g`(144 = 갭 6×시총 3×진입창 2×출구 4). 파티션 탭 목록은 오류 응답의 `allowed[]` 또는 초기 질의로 동적 구성(P2 확장 시 코드 무수정).

**렌더링 규칙**:
- 지도 선택 탭: ① O-1G — x=갭 밴드(`gap_label`: lt0/0-2/2-5/5-10/10-20/ge20), y=시총 밴드(`mktcap_b`: 0/1/2 — 라벨은 `extra.mktcap_label`), 상단 토글=진입창(`win_label`) × 출구(`label_kind`) ② S-v1(l0/l1) — x=`time_label`, y축은 `axis_set`에 따름: `time_ud`=y=`updown_q` 2축 / `time_mc_ud`=시총×등락율 3축 좌표 동시 보유(y=`updown_q`, `mktcap_b`는 소지도(스몰멀티플) 분할 — 택일 셀렉터 아님) ③ V2-A(full/pilot) — `label_kind`(h300/l3) 토글.
- 셀 색 = `ci_low` 단방향 스케일(R2). `insufficient` 회색(R1). 셀 내 텍스트 최소화(색+툴팁).
- 셀 툴팁: `n`·`n_candidates`·`mean_net`·CI·`median_net`·`p_net_ge0`·`p_net_ge1`·MFE/MAE(있는 파티션만)·연도 정보 — sv1·o1g 모두 `year2022_mean` 등 전용 연도 컬럼에서(로더 매핑 정정 반영), **o1g의 `p_one_sided`·`year_same_sign_pos`는 `extra`에서**(P3-1 §4.3 파티션별 채움 실측). null 필드는 "—" 표기(0으로 위장 금지).
- 판정 배너 상시(R11 교정 문구): O-1G 탭 = "FDR 생존 0 · 현재 축·온셋·비용 가정에서 평균 양EV 셀 0 — 갭+20% 추격 최악"(R11 예시의 '고정지평' 한정어는 h300 단독 지도 전용 — O-1G는 출구 4종(h60/h120/h300/l3) 병기 지도라 의도적으로 제외). S-v1/V2-A 탭 = "현재 축·온셋 라벨은 챔피언 우위를 포착하지 못함(칸-조준 KILL — h300·L3 교차)".
- 워터마크: 해당 파티션의 `label_tag` 원문(§1.2 — 4종 실측 문자열) + 요약형 "설명 지도(veto 아님)". `v2a_pilot`은 `label_tag`의 "파일럿 참고" 문구를 추가 배지로.

**상호작용**: 파티션·축·출구·진입창 선택, 셀 hover 툴팁, 셀 클릭=상세 패널(연도 분해·분위수·`extra` 원문). 셀 다중 선택·병합 통계 없음(R6).

**수용 기준**:
1. `insufficient=1` 셀이 항상 회색이고 어떤 수치도 노출하지 않는다(전 파티션 표본 검사).
2. 색상 범례가 `ci_low` 기준임을 명시하고, `ci_low>0` 셀이 없을 때 수익색이 화면에 존재하지 않는다.
