## 1. 창·데이터 (원장 준수)

- 측정 창: **발견 가용 2022-03-23 ~ 2023-12-31 (437일)만.** known 2025·조건부 2024 미접촉.
- 표본 단위: 관심종목=1인 (종목, 초) 그리드(L0) 중 **진입창 내** 시점. 서지 온셋(L1)과의 교차는 보조 통계로만.
- 기반 상수: V2-A 승계 — 등락율 경계 아님(본 연구는 갭 축), 비용 = 수수료 0.015%×2 + 연도 세율(2022=0.23%/2023=0.20%) + 2틱 불리체결.

## 2. 갭 공식 (감사 §7 필수 항목)

- 전일종가 = 현재가 / (1 + 등락율/100) — same-row 봉인 파생(스키마 v1 계열).
- **시가갭(%) = (시가/전일종가 − 1) × 100.**
- 결측·이상 처리: 시가 ≤ 0, 전일종가 ≤ 0, 등락율 = −100 → 표본 제외(제외율 보고). 갭은 일·종목당 상수(당일 시가 기준)이며 행마다 재계산 값이 동일함을 스팟 검증.

## 3. 조합표 (측정 전 고정 — 전수 측정, 사후 추가·재구획 금지)

| 축 | 구간 (고정 경계) | 수 |
|---|---|---|
| 시가갭 | (−∞,0) / [0,2) / [2,5) / [5,10) / [10,20) / [20,∞) | 6 |
| 시가총액(억) | <1000 / 1000~3000 / 3000+ | 3 |
| 진입창 | 09:00:00~09:04:59 (주) / 09:05:00~09:09:59 (보조 비교) | 2 |
| 출구 | h60 / h120 / h300 (고정지평, 교정 비용) / **L3**(RR8_12 출구 조건부 — V2에서 100% 등가 인증된 라벨) | 4 |

**판정 족 크기 = 6×3×2×4 = 144 셀** (다중검정 분모로 봉인). 상관·3D·시각화는 이 조합표의 서술 통계이며 추가 판정 아님.

## 4. 셀당 기록 지표

n, mean_net(비용차감), P(net≥0), P(net≥+1%), median, q25/q75, MFE/MAE 평균, 일자 블록 부트스트랩 95% CI(mean_net, n_boot 400), 연도별(2022/2023) mean 부호, censor/제외율.

## 5. 판정 기준 (측정 전 봉인)

| 판정 | 기준 |
|---|---|
| **가능성 있음(strong)** | BH-FDR(q=0.10, 분모 144) 생존 ∧ mean_net CI 하한 > 0 ∧ n≥2,000 ∧ 연도 동부호(+) 셀 ≥ 1 |
| 약신호(weak) | mean_net 점추정 > 0 ∧ 연도 동부호(+) ∧ n≥2,000 (CI 미충족) — 보고만, 후보화는 별도 봉인 |
| **kill** | 전 셀에서 mean_net CI 상한 < 0 → "갭×시총×진입창 **단순 조합**은 기각" (조합에 가드 절을 더한 확장은 별도 사전등록의 몫) |
| insufficient | n<2,000 셀은 판정 금지 표기 |

주의(반증 대조 상속): E2 개장갭 **단독** FDR 0/138 전례 — 본 연구는 갭×시총×시간×출구 결합이므로 재포장이 아니나, kill이 나오면 그 계보를 잇는 부정 지도로 기록한다. "소수 종목 큰 베팅"의 용량 검증은 본 연구 범위 밖(O-5 엔진 스윕, U-7 승인 후).
