## 0. 쉬운 요약 — 이 계획이 하는 일

**산 전체의 지도를 그린다.** 지금 가진 데이터(tick 952일, min 213일)를 "시간대 × 시가총액 × 시장상태" 칸으로 나눠, 칸마다 "N분 뒤 오를 확률 / 실제로 남는 돈(비용 차감) / 표본 수 / 연도별 안정성"을 미리 계산해 **영구 통계 DB**로 만든다. 이후 모든 조건식 발굴(합성 단일식의 절 추가, 진입금지 규칙, 청산 개선)은 이 지도 위에서 시작한다. 지도를 그리기 전에 **장부(창-지위 원장)**부터 만들어 "이미 본 데이터로 자기 채점하는 함정"을 막고, **전당 랭킹**으로 진짜 최고 시드를 확정한다.

### W1c — 실전 승격 규약

데이터 검증 상한 = "감독형 후보". 승격 = v4 감독형 프로토콜(소액·킬스위치·09:00~09:30 감시) 실전 성적 + 실체결가로 tick2/3 상수 캘리브레이션. 채점표 = **총수익·일평균 거래수·손익비**(v3-2), MDD는 킬스위치 한도로만.

### W3 — S-트랙 설계 연구 (사용자 아이디어 고도화)

**쉬운 설명**: 지도를 그리기 전에 "칸을 어떻게 나눌지, 칸마다 뭘 적을지"를 데이터로 정한다. 임의로 정하면 칸이 너무 잘거나(표본 부족) 너무 굵어진다(신호 뭉개짐).

**W3-1 설계 질문 목록 (연구로 확정할 것)**:

| 질문 | 확정 방법 |
|---|---|
| Q1 셀 차원: 시간대·시가총액·등락율·서지배수·체결강도 중 어떤 조합? 차원 수 상한은? | 데이터 프로파일링: 각 후보 차원의 조건부 EV 기울기(십분위 스프레드)를 측정 — 기울기 없는 차원은 제외. 차원 수는 "말단 셀 중위 표본 ≥ 2,000"을 만족하는 최대로 |
| Q2 버킷 경계: 등분위(quantile)인가 고정 경계인가? | 발견 가용 창(2022-03~2023-12)의 분포로 등분위 경계 산출 후 고정(경계도 봉인 대상 — 사후 조정 금지). 시가총액·시간대는 해석 가능한 고정 경계(예: 시총 <500/500-1000/1000-3000/3000+억, 시간대 1분/5분 버킷 2계층) |
| Q3 라벨 지평 N: tick(초 단위)·min(분 단위) 각각 몇 개? | tick: {30초, 60, 180, 300, 600} (09:30 창 한계 내), min: {1, 3, 5, 10, 20분}. 우측 절단(09:30/15:18 도달) 처리 규칙 명시 — 절단 비율 기록, 절단 시 보수적 마감가 청산 |
| Q4 라벨 정의: 어떤 수치를 칸에 적나? | 필수 8종: 상승확률 P(net≥0), P(net≥+1%), 평균 net 수익률(**tick2 비용 차감**), 중앙값, q25/q75, MFE/MAE 평균, 표본수 n, 부트스트랩 CI. 보조: 승률·손익비 분해, 연도별(2022/2023) EV 부호 |
| Q5 표본 단위: 모든 초/분(그리드)인가, 전이 시점인가? | **2계층**: L0 그리드(전 시점 — 기저율 지도)와 L1 온셋(상태 진입 시점 — 발화 정합 지도, RC-2 교훈). 두 층 다 적재하고 용도 구분(L0=지형, L1=진입 후보 평가) |
| Q6 변수 상관·중복 지도 | 후보 차원 변수 간 스피어만 상관행렬 + 정보계수(IC: 변수 값 ↔ N분 후 수익 순위상관) — 중복 차원 제거 근거 |
| Q7 저장 스키마·위치 | 신규 SQLite `docs/research/condition_research/research_runs/alpha_restart_20260710/stats_map/stats_map.db` (원본과 물리 분리). 테이블: `cells_l0`, `cells_l1`, `corr_matrix`, `build_receipts`(입력 일자 범위·행수·sha·생성 시각). **git에는 DB 파일 대신 스키마 정의·빌드 영수증·요약 JSON만 커밋**(대용량 바이너리 커밋 금지) |

| Q9 다중비교 규율 연동 | 지도에서 셀을 "후보화"(조건절로 승격 시도)하는 순간을 n_trials 1로 계상(W1a 규약). 지도 조회 자체는 자유(가설 생성) |
