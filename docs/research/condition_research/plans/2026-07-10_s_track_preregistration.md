## 2. 표본 정의

- **L0 (지형 지도)**: 관심종목=1(moneytop 게이트)인 (종목, 초) 그리드 전 시점. 09:00:00~09:30:00.
- **L1 (온셋 지도)**: 서지 온셋 시점 — `초당거래대금 > 초당거래대금평균(30) × 2.0`의 FALSE→TRUE 전이(직전 초 미충족 → 당해 초 충족). 동일 종목 연속 온셋은 30초 쿨다운.
- 컬럼 접근: 이름 기반(UTF-8 정상 실측). **시가총액 = 저장 index 14**(w3 정정 — 문서 잠정치 13은 전일동시간비였음).

## 3. 셀 축 (프로파일링 Q1/Q2 채택)

| 축 | 버킷 | 근거 |
|---|---|---|
| 시간대 | 5분 × 6버킷 (0900/0905/0910/0915/0920/0925) | 절단·표본 균형 |

- **1차 지도 = 2축(시간대×등락율)**: 전 칸 n≥2,000 보장(중위 60,935).
- **2차 지도 = 3축(+시총)**: n≥2,000 미달 칸은 `insufficient` 표기(판정 금지 — P3 교훈).
- 1분×4×4 완전 3D **금지**(46% 칸 표본 미달 실측).
- **제외 축**: 서지배수(연속 EV 평평 -0.027pp — L1 온셋 게이트로만 사용), 체결강도(+0.071pp 평평 — 축 보류), 잔량비(비단조 — 라벨 보조 분해로만).

## 4. 라벨 (칸당 기록 항목 — 필수 8종 + 보조)

지평 h: **tick {60, 180, 300}초** (30초는 옵션 컬럼), 600초 제외(절단 33%). min 오버레이: {3, 5, 10, 20}분.

| # | 항목 | 정의 |
|---|---|---|
| 1 | n | 표본수 (절단 제외 후) |
| 2 | P(net≥0) | 상승확률 (비용 차감 후 0 이상) |
| 3 | P(net≥+1%) | +1% 초과 확률 |
| 4 | mean_net | **비용차감 순수익률 평균** — 확률 옆 필수 병기(lift≠돈) |
| 5 | median / q25 / q75 | 분포 형태 |
| 6 | CI_low/CI_high | 일블록 부트스트랩 95% CI(mean_net, n_boot 400) |
| 7 | year_sign | 연도별(2022/2023) mean_net 부호 |
| 8 | censor_rate | 절단 제외율 |
| 보조 | winrate·payoff(승률·손익비 분해), MFE/MAE 평균(h내 최대유리/불리) | v3-2 채점표 정합 |

- **비용식(봉인 상수, `alpha_lab/dataset/labels.py`와 패리티 필수)**: 진입 = 매도호가1 +2틱(KRX 밴드 단계 통과), 청산 = 매수호가1 −2틱, net = (sell×(1−0.0018−0.00015) − buy×(1+0.00015)) / (buy×(1+0.00015)). 패리티 검증: 표본 1,000행에서 labels.py 산식과 max_err=0 확인(프로파일링에서 기실측).
- **절단 규약**: 장 마감 h초 이내 표본 제외(깨끗한 계단 절단 실측 — tick h300은 09:25 이후만 해당). 제외율을 censor_rate로 기록.
