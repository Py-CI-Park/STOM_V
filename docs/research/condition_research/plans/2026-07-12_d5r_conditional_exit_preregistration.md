## 0. 결론 먼저

**현직 챔피언 매도식을 1바이트도 바꾸지 않고 보존한 채, 매도 네임스페이스의 인과 관측 변수(보유시간·최고수익률·수익률)만으로 give-back(반납)을 조준하는 청산 변형 10개를 사전 봉인한다.** 목적함수는 총수익 상향(손익비 개선이 1차 경로)이고 MDD는 킬스위치 제약으로만 둔다(프로그램 v3-2). 판정은 발견창(2022~2023) 리플레이 triage로만 하며, 채택 기준은 총수익 개선폭 하한 + 일자블록 CI 하한>0 + RR8 가문 내 방향 일관성(GPTAUTH는 영향거래 0이라 제외) + 연도(2022 vs 2023) 동방향이다. 엔진 확인은 예산만 봉인하고 **별도 승인** 전에는 실행하지 않는다.

**이 초안이 가장 조심하는 두 가지**: ① 2024는 이 계열(청산 레버)에 대해 이미 known이다(P5가 개봉) — 그래서 발견창은 2022~2023 **2개 연도뿐**이고 최종 증명은 감독형 실전이다. ② give-back 질량의 다수(44.9%)를 담는 "저피크 왕복 손실 거래" 조준(Family B)은 **P5에서 기각된 전역 time_stop과 가장 가까운 레버**다 — 그래서 발동집합 겹침률 상한과 kill-1(레짐 위장 자기기각)을 최우선 방어로 둔다.

## 0.5 쉬운 설명 (등산 비유 — W6a 상속)

W6a가 그린 지도는 "산을 오르다 내려온 뒤에야 아까 저기가 정상이었구나를 안다"는 것이었다. give-back = 정상(보유 중 최고수익률)에서 하산까지 반납한 높이다.

이 사전등록은 그 지도 위에서 **"언제·어떻게 하산할지" 규칙 세 종류**를 공정하게 시험한다.

- **Family A (트레일링 완화 = 정상 근처에선 서두르지 않기)**: 승자가 정상 근처일 때 조금 더 버틴다(피크의 60%까지 반납하면 팔던 것을 → 50~55%까지 버팀). 승자를 더 오래 태워 손익비를 올린다. 대신 반전하면 더 많이 반납할 위험.
- **Family B (저피크 왕복 조기 절단 = 산기슭에서 헤매면 일찍 집에 가기)**: T초가 지났는데도 아직 산기슭(최고수익률<x)이고 본전 아래(수익률<y)면, 이 산은 포기하고 일찍 손절한다. 패자의 손실을 줄여 손익비를 올린다.
- **Family C (하드손절 국소 이동 = 비상 대피선 조정)**: -5% 비상 손절선을 -4~-4.5%로 살짝 올려 큰 손실 꼬리를 더 일찍 자른다.

**정직한 한정(감사 §9 상속)**: 지도의 정상 높이(MFE)는 내려와서야 아는 사후 최대값이다. 지도는 "반납이 어디서 나는지"는 알려주지만 "그 반납분을 다 회수할 수 있다"는 뜻이 아니다. 그래서 이 문서는 규칙을 눈으로 고르지 않고, **그 규칙이 한 번도 결과를 안 본 방식(사전 봉인 → 리플레이 → 별도 엔진)으로 실제 총수익을 올리는지**를 검정한다. 주의: 지도의 give-back은 청산시점 MFE로 계산하지만, 실전 절은 매 틱의 **누적 최고수익률**(그 순간까지의 최대, 인과 관측 가능)을 쓴다 — 둘은 청산 순간에만 같다.

W6a 포렌식(발견창 1,658거래, RR8 3종 유니크 dedup 1,188)이 확정한 절 표적:

| 절 표적 | n | 평균 give-back | 평균 실현 | 대응 Family |
|---|---|---|---|---|
| 트레일링(피크60%) | 137 | 1.82%p | +1.97% (승률 98.5%) | **A** (승자 연장) |

## 4. 후보 격자 봉인 — 10개 (상한 12) (`design_verdicts` refuted-fix #1: 사전값 봉인)

전 후보 공통 규율: **매수식 byte-exact 무수정**(sha 348c5181…, 신규 회전율 0), 매도식은 **현직 절 체인 순서 보존** + 지정 절만 수정/추가, 사용 변수는 매도 exec 네임스페이스 실측 바인딩 스칼라 3종(보유시간[초]·최고수익률[누적최대]·수익률)뿐, `매도=True` 직전 매도조건명 주석으로 절별 attribution 자동 확보(`back_static.py:202 SetSellCond`). 기준 챔피언 = RR8_12(sell sha 8ef01e0e…).

현직 절 `elif 최고수익률 > 3 and 최고수익률 * 0.6 >= 수익률:`의 keep 배수만 하향(발동 더 늦춤 = 승자 더 오래 보유).

### Family B — 저피크 왕복 조건부 조기 절단 (패자 조기 처리, 신규 절 추가)

신규 절을 **`elif 시가총액 < 10000:` 블록의 최하단 sub-elif로 추가**(절 순서 보존 — 현직 하드/트레일/각도급락/MA 절이 먼저 평가되고 어느 것도 발동 안 한 잔여 집합에만 도달). 챔피언 매수식이 시가총액<3000만 매수하므로 이 블록은 전 포지션에서 진입된다. 시분초<93000 게이트 안이며 T≤240s·진입 09:00~09:05라 청산은 09:09 이전, 절단 무관.

```python
        # ... (현직 각도급락 3절 + MA이탈익절 절 원문 유지) ...

            매도 = True
```

| 후보 | T(초) | x(최고수익률 상한) | y(수익률 상한) |
|---|---|---|---|
| B1 | 120 | 1.0 | 0.0 |
| B2 | 120 | 1.5 | 0.0 |
| B3 | 180 | 1.0 | 0.0 |
| B4 | 180 | 1.5 | 0.0 |
| B5 | 240 | 1.0 | 0.0 |
| B6 | 240 | 1.5 | 0.0 |

- **T=300은 격자에서 제외**(feasibility-fix #1 반영): 발견창 pooled 보유≥300 = 343(하드 상한)이라 저활력·dedup 후 하한 미달 확정. 격자를 T∈{120,180,240}로 하향(feasibility-fix 권고 (b)).
- **x가 핵심 차별자**: 최고수익률 상한이 없으면 이 절은 전역 time_stop으로 수렴한다(refuted-fix #3). x∈{1.0,1.5}로 "한 번이라도 x% 이상 간 거래(느린 승자)는 절대 자르지 않음"을 구조적으로 강제.

### Family C — 하드손절 국소 이동 → **격자 제외 (봉인 결정 §14-2)**

현직 절 `if 수익률 >= 9 or 수익률 <= -5.0:`의 손절 쪽 이동(-4.5/-4.0)은 초안에 있었으나 **봉인에서 제외**한다. 근거: 발동 모집단 n=26으로는 어떤 CI 판정도 성립하지 않고(추정 MDE가 채택 하한의 6배 이상), FDR 분모만 낭비한다. 이 제외는 아이디어의 kill이 아니라 **"판정 불가 지역" 기록**이다 — 표본을 늘릴 새 데이터가 없으므로 사실상 종결.

**격자 요약(봉인)**: A(2) + B(6) = **8 후보** (상한 12). 두 계열 모두 W6a 실측 절 표적에 1:1 대응하며, 성격이 정반대(A=승자 연장, B=패자 조기 처리)라 격자 균형을 유지한다.

## 5. 표본 하한 — W6a가 T별 하한을 정한다 (feasibility-fix #1·#3·#4)

**측정 시점 규칙(feasibility-fix #4)**: 영향 모집단은 exit 시점 값이 아니라 **hold==T 시점의 (누적 최고수익률, 수익률)**로 정의한다. R1 포렌식이 tick 리플레이로 t=T 상태를 재구성한다. exit-시점 프록시로 하한 판정 금지.

**dedup 규칙(refuted-fix #4·feasibility-fix #3)**: RR8 3종은 거래가 겹치므로 하한 판정은 **RR8 가문 dedup 후 유니크 거래**로 한다. dedup 키 = `(일자, 종목명, 진입시각)` — 봉인 시점 고정. 확장 여부를 결과를 본 뒤 결정 금지.

**하한 산정(W6a 상한 + 검정력 규칙)**: W6a는 exit-시점 값이므로 t=T 영향 모집단의 **하한(exit-저피크 집합 ⊆ t=T 저피크 집합)과 상한(보유≥T 전체)** 을 준다. pooled 기준:

| T | 보유≥T 전체(pooled 상한) | exit MFE<2% 저피크(pooled 하한) | t=T 영향 모집단(측정 대상) |
|---|---|---|---|
| 120 | 873 | 382 | [382, 873] 구간, R1이 dedup 후 확정 |
| 180 | 343~873 사이 | 125~382 사이 | R1 확정 |
| 240 | 343~873 사이 | 125~382 사이 | R1 확정 |
| (300) | 343 | 125 | 격자 제외 |

**봉인 하한 규칙 (§14-1 결정 반영 — 정직한 2단 규칙)**: "검정력 80%로 하한 역산" 규칙은 **폐기**한다 — σ(Δnet)≈1.5%p 가정 시 +0.10%p 검출에 n≈1,400이 필요해 발견창 모집단(dedup 상한 <900)으로는 어떤 후보도 성립 불가, 즉 규칙이 형식화된다. 대신:
1. **하드 백스톱(판정 자격)**: Family B = RR8 dedup 영향거래 ≥ **150** ∧ 연도별 ≥ **40**. Family A = ≥ **100** ∧ 연도별 ≥ **30** (모집단 137의 현실 반영 — 단 §7의 강화 효과 하한으로 상쇄). 미달 셀 = inconclusive, triage 채점 전 제외(엔진 예산 0).
2. **MDE 병기(오독 방지)**: 후보별로 일자블록 부트스트랩 SE 기반 최소 검출 가능 효과(MDE)를 결과에 병기 — "검정력 미달로 미검출"과 "효과 없음"을 구분해 보고한다. 채택은 어차피 CI 하한>0이 지배하므로(작은 표본은 큰 효과만 통과) 자기교정적이다.

## 8. 재포장 방지 — 발동집합 겹침률 상한 (refuted-fix #3, Family B 전용)

P5 전역 time_stop 300은 보유≥300 도달 거래 584건을 최고수익률 무관하게 전부 절단했다. Family B가 "이름만 조건부"가 되지 않으려면 발동집합이 그와 실질적으로 달라야 한다.

| 게이트 | 봉인 문턱 |
|---|---|
| 겹침률 | `|절B 발동집합 ∩ {보유≥T 도달 거래}| / |{보유≥T 도달 거래}|` ≤ **0.50** (§14-3 결정) |
| 근거 | "조건부"라는 이름이 성립하려면 전역 절단 모집단의 **과반을 자르지 않아야** 한다(과반 초과 = 이름만 조건부). W6a 실측 자연 겹침 추정(보유≥120 중 exit 저피크 43.8%, MFE<1%는 그 이하)과 정합 — 정상 후보는 마진을 갖고 통과 가능 |
| 민감도 | 0.55·0.60 기준의 판정 변화를 **보고만**(판정은 0.50 고정 — 사후 완화 금지) |
| 초과 시 | 해당 (T,x,y)는 전역 time_stop 동등으로 판정·폐기(x 상한이 사실상 무력) |
| Family A | 기존 절 수정이라 전역 time_stop과 구조적 겹침 ~0 — 본 게이트는 Family B에만 적용 |

kill-1(레짐 위장)과 병행: 겹침률이 낮아도 R1에서 보유상태 분리가 실패하면 폐기.

## 10. Kill 기준

1. **kill-1(레짐 위장)**: R1에서 time_stop 도움/해악이 보유상태로 분리 안 되고 연도 효과로만 설명 → 즉시 종료(엔진 0회).
2. **kill-2(표본 하한)**: RR8 dedup 후 영향거래가 검정력 하한(§5) 미달 → 해당 셀 inconclusive, 엔진 미사용.
3. **kill-3(triage 방향)**: 연도 방향 뒤집힘 또는 RR8 3종 중 동일 방향 <2 → 후보 폐기. 전멸 시 프로그램 종료.
4. **kill-4(겹침률)**: Family B 겹침률 >0.55 → 전역 후보 재포장으로 폐기.
5. **kill-5(엔진, 별도 승인 후)**: P5 기각 기준선 발동 — CI 0 포함 / 2024·2025 역방향 / 2024 MDD 악화 / 거래수 변화 ±20% 초과 → 기각·현행 유지.
6. **kill-6(포트폴리오)**: 5번째 슬롯/배분 분할이 walk-forward 4창 중 3창 이상에서 총수익 비개선 또는 MDD 킬스위치 초과 → 감독 리포트 자산으로만 강등.

## 11. 엔진 예산·n_trials (격자 봉인 시점 합산)

- **triage(엔진 0회)**: 후보 8개(A2+B6, §14-2로 C 제외) 각 반사실 채택 검정 = **type-b 8건**(감사 §6.3: 후보 단위 시행 계상). **FDR 분모 = 8.**
- **엔진 확인(type-a, 별도 승인 전 미집행)**: triage 생존 후보(≤3 예상) × 챔피언 2종(rr8_12 + RR8_0) × A/B × 발견창 2창(2022·2023) = **≤12회 봉인**. GPTAUTH·2024·2025 창 제외(known). 통과 시 RR8_21 확장 +≤4회. **상한 16회**.
- **합산 봉인 예산**: type-b 8 + type-a ≤16 = 시행 24. 전역 n_trials 원장에 합산 기록. 구 프로그램 누계(1,100+) 병기.
- 격자·라벨·게이트 설계(본 문서)는 적응적 설계 결정으로 원장에 별도 기록.

## 14. 봉인 결정 기록 (메인 세션, 2026-07-12 — 초안 §14 미결 3건의 해소)

1. **검정력 규칙 교체(§5 반영)**: "80% 검정력으로 하한 역산"은 발견창 규모에서 성립 불가(필요 n≈1,400 > 가용 <900)라 형식화됨 → 폐기. 대신 ① 하드 백스톱(B: ≥150/연 40, A: ≥100/연 30) = 판정 자격, ② MDE 병기 = "미검출 vs 효과 없음" 구분, ③ 채택은 CI 하한>0이 지배(자기교정적). 정직성 원칙: 통계 보증을 흉내 내지 않고 한계를 수치로 공개한다.
2. **Family C 제외, Family A 존치(§4·§5·§7 반영)**: C(n=26)는 판정 불가 지역으로 제외(FDR 분모 낭비 방지). A(n=137)는 존치하되 백스톱 완화(≥100)의 대가로 **효과 하한을 +0.20%p로 상향** — 작은 표본은 큰 효과만 인정. 격자가 B로 수렴하는 위험(§0)은 인정하되, A 존치로 "승자 연장 vs 패자 절단" 양방향 균형을 유지하고, B의 재포장 위험은 겹침률(§8)+kill-1이 방어한다.
3. **겹침률 상한 0.50 확정(§8 반영)**: 근거 = "전역 절단 모집단의 과반을 자르지 않아야 조건부라는 이름이 성립" + W6a 자연 겹침 추정(43.8% 이하)과 정합. 0.55/0.60은 민감도 보고만(판정 고정). R1 후 데이터 기반 재산정은 **하지 않는다** — 측정 후 문턱 조정은 사전등록 원칙 위반.

추가 결정: 반기(H1/H2) 방향 부호를 보조 보고로 병기(§7 — 채택 조건 아님). 이로써 초안의 모든 미결이 해소되어 본 문서는 봉인본이다.
