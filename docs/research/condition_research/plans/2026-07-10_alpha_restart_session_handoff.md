## 0. 가장 먼저 읽을 결론

1. 사용자 지시: **"이 브랜치의 5개 아이디어는 성과가 없었다. 제약 전면 재검토를 허용하니 처음부터 다시 시작한다는 자세로, wt-dev 루프와 다른 방법으로 tick/min DB 분석 → STOM 조건식 → 실수익 경로를 연구하라."** 이후 "ultracode 사용해서 진행 가속화"로 멀티에이전트 오케스트레이션이 승인됐고, **개정 v2에서 "수집 없음·고정 DB 시스템·코인 보류·쉬운 설명·v4 대시보드 연동" 5건이 추가 지시됐다.**
2. 세션 결론(개정 v2): **"새 단독 매수 알파 채굴"을 "v4 포트폴리오 개선"으로 문제를 바꾸면 지금 있는 DB로도 풀 수 있다.** 데이터는 더 늘지 않으므로 성패는 ① 같은 데이터를 다시 볼 때마다 기록하는 장부(전역 창-지위 원장+전역 n_trials)로 자기기만을 막는 것 ② 데이터로는 "감독형 후보"까지만 올리고 **최종 증명은 소액 실전 운용**으로 하는 것에 달려 있다.
   - **쉬운 설명**: 우리 데이터는 새 문제가 안 나오는 기출문제집이다. 이미 본 페이지로 채점하면 성적이 뻥튀기되므로 "본 페이지 장부"를 적고, 진짜 실력은 실제 시험(소액 실전)으로 확인한다.
3. 12개 연구 방향을 독립 설계하고 방향별 3렌즈 적대검증(36회) + 완결성 비평 + 정량 실사 6종을 통과시켰다. **FAIL 판정 0** — 전 방향이 PASS 또는 FIX(수정 조건부).
4. 확정 순위(개정 v2): **0순위 D11 개정판(고정 DB 증거 규율 인프라: 원장·카운터·봉인 가드·실전 최종심판 제도화 — 수집 컴포넌트는 기각)** → 1군 D3(원장+손실꼬리 베토)·D7(보완성-표적, 공용 심판)·D9(moneytop churn)·D6(분위수 지도) → 2군 D5(수정판 조건부 청산)·D12(사실 정정 후)·D8+D10 병합(min 트랙, audit-grade 상한·승격은 실전 성적으로만) → 3군 연기 D1·D2(D6 조건부)·D4(불가 인증만). **코인·일봉 스윙(백필 필요)은 보류.**
5. 기존 봉인 결론(C-001~C-015, RC-0~RC-4)은 하나도 뒤집지 않았다. 재검토로 **완화**된 것은 프로세스 제약(docs-only, "단독 조건식 금지" 뉘앙스 → 채택 기준 교체)이고, **신설**된 것은 전역 창-지위 원장·전역 n_trials·공용 개봉 1회·5번째 슬롯 공용 심판이다.
6. 최종 산출물의 정의(개정 v2): 조건식 몇 개가 아니라 **"존재하는 DB에서 조건식을 발굴하는 시스템" 4층** — ① 측정·발굴 모듈(D3/D6/D9/D5) ② 심판 모듈(D7) ③ 규율 모듈(원장·카운터·가드) ④ 운용 연결(감독형 프로토콜·v4 대시보드). 추후 코인 연구도 이 구조를 복제한다.

### 3.1 데이터

- **tick DB는 09:00~09:30만 담는다.** 5개 연도 표본일 전 테이블 스캔에서 09:30 이후 행 0건, moneytop 정확히 1,800행(1초×30분). "장중/오후 tick 연구"는 데이터 부재로 사망.
- **min DB가 유일한 장중 데이터 축**: 09:00~15:17/18 전일 커버, 57컬럼, 그날 moneytop 종목만(일 51~66종목), 2025-04-07 시작. 15:19~15:30 동시호가 미포함.
- **min 백필 사실상 불가**: OPT10080 사용 코드 0건, API는 기간지정 불가·과거 ~8개월 한도, 그리고 백필해도 OHLCV급뿐이라 57컬럼(호가·체결강도·분당금액) 재구성 불가. → min DB는 실시간 수집으로만 자란다.
- 2026-03 이후 데이터는 전 워크트리에 없다. 현재 어떤 후보도 fresh blind OOS를 가질 수 없다.

### 3.2 비용 (재계산으로 그리드 EV -1.022%와 소수 4자리 정합 확인)

- 왕복 총비용(tick2 슬리피지+수수료 0.015%×2+거래세 0.18%)은 **0.61~1.21% 준고정**(가격대·호가단위 밴드 의존). tick3는 0.81~1.10%.
- 목표수익별 잠식률(5천원/2만원/10만원 종목): +1% → **101%/121%/61% (구조적 적자)**, +3% → 34/41/21%, +5% → 21/25/13%, +10% → 11/13/7%. 손익분기 gross 0.61~1.21%.
- 단서: 비용표는 필요조건 제거이지 충분조건 아님 — 그리드 gross 드리프트 자체가 ≈0~음수.

### 3.3 문법 (ground_grammar_map.json이 정본)

- tick 조건식: 스칼라 ~50종 + 전 스칼라 N초전 함수 + 구간함수 15종(사전계산 윈도우 tick 60/150/300/600/1200, avg_list 등록 필수) + **복합조건 61종 + 매도전용 동적청산 8종 = 181개 함수**. 복합함수 공간은 어떤 채굴 사이클도 탐사 안 함(채굴은 43피처만).

- **시장 수준/횡단면 변수 전무**(지수·시장폭·VI발동수·moneytop 순위값 없음). 유일한 유니버스 변수 = `관심종목`/`관심종목N(n)`. 매수는 관심종목=1에서만 평가(엔진 강제). 전일 참조 불가.
