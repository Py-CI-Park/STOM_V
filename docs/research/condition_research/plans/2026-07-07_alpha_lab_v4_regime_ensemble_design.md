# 알파 랩 v4 설계·사전등록 — 레짐-적응 챔피언 앙상블 (2026-07-07)

> **관리자 결정 C 이행**: 데이터-우선 채굴(v1·v2·v3, 3연속 실패)을 종결하고, 야간캠페인이 실증한 방향(앙상블·레짐 적응)으로 전환. **방향이 정반대**다 — 데이터에서 새 규칙을 채굴(실패)하는 대신, **엔진에서 이미 수익 내는 검증된 챔피언들을 레짐-적응으로 조립**한다.
> **성공 정의**: OOS 봉인창(2025-01~2026-02)에서 위험조정수익(수익/MDD)이 **최선 단일 챔피언(always-on)보다 우월한 배포 가능 구성 ≥1개**. 최소 바닥 = 단일 챔피언 적응형(야간캠페인 다년 OOS 실증분)의 이 워크트리 재현.

---

## 1. 왜 이건 다른가 (v1~v3와의 근본 차이)

| | v1~v3 (실패) | v4 |
|---|---|---|
| 재료 | 데이터에서 채굴한 규칙(엔진 미검증) | **엔진 검증된 챔피언 4종**(rr8 계보 4/4 OOS) |
| 방향 | 건초더미→바늘 | 이미 찾은 바늘들을 **조합** |
| 엣지 원천 | "찾아야 함"(못 찾음) | **이미 존재**(챔피언 +15M 실증) |
| 신규성 | 신규 규칙 | 신규 **조합·타이밍**(개별 전략은 기존) |

핵심 통찰(야간캠페인 실측): 시드는 2025년 5~12월 −2.18M 잃지만, 그 약세 레짐에 다른 전략은 흑자 → **상보적 다각화**. 적응형 타이밍(자본곡선 추종 lookback=2)은 2022~2026 OOS에서 시드 MDD를 −71%(2.37M→694k) 줄이며 수익 유지 = 배포 가능 최강 결과. v4는 이를 **다중 챔피언 앙상블**로 확장.

## 2. 재사용 자산 (전부 이 워크트리 존재 확인)

- `ai_strategy_loop/fitness/adaptive_timing.py`: `apply_adaptive_timing(monthly_seq, lookback)`, `adaptive_timing_report(csv, lookback=2)`, `monthly_pnl_from_csv` — 야간캠페인 검증분.
- `ai_strategy_loop/fitness/multiyear.py`: 다년 안정성.
- 챔피언 패스포트 4종: `rr8_12_turnover_min_902_1.5`, `rr8_0_cap_max_2500`, `rr8_21_trail_keep_0.7`, `human_seed_gptauth_B_gen8` + strategy.db의 Tick_902 계열(C_T_902_905_U3_B 등, R0에서 실명 확정).
- 로컬 엔진 + 독립 DB(62GB). 공식 warm64 프로파일.

## 3. 단계 (봉인)

**R0 특성화** (엔진 ~5~10회): 챔피언 4~5종을 발견창(2022-03~2024-12)에서 백테 → 월별 P&L 시퀀스 추출 → 월수익 상관행렬(상보 쌍 식별). OOS 2025-01~2026-02는 **미개봉**.

**R1 단일 적응형 바닥** (엔진 0회, 오프라인): 각 챔피언에 `apply_adaptive_timing`(lookback=2 봉인) 적용 → 위험조정 개선 재현. 이것이 최소 성과 바닥.

**R2 앙상블 조립** (엔진 0회, 오프라인 — R0 백테 재사용): 발견창에서만 파라미터 확정·봉인:
- (a) 정적 등가중 앙상블
- (b) 적응형 앙상블(각 챔피언 적응형 후 합산)
- (c) 레짐-로테이션(직전 lookback 성과 최고 챔피언에 배정)
- 조합 가중·lookback·전환규칙 전부 발견창에서 확정 후 봉인.

**R3 OOS 블라인드** (엔진 ~5~10회): 봉인 구성을 2025-01~2026-02에 **각 1회** 적용. 비교표: 최선 단일 always-on vs 단일 적응형 vs 앙상블 (a)(b)(c). 위험조정(수익/MDD·calmar) 순위.

**R4 검증·패키지**: 성공 구성 원문·전 창 수치·배포 규칙(감독형) 동결.

## 4. 판정 (봉인)

- **성공**: OOS에서 위험조정수익이 최선 단일 챔피언(always-on) 초과 구성 ≥1 → 배포 후보 → 관리자 보고 → PR 머지.
- **부분 성공**: 앙상블이 단일 초과 못 해도, **단일 적응형이 always-on 대비 MDD 유의 개선(다년 재현)** → 그 자체가 배포 가능 성과(야간캠페인 결과의 독립 재현).
- **실패**: 적응형·앙상블 어느 것도 always-on 대비 위험조정 개선 없음 → 정직 종결, 머지는 인프라·원장 명분.

## 5. 정직한 한계

- 챔피언이 전부 rr8 계보면 상관 높아 앙상블 이득 작을 수 있음(R0 상관행렬로 사전 진단, 낮으면 (b)(c)가 (a) 못 이김을 정직 보고).
- 적응형은 "약세월 OFF=플랫"이라 상방 일부 희생(2024 휩쏘 비용) — 야간캠페인 caveat 승계.
- OOS 단일 창(2025-01~2026-02). 전환비용 미모델(감독형 배포 전제).
