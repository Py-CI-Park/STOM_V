## 0. 쉬운 요약

두 가지가 확정됐다. ① **지도(S-트랙 v1)는 정확하게 그려졌지만, 챔피언의 비밀을 보기엔 눈금이 얕았다** — "300초 뒤"라는 고정 자로 재면 챔피언 사냥터도 평균 이하로 보인다(0/4 실패, kill-2 발동). ② **사람 최고 전략(전당 19종)은 전부 시초(장 시작 직후) 사냥꾼**이고 기계 전략보다 1.6~3.2배 강하다.

그래서 다음 라운드는 세 갈래다: **(1) 지도의 자를 바꾼다** — "챔피언 매도식대로 팔았을 때"(L3 리플레이)로 다시 재서 엣지가 보이는지 확인. **(2) 후보의 원천을 사람 최고 전략으로 옮긴다**(전당-시드). **(3) 사용자 신규 아이디어 채택** — 시초 몇 분, 갭상승·돌파, 소수 종목 큰 베팅(O-트랙). 셋 다 지금 있는 데이터로, 엔진 예산 없이 시작한다.

## 3. 신규 아이디어 검토 — 시초 집중 트랙 (O-트랙, R12)

**사용자 제안 요지**: "명예의 전당이 알려주는 것은 시초 거래에서 좋은 성과를 낼 수 있다는 점. 추가로 — 장 시작 몇 분의 소규모 거래, 장 시작 후 갭상승, 차트술사의 원리 같은 돌파 등, 완전 시초의 소수 종목에 큰 돈을 매수해서 수익을 내는 것도 하나의 방법."

**검토 결론: 좋은 아이디어이며 채택한다 (O-트랙 신설).** 증거 정합성이 이례적으로 높다.

### 3.1 왜 증거와 잘 맞는가

| 근거 | 내용 |
|---|---|
| 데이터가 정확히 그 시간대만 있다 | tick DB는 09:00~09:30만 존재(실측) — "완전 시초" 연구는 우리 데이터의 유일한 강점 지대와 정확히 일치 |
| 전당이 전부 시초 사냥꾼 | W2: 인간 전당 19종·챔피언 4종 전원이 개장 직후 진입형. "시초에서 이길 수 있다"는 존재 증명이 19개 있다 |
| 문법이 갭·돌파를 표현한다 | `시가`, 시가등락율(파생), `시가돌파`/`시가지지`/`이평돌파`, `최고현재가(N)`(전고 돌파), `고저평균대비등락율` 등 — 번역갭 없음. 단 **돌파류 복합함수 90종은 어떤 채굴도 탐사 안 한 공간** |
| 큰 베팅의 슬리피지를 엔진이 검증 가능 | 엔진 체결은 호가 잔량 소진 방식 — `--betting`을 키우면 슬리피지가 내생적으로 커진다. "소수 종목 큰 돈"의 실행 가능 상한을 백테로 실측할 수 있다 |
| 수익 최대 선호(v3-2)와 정합 | 소수 정예 × 큰 베팅 = 거래당 절대수익 극대화 구조. 손익비 좋은 돌파형(짧은 손절, 긴 이익)은 비용 헛들(0.6~1.2%)을 넘는 정석 구조 |

### 3.2 반증 대조 (정직한 위험)

| 과거 증거 | O-트랙에 주는 경고 | 설계 반영 |
|---|---|---|
| E2 개장갭 이벤트 FDR 0/138 | "갭상승" **단독 사건**은 죽은 길 | 갭은 트리거가 아니라 **조합의 한 축**(갭 구간 × 돌파 유형 × 가드)으로만 사용 |
| 함정 지도: 시초 급등 소형주 칸이 평균 최악 | 시초는 평균적으로 가장 비싼 지형 | "나쁜 동네에서 바늘 고르기"가 과제 — 전당·챔피언이 이미 그렇게 이기고 있음(칸 게이트 실패가 역설적 근거) |
| W2 규모 스트레스: 고빈도 전략 20M 확장 시 -40~-46% 붕괴 | "큰 돈"은 슬리피지로 전략을 죽일 수 있다 | **베팅 스윕(1/5/10/20M)을 엔진 확인의 필수 단계로** — 용량 상한을 후보의 속성으로 기록 |
| 챔피언 칸 게이트 0/4 | 시간대·등락율 칸만으로는 선별 불가 | 선별 절은 전당 원문의 가드 조합 + 돌파/경로 함수에서 — S-트랙 v2(L3 라벨)로 측정 |

### 3.3 O-트랙 연구 질문과 단계

| ID | 질문/작업 | 방법 | 엔진 |
|---|---|---|---|
| O-1 | 갭 축 프로파일: 시가등락율(갭) 구간별 × 시총 × 시간(분)의 조건부 분포에 기울기가 있는가 | S-트랙 v2 셀 축 후보로 갭 축 추가(§4 변경 3) — 기존 파이프라인 재사용 | 0회 |
| O-2 | 돌파 유형 사전: 전당 19종+챔피언 원문에서 갭/돌파/시초 관련 절을 전수 추출·분류(어떤 돌파를 쓰나) | strategy.db read-only 파싱 (W5 Composite 조사와 병행) | 0회 |
| O-3 | 돌파 온셋 지도: `현재가 > 최고현재가(N,1)` 계열(전고 돌파)·시가돌파 온셋을 L1 이벤트로 추가하고 L3 라벨로 측정 — "돌파 순간, 챔피언식 출구" 조합의 조건부 EV | S-트랙 v2 확장 (서지 온셋과 동일 인프라) | 0회 |
| O-4 | 소수 정예 후보 사전등록: O-1~3에서 생존한 조합(갭 구간×돌파 유형×가드) ≤8개 봉인 | 새 사전등록 | 0회 |
| O-5 | 엔진 확인 + **베팅 스윕**: 후보별 1/5/10/20M 베팅으로 슬리피지 내성·용량 상한 실측, 최대매수종목수 1~3 스윕 | 엔진 (별도 승인·예산 봉인) | 필요 |

**성공 기준(v3-2 정합)**: 총수익 1차 + 거래당 절대수익(큰 베팅 유지력) + 손익비. MDD는 킬스위치 제약만.

## 4. S-트랙 재설계 v2 상세 (사전등록 v2에 봉인할 내용)

**v1 판정 요약**: 지도 자체는 정밀(재현성 sha 일치·사상 오차 0·비용 패리티 0)하나, 고정지평(h300) 자로는 챔피언 엣지가 안 보임(0/4, adv -0.111~-0.163%p). kill-2 발동 → 조준 용도 무효, 함정/veto 자산 유지.

**v2 핵심 가설(1개)**: *"자(라벨)를 '고정 300초 뒤'에서 '챔피언 매도식대로 팔았을 때의 실현 손익(L3 리플레이)'로 바꾸면, 챔피언 진입 칸이 지도에서 밝게 보인다."* — 근거: P5 실측에서 챔피언 엣지의 상당 부분이 출구(MFE 2.83% vs 실현 0.39%)와 절 조합에 있음이 확인됨. v2가 성공하면 지도의 조준 기능이 부활하고, 실패하면 "칸 해상도로는 엣지 포착 불가"가 최종 확정되어 조준은 전당-시드·Composite로 완전 이관.

### 변경 명세

| # | 변경 | 상세 |
|---|---|---|
| 1 | **L3 라벨 레이어 추가** | L1 온셋(서지·돌파) 표본에 L3_replay 라벨: 진입가 = 매도호가1+2틱, 출구 = **rr8_12 검증 매도식 리플레이**(`alpha_lab/dataset/labels_v2.py`·`distill/replay.py` 재사용, sha 봉인). 기존 h60/180/300 고정지평은 지형 지도용으로 유지 |
| 2 | **챔피언 칸 게이트 v2** | v1과 동일 사상(오차 0 증명된 파이프라인)에 L3 라벨로 재판정: 챔피언 점유 칸의 L3 mean이 전체 L1 평균 대비 우위 ≥3/4 → 조준 부활. <3/4 → 칸-조준 최종 폐기(문서로 종결) |
| 3 | **갭 축 추가 검토(O-1)** | 시가등락율(갭) 축의 십분위 기울기를 스팟 측정 → 기울기 있으면 셀 축 편입(말단 셀 n≥2,000 floor 유지, 기존 축과 교체 또는 3축 재구성) |
| 4 | **돌파 온셋 추가(O-3)** | L1 이벤트 유형 확장: 서지 온셋 외 `전고 돌파`(현재가 > 최고현재가(300,1) 등 봉인 정의)·`시가 돌파` 온셋. 온셋 유형별 지도 분리 |
| 5 | 한계 명시 | L3 라벨 지도는 "rr8_12 매도식에 조건부"라는 딱지 필수 — 다른 출구에선 다른 지도. 전당 상위 매도식 리플레이는 후속 확장(파싱 가능성 O-2에서 판정) |
| 6 | 게이트·kill | 재현성·비용 패리티는 v1 파이프라인 계승. kill: L3 리플레이 재현 게이트(현직 재현 오차 — P5 기준 0.0pp 중앙값) 실패 시 라벨 무효. 챔피언 게이트 v2 실패 시 §4 목적 종결(함정 지도 자산은 영구 유지) |

**비용**: 엔진 0회. 리플레이는 tick 경로 재생(기존 P5 인프라, 재현 게이트 통과 이력 있음). L1 86만 온셋 × 리플레이 — 배치 규모는 파일럿(1개월)로 먼저 검증.

## 5. 트랙 구조 재편 (현행 전체 구조)

```
[규율층]  창-지위 원장 + 전역 n_trials + 가드(설계) + 실전 승격 규약   ← 전 작업의 지반
```
