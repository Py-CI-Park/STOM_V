> **관리자 지시**: "성과가 보여야 PR 머지가 타당하다. 왜 문제였고 무엇이 부족했는지 상세 연구·원인 분석하고, 해결까지 가는 상세 계획을 세워라. 그 마지막이 PR 머지다." — 본 문서가 그 답이다.

## 1부. 왜 실패했는가 — 실측으로 확정한 근본 원인

### RC-0 (오늘 확정, 결정적): 채굴한 피처 공간에 양(+)의 EV 구역이 없다

v2 데이터셋(678,451표본)의 연속 실현손익 라벨(L3_net = 챔피언 매도 규율 리플레이)로 리프 76개 전수를 EV 재채점(일블록 부트스트랩 CI, n_boot 400):

```
기저(전체 그리드):  평균 −1.022% / 중앙값 −1.297%   ← 비용(tick2+수수료)이 지배하는 공간
리프 76개 전수:     EV 점추정>0 = 0개, CI하한>0 = 0개
최선 리프:          EV −0.106% ~ −0.139% (CI가 0을 걸침 — 그나마도 확증 불가)
lift 3.2 리프도:    적중률(P(≥+1%)) 36%인데 손실 꼬리가 전부 잠식 → EV 음수
```

**의미**: v1·v2의 채택 기준(lift = 적중률 배수)은 경제성과 무관했고, 더 깊게는 — **저장 54컬럼(그중 25 화이트리스트) × 임의 그리드 초**라는 표본 공간 자체에 depth≤4 규칙으로 잡히는 흑자 포켓이 존재하지 않는다. 이것이 "필터 전멸·ρ게이트 전규칙 적자·단독 매수식 전멸"의 공통 하부 원인이다.

### RC-1: 챔피언이 실제로 쓰는 정보가 화이트리스트에 없었다

챔피언(rr8_12 계열, 엔진 실측 full +15,284,154/MDD 7.14 — **엣지 존재의 증명**)과 인간 시드들의 절은 이동평균 계열·각도·체결강도평균·누적수량 등 **엔진 재계산 파생 19항**을 핵심으로 쓴다. v1 설계는 이를 "패리티 재계산기 비용" 때문에 v2로 이월(결정 D-2)했고, v2도 편입하지 않았다. 즉 **엣지가 사는 피처 공간을 두 사이클 내내 탐사하지 않았다.** (v1 설계서도 "반-C20 논거는 저장 54컬럼에만 성립"이라 한정을 명시했었음 — 한정이 옳았고, 그 밖을 탐사 안 한 것이 문제)

### RC-2: 표본화가 엔진 발화 프로필과 괴리 (stride 그리드 ≠ 신호 전이)

그리드 5초 표본은 "매초가 독립 기회"로 취급하지만, 엔진 조건식은 상태가 참인 **구간** 동안 연속 발화한다(v1 ρ게이트에서 리프 하나가 49,273거래). 라벨 통계와 엔진 거래 분포가 다른 대상을 측정 — 채굴→엔진 전이 손실의 2차 원인.

### RC-3: "챔피언 개선(필터)" 목표 자체의 구조 한계

전수→챔피언 방향은 교집합 소멸(최선 10거래/665), 챔피언→전수 방향은 표본 부족(346~671건) — 양방향 실측 종결. 챔피언은 이미 국소 최적이라 개선 여지가 좁고(P5: 청산 격자 192개 전수도 현행 미달), 올바른 목표는 **챔피언과 독립인 신규 흑자 패밀리**다(본선 야간 캠페인 실증: AI 발굴 니치가 시드 약세월 보완).

### RC-4: 아이디어별 사인(死因) 매핑

| 아이디어 | 직접 사인 | 근본 원인 연결 |
|---|---|---|
| P1 v1 (단독 매수식) | 전규칙 엔진 적자 | RC-0(공간에 EV 없음) + RC-2(발화 폭주) |
| P2 이벤트 | FDR 0/138 | RC-0의 이벤트판 — 사건 후 분포에도 비용 이길 EV 없음 |
| P3 필터 | 표본 346<2000 | RC-3(챔피언 표본 희소) |
| P5 청산 | 엔진 기각 | 챔피언 매도식이 이미 최적(개선 여지 자체가 없었음) |
| v2 필터 | 교집합 소멸 | RC-3 + RC-0 |

**요약 서사**: 우리는 "통계적으로 유의한 패턴"을 찾는 데는 성공했지만(FDR 생존·교차창 재현·ρ=0.669), 그 패턴들이 사는 공간에 **경제적 엣지가 없었다**. 엣지가 실존하는 공간(파생 지표 + 전이 시점 + EV 기준)을 이제부터 판다.

## 2부. v3 해결 계획 — "해결까지"의 상세 로드맵

### 설계 원칙 (원인별 1:1 대응)

| 원인 | v3 처방 |
|---|---|
| RC-0 채택 기준 | **lift 폐기 → EV 채택**: 일블록 부트스트랩 CI하한(mean L3_net) > 0 필수 |
| RC-1 피처 공간 | **파생 19항 편입**: avg_list=30(공식 프로파일 동결값) rolling 재계산기 + 엔진 산출 스팟 패리티(≥99.9% 일치) 통과분만 — annex 봉인 |
| RC-2 표본화 | **전이 샘플링**: 후보 규칙의 FALSE→TRUE 전이 시점만 재라벨링(발화 프로필 정합) + 일평균 발화 예산(5~60/일) 채택 조건 |
| RC-3 목표 | **신규 패밀리**: 챔피언 필터 아님. EV 생존 규칙 → **결정론 힐클라임**(엔진 피드백 국소 개선 — 이 저장소의 유일 검증 개선 경로의 기계화) |

### Phase 계획 (예산·판정·중단 기준 포함)

**P0 — 원인 확정 진단** ✅ 완료(본 문서 1부). 비용 0.

**P1 — 파생 피처·전이 샘플러·EV 채점기 구축** (엔진 0회, ~1일)
- `alpha_lab/dataset/derived.py`: 파생 19항 rolling 재계산기(avg_list=30 동결). **패리티 게이트**: 실DB 표본일에서 엔진 재계산 값과 스팟 대조 — 피처별 일치율 ≥99.9%만 채택, 결과를 `v3_feature_annex.json`으로 봉인(통과 목록+일치율).
- `alpha_lab/mining/transition.py`: 규칙 전이 시점 추출기 + 전이 기준 EV/빈도 재측정.
- `alpha_lab/mining/ev_adopt.py`: EV 채택기(부트스트랩 CI·연도별 EV·빈도 예산·FDR).
- 전 모듈 TDD. **중단 기준**: 패리티 통과 파생이 5종 미만이면 파생 편입 실효 없음 → P5-대안(밴드-생성기)으로 직행.

**P2 — 44피처 EV 채굴** (엔진 0회, ~0.5일)
- 60일 데이터셋에 파생 피처 증축(캐시 v3) → L3_net 회귀·분류 트리로 채굴 → **EV 채택 기준** 적용 → 교차창(2023↔2024) EV 재현 확인 → 후보 전이-EV 재측정.
- **판정**: EV CI하한>0 ∧ 연도별 EV>0 ∧ 전이 일평균 5~60 후보 ≥3개 → P3 진행.
- **중단 기준**: 후보 0 → "스냅샷+파생 채굴로도 엣지 포착 불가" 확정 → P5-대안으로.

**P3 — 결정론 힐클라임** (엔진 ≤200회 봉인, ~1~1.5일)
- 시드: P2 생존 후보 + 기존 V2SEED 10.
- 뮤테이터: 절 임계 ±분위 스텝, 절 추가/제거(44 화이트리스트), 매도식은 검증 hard-stop 고정.
- 평가: 공식 warm64 train 창. 수락: profit>0 ∧ (profit↑ ∧ MDD≤) ∨ calmar↑. 시드당 ≤20회.
- **판정**: train 게이트(흑자·일평균≥0.3·MDD 상한) 통과 후보 ≥1 → P4.
- **중단 기준**: 전멸 → 정직 보고 + P5-대안.

**P4 — 공식 게이트 + OOS** (엔진 ~10~20회, ~0.5일)
- 생존 후보: 2022 holdout 재현 → **OOS 봉인창(2025-01~2026-02) 각 1회, 재시도 금지** → tick3 민감도.
- **성공 = 여기 통과 ≥1개.** 이것이 관리자가 요구한 "보이는 성과".

**P5 — 성과 패키지 → PR 머지** (~0.5일)
- 성과 요약(전략 원문·전 게이트 수치·재현 명령) + 시드/원장 통합 → **이때 PR 머지 절차 개시**.

**P5-대안 (사전 명시된 피벗)** — P1/P2/P3 중단 기준 발동 시:
- **밴드-생성기 + 국소탐색**: 인간 시드(Tick_902·rr8_12)의 밴드 파라미터 공간을 Optuna식 탐색(본선 P0 검증 자산 — round-trip byte 동일 실증). 채굴이 아니라 "검증된 흑자 이웃 탐색"이라 성공 확률이 남은 경로 중 최고. 동일 게이트 체인으로 판정.
- 그것도 전멸 시: "이 도메인의 신규 알파는 현 데이터 해상도로 불가" 최종 보고 + 머지 가치 재논의(인프라·원장만) — 정직 종결.

### 일정·예산 총괄

```
기준 경로: P1(1일) → P2(0.5) → P3(1.5) → P4(0.5) → P5(0.5) ≈ 4일
피벗 포함 상한: ~7일 | 엔진 총예산 ≤260회(봉인) | OOS 봉인창은 P4 생존자에게만 1회
무결성: v3 봉인(본 계획 채택 기준·예산) + annex(패리티 피처) — 측정 전 커밋, 변경은 새 n_trials
```

### 왜 이번엔 다른가 (한 줄 검증 논리)

v1·v2는 "유의한 패턴"을 찾고 나서 경제성을 확인했다(실패). v3는 **경제성(EV CI>0)을 채택 기준 그 자체**로 삼고, 엣지가 실존함이 증명된 정보 공간(챔피언이 쓰는 파생 지표)에서, 엔진 발화와 같은 대상(전이 시점)을 측정하며, 유일하게 검증된 개선 절차(힐클라임)를 기계화해 잇는다 — 실패한 고리 전부를 실측 근거로 교체했다.
