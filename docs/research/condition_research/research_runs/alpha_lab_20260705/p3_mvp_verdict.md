## 2. 시행 결과 (봉인 파라미터 그대로)

- 시행 150 = 봉인 피처 25조합(F1~F11 × {5,10,30}s + 순간형 4) × 라벨 표적 6 — 선계상 150과 일치.
- 피처 결측 0건(25조합 전부 346표본 전면 계산 가능 — 윈도우 최소 관측 규칙 전원 충족).
- **유효 시행 0 / 150**: 전 시행 `insufficient_cell`. 4분위 셀당 최소 표본 500(봉인 §7-3) 대비
  실제 셀당 ≈86. `p_trial=1.0` 보수 잔류로 BH-FDR(q=0.05) 일괄 적용 → FDR 통과 0.
- 생존 피처 0 → 플라시보 게이트(비진입 초, seed 20260706)는 결합 대상 없음 — **미실행**(봉인
  pass_rule 상 플라시보는 survivor 에 결합하는 관문. 데이터 선택이 일어나지 않았으므로 추가
  다중성 리스크 없음).

## 3. MVP 기준 대비 판정 (연구 프로그램 §4.3 / 봉인 §7)

| 기준 | 요구 | 측정 | 판정 |
|---|---|---|---|
| 공식 생존 피처(FDR∧단조∧연도∧이중 플라시보) | ≥ 2 | 0 (유효 시행 자체 0) | 미충족 |
| 그중 꼬리(손실) 억제형(mae_suppressor) | ≥ 1 | 0 | 미충족 |
| **판정 전제: dedup 풀 N ≥ 2000** | ≥ 2000 | **454 (표본 346)** | **전제 미달** |
| 판정 전제: 유효 시행 비율 ≥ 1/2 | ≥ 75/150 | 0/150 | 전제 미달 |

**⇒ 봉인 3분지 판정 = `inconclusive`(판정 불가·표본 부족).** `abandon`(포기) 판정의 전제인
"시행은 유효했으나 생존 0"이 성립하지 않으므로, **"orderbook 축(챔피언 조건부)에 엣지 없음"
결론은 기록하지 않는다**(봉인이 명시적으로 금지). 이 판정 자체가 자산이다: 엔진 0회로,
현행 챔피언 원장 규모로는 P3 스크리닝이 착수 불가능함을 봉인 절차로 확정했다.

## 4. 구조 원인과 정직 노트

1. **판정은 Phase 0에서 수학적으로 결정돼 있었다.** MIN_CELL_N 500 × 4분위 = 2,000 = MIN_POOL_N.
   풀 < 2000이면 어떤 피처도 유효 시행이 될 수 없다. 봉인 `insufficient_action`은 "풀 N < 2000
   이면 착수 보류"를 규정하나, 본 라운드 임무 계약(피처×임계 스캔 전수 실행 + P3 계상)에 따라
   봉인 스캔을 실행하고 150을 보수적으로 전액 계상했다(반환 없음 규칙 — 이중 장부 방지).
2. **풀이 작은 이유는 부속 봉인 범위다.** 챔피언 풀 부속 봉인은 rr8_12 계보 단일 챔피언 원장
   (671건)만 확정했다. 봉인 초안이 예정한 확장 대상(r8_exclude_cap_lt_1500, hard-stop 매도 축 등)
   은 원장에 없다. 단일 챔피언 계보의 발견창 3개년 생산량은 ~454건 — 100% 커버리지라도 2,000에
   미달한다.
3. **커버리지 손실의 지배 항은 tick 결측 초다**(105/454 = 23.1%, 전부 `horizon_missing`).
   이는 봉인 결측 정책(전 지평 관측 시에만 채택)의 정직한 산물이다.
4. 측정 결정 공개: 윈도우형 '[t0]' 참조는 W 내 가장 늦은 관측 초로 해석(봉인은 t0−w 대체만
   명시); C4 감지는 파일 태그 부재로 스킵(dedup 은 P5 Phase 0에서 32개 CSV first-wins 선수행);
   종목명→코드 매핑 원천 = 엔진 dict_cn 원천(`stock_tick_back.db::stockinfo`,
   fallback `code_info.db::stockinfo`) + 거래일 tick DB 테이블 실재 검증.
