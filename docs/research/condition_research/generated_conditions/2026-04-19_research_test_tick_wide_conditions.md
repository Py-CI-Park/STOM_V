# Research Test Tick Wide Conditions

## 목적

자동 조건 연구를 위한 넓은 tick baseline 조건식이다. 이 문서는 조건식 기록용이며, 실전 전략 채택이나 수익률 최적화를 목표로 하지 않는다.

## 매수 전략명

`ResearchTest_Tick_B_090000_092800_Wide_20260419`

## 매수 조건식 코드

```python
매수=True

if 관심종목 != 1:
    매수 = False
elif not (0 < 현재가 <= 50000):
    매수 = False
elif not (90000 <= 시분초 <= 92800):
    매수 = False
elif not (0 < 등락율 <= 25):
    매수 = False
elif not (당일거래대금 > 100):
    매수 = False
elif 라운드피겨위5호가이내:
    매수 = False

if 매수:
    self.Buy()
```

## 매수 조건 요약

- `매수=True`로 시작한다.
- `관심종목 != 1`이면 `False`로 전환한다.
- `0 < 현재가 <= 50000` 범위만 허용한다.
- `90000 <= 시분초 <= 92800` 범위만 허용한다.
- `0 < 등락율 <= 25` 범위만 허용한다.
- `당일거래대금 > 100` 조건을 요구한다.
- `라운드피겨위5호가이내`이면 제외한다.
- 최종적으로 `if 매수: self.Buy()`를 실행한다.

## 매도 전략명

`ResearchTest_Tick_S_090000_092800_Wide_20260419`

## 매도 조건식 코드

```python
if 수익률 >= 3.0:
    self.Sell()

elif 수익률 <= -3.0:
    self.Sell()

elif 보유시간 >= 300:
    self.Sell()

elif 시분초 >= 92800:
    self.Sell()
```

## 매도 조건 요약

- `수익률 >= 3.0`이면 매도한다.
- `수익률 <= -3.0`이면 매도한다.
- `보유시간 >= 300`이면 매도한다.
- `시분초 >= 92800`이면 매도한다.
