## 0. 한 줄 결론

**분석 "기계"는 풍부하지만(모듈 15종) 그중 생성 루프에 실제로 환류되는 것은 절반이고,
환류되는 신호조차 "방향만 있고 숫자가 없다".** 가장 비싼 갭은 ②표시 전용으로 묶인
상관/중요도 분석과 ⑤분포 검증(MC) 부재가 아니라, **백테 없이 가설을 수 초에 검증하는
"반사실 필터 분석"이 아예 없다는 것** — 오늘 데모에서 이 방법이 첫 실행 만에
"시가총액≤2100 상한 = 총손익 106% + 2025 쇠퇴 구간 4.4배 구원" 가설을 찾아냈다.

## 1. 분석→생성 환류 지도 (실측 분류)

### 1.1 생성 루프에 환류되는 것 (8종)
| 분석 | 신호 | 주입 위치 |
|---|---|---|
| 진입 부검(analyze_trades) | 승/패 Cohen's d 상위 변수 + **방향**("높여라/낮춰라") | 다음 세대 매수 프롬프트 |
| 청산 부검(analyze_exits) | MFE 반납·MAE 깊이·손실집중 매도규칙 | 매도 프롬프트 |
| 세그먼트 avoid(T4) | 패배 구간(시총×시간) 배제 라인 | 매수 프롬프트 |
| 가정 루프(P2a/b) | 채택/기각 가정("틀린 방향 반복 금지") | 부검보다 상위 슬롯 |
| 메타 시드(P4) | run 누적 공통 변수/실패 패턴 | 생성 가이드 |
| edge_ratio 환류(토글) | 손실 MAE가 승리 대비 깊음 등 | 매도 프롬프트 |
| holdout 졸업(P5, 토글) | 최근 슬라이스 게이트 | winner 인정 게이트 |
| (6/10 신설) 계산예산·v5 원리 어휘 | 구조 지침 | 매수/매도 프롬프트 |

### 1.2 표시/동결 전용 — 생성이 못 보는 것 (7종)
| 분석 | 내용 | 소비처 |
|---|---|---|
| variable_correlation | B_* 변수 ↔ 수익률 pearson/spearman | 대시보드 Correlation 탭만 (`prompt_injected: False` 명시) |
| feature_importance | 세그먼트별 Cohen's d + **상/하위 4분위 승률 차** | 대시보드 탭만 |
| correlation_profile(combos) | 변수 조합 프로파일 | 대시보드 탭만 |
| edge_ratio 패널 | MFE/MAE/효율 | 대시보드(매도 환류 토글 제외) |
| equity_series/run_yearly | 곡선·연도 분해 | 대시보드 |
| overfit_stats(PBO/DSR, 6/10 신설) | 과적합 통계 | 동결 advisory·결정 카드 |
| adaptive_timing·multiyear 등 | 레짐/다년 | 분석 전용 |

**판정(질문①)**: "충분하지 않다." 환류 신호는 (a) 단변량 + (b) 방향만 제공 + (c) 전부
인샘플(6/5 §3.4 기진단)이고, 가장 변별력 있는 산출물(분위수 승률 차, 세그먼트별 d)은
생성이 보지 못한다. 생성기는 "전일동시간비를 높여라"는 들어도 **"얼마로?"는 모른다.**

## 2. 갭 5가지 (실측 근거 포함)

- **G1. 숫자 없는 방향 환류**: 부검 NL은 "기준을 높여라/낮춰라"로 끝난다. 임계값 제안
  (예: 승자 분위수)이 없어 LLM이 임의 숫자를 찍는다 → 6/10 실측에서 직이식 임계 5/5 음수.
- **G2. 상관·중요도 분석 미주입**: 위 1.2 — 설계부터 분석 전용. 대시보드는 사람에게만 보인다.
- **G3. 풀링이 세대를 섞는다**: /variable_correlation·/feature_importance·/edge_ratio는
  run 단위 풀링만 지원(`gen_no` 필터 없음 — 실측: cldgen train 조회 시 sources=3으로
  시드+C7+C8B 1,033거래가 **혼합**됨). 이질 전략 혼합 상관은 심슨 역설 위험. 배치 run과
  니치가 다른 세대들이 섞이는 LLM run 모두에서 해석을 오염시킨다.
- **G4. 전부 단변량**: 상호작용(예: 체결강도×시총)은 combos 프로파일 외 부재, 환류 없음.
- **G5. 분포 검증 부재(헤드리스)**: GUI 백테스트의 부트스트랩(아래 §3)이 루프/배치/동결
  경로에는 없다. 단일 경로 수익만 보고 PROMOTE/REJECT를 가른다(DSR은 6/10에 장착됨).

## 3. 몬테카를로 질문(③)에 대한 직접 답변

### 3.1 GUI 기능의 실체 (코드 실독)
`backtest/back_static_numba.py: bootstrap_test` — 거래 수익률을 **iid 복원추출**(n=10,000회)
해 복리 누적 수익률 분포를 만들고, GUI(backtest.py:247~)가 평균·95% 구간·**수익확률 pv**를
그래프 2개 중 하나로 표시한다.

### 3.2 도움이 되는가? — **된다. 단, iid 한계를 알고 써야 한다(이미 한 번 속았다)**
- **가치**: 단일 누적곡선의 운(거래 순서)을 제거하고 "이 거래 모집단이면 결과 분포가
  어떤가"를 보여준다. 거래수가 적은(31~142건) 우리 후보들의 확신도 평가에 특히 유효.
- **한계(실측된 교훈)**: iid 추출은 **레짐 군집·시퀀스 위험을 지운다**. 6/2 캠페인의
  in-sample iid MC는 P(수익>시드)=77.9%를 줬지만 해당 앙상블은 OOS 전이에 실패했다
  (6/5 검토 §4.3에 기록). iid MC pv가 높아도 레짐이 바뀌면 무력하다.
- **올바른 사용법(권고)**:
  1) **블록 부트스트랩(일 단위)**: 거래가 아니라 **일별 손익**을 주 단위 블록으로 재추출
     → 군집 보존. 산출물에 수익 분포뿐 아니라 **MDD 분포**(iid 거래 추출로는 불가)를 포함.
  2) **동결 시점 advisory**로 배선(p5-overfit-advisory에 병기): "P(연수익>0)", "MDD 95%분위".
  3) 이미 장착된 **DSR**(선택 편의 보정)과 함께 3중 분포 검증: MC(경로 운) + PBO(선택
     과적합) + DSR(다중 시도) — 서로 다른 실패 모드를 잡는다.
  4) 대시보드 Validation 탭에 **팬차트**(GUI MC 그래프의 헤드리스 대응물).

## 4. ④ "생각지 못한 방법" — 오늘 실증한 돌파구: 반사실 필터 분석

**아이디어**: 이미 생성된 per-trade CSV에서 "이 조건을 추가로 걸었다면 어떤 거래가
남았고 손익이 어땠나"를 계산한다 — 진입 조건 **강화** 방향 한정으로는 **백테스트 0회**로
가설을 검증/기각할 수 있다(남는 거래는 원 거래의 부분집합이므로).

### 4.1 당일 실증 (시드 train 307건, 2023-2025)
| 가설(필터) | 거래 | 총손익(원본 대비) | 승률 | 판정 |
|---|---:|---:|---:|---|
| 원본 | 307 | 8,631,199 (100%) | 50.2% | — |
| **시가총액 ≤ 2,100억(패자Q75)** | 245 | **9,143,437 (106%)** | 53.5% | ⭐채택 후보 — 잘린 62건 순손익 **-512,238** |
| 시가총액 ≤ 1,500억 | 171 | 7,069,156 (82%) | 57.3% | 과도(흑자 거래도 잘림) |
| 전일동시간비 ≥ 900 | 142 | 6,240,673 (72%) | 54.9% | 기각(승률↑·손익↓) |
| 회전율 ≥ 5 | 139 | 3,808,452 (44%) | 51.8% | **즉시 기각** |
| 시총≤2100 & 회전율≥3 | 185 | 6,944,878 (80%) | 55.1% | 연도별 분해 ↓ 참조 |

**연도별(결합 필터)**: 2023 4.88M→3.08M, 2024 3.37M→2.19M, **2025 0.38M→1.67M (4.4배)**.
필터는 정확히 **쇠퇴 구간(원인5)에서 작동**한다 — "최근 레짐에서 시드의 대형주 진입이
죽었다"는 가설을 데이터가 지지.

### 4.2 왜 이게 핵심 누락이었나
- 부검의 "방향" 신호와 분위수 "숫자"를 **손익 영향으로 즉시 번역**한다(G1+G2 동시 해소).
- 나쁜 가설(회전율≥5)을 백테·LLM 세대 낭비 없이 수 초에 기각 — **탐색 단가가 1/100**.
- 단 **정직성 경계**: 같은 데이터에서 임계를 뽑아 같은 데이터에 적용한 인샘플 수치다.
  채택 후보는 반드시 기존 규율(스모크→train→동결→OOS)로 보내야 하며, 반사실 결과
  자체는 advisory다. (완화 방향(거래 추가)은 이 방법으로 불가 — 백테 필요.)

## 6. 대시보드 연동 검토 결과 (질문②)

- **작동 확인(라이브 QA, cldgen train run)**: /variable_correlation(pearson, 1,033거래,
  14변수 — 시가총액 r=-0.095·회전율 +0.074), /feature_importance(시가총액 d=-0.238,
  **상위4분위 승률 33.8% vs 하위 48.3%**), /edge_ratio(MAE 패자 1.45 vs 승자 0.69 —
  2.1배 분리), Validation 탭(6/10 신설: 연도분해·부검·선택기 미리보기).
- **문제**: ①G3(run 풀링 혼합 — gen 필터 없음), ②이 패널들의 발견이 **사람 눈에서 끝남**
  (생성 환류 없음 — R2/R5로 해소), ③MC 그래프 부재(R3 팬차트로 해소).
- 종합: "보는 기능"은 견고하고 데이터 신호도 실재한다. **"보는 것"과 "생성이 배우는 것"
  사이의 다리가 없다는 것**이 연동의 본질적 공백이다.

## 7. 정직성 주의
반사실·MC·상관 전부 **인샘플 advisory**다. 어떤 수치도 동결·OOS 규율(사전선언 선택기,
OOS 사후 재선택 금지)을 대체하지 않는다. R1~R6 채택 시에도 최종 판정은 기존
