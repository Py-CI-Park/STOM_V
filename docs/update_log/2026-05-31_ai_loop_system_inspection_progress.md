## 4. 부족한 내용 (Gaps)

1. **단일기간 평가**: 모든 분석·졸업이 한 해(2025) 내부. → 연-단위 레짐 과적합을 구조적으로 못 거름(holdout도 같은 해 슬라이스).
2. **표본 희소**: 시드 105거래/년. 시간×시총×거래대금 버킷화 시 버킷당 1~3건 → 통계적 무의미.
3. **단변량 부검**: 변수 하나씩만 변별. 조건 *조합*·상호작용·맥락 미분석.
4. **ablation 부재**: "조건 X를 바꾸면 결과가 Y만큼 변한다"의 인과 측정 없음(LLM 막변형에 의존). + AST 변형은 실제 중첩 전략코드서 깨짐.
5. **생성 품질**: fresh(백지)는 과발화 garbage(거래 4932~55773), 시드 도메인지식 재현 불가. refine는 시드 천장.
6. **매크로 레짐 미관측**: 엔진이 종목별 병렬 → 전략이 "오늘 시장 전체가 나쁜가"를 못 봄.
7. **export 불완전**: 조건코드만 복사, 부가설정(주문설정·stockvars) 미동반 → 운영 동작 동일성 미보장.
