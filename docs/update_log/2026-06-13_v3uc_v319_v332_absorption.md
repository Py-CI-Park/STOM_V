# 3U_C lane V3.19~V3.32 흡수 완료 기록 (2026-06-13, V3U_C 사이클 5)

## 목적

`STOM_Version_3U_C`(V3.18 분기 후 custom 작업 4사이클 진행)를 `STOM_Version_3U`
lane(V3.32, 통합 게이트 + 시각 검증 7회 완료)으로 따라잡았다. 14개 버전 격차
(V3.19~V3.32) + V3U lane 결함 fix + 신규 worker를 3U_C가 상속한다.

## 흡수 방식 — 중요 구분 (다음 사이클 혼동 방지)

V3 propagation 체인에서 hop마다 흡수 메커니즘이 **다르다**.

| Hop | 메커니즘 | 도구 |
|---|---|---|
| `V3 공식(wt-3)` → `V3U(wt-3u)` | upstream 파일 **overlay** (pyd 제외, V3U 보정) | 수동 overlay 또는 `v3uc_ingest_pipeline.py`(E1, V3공식→V3U 전용) |
| **`V3U(wt-3u)` → `3U_C(wt-3uc)`** | **`git merge STOM_Version_3U`** (custom 보존) | 표준 git merge |

- **E1 파이프라인(`v3uc_ingest_pipeline.py`)은 본 hop에 사용하지 않는다.** docstring
  명시: "V3U lane(STOM_Version_3U)에서 실행 — 3U_C는 본 스크립트 보관만". E1은
  `STOM_Version_3` → `STOM_Version_3U` merge 전용이다.
- 3U_C는 V3U에서 분기된 lane이므로 V3U를 직접 merge하면 V3.19~V3.32 + 안전망 +
  결함 fix를 한 번에 상속하고, 3U_C custom 커밋(추가 파일)은 자동 보존된다.
