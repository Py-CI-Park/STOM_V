## §3. 5개 진입 페이지 — 단계별 활성화 순서

| 단계 | 의미 | 상태 | 영향 |

| **1단계** | 키움 환경에서 V3 한 번 시동해보기 | ✅ **완료** | 시동만 — 실거래 영향 0건 |
| **2단계** | 운영 DB를 V3 구조로 실제 전환 | ⏸ 보류 | 매매 신호 데이터 경로 영구 변경 |
