## A. 본 세션 추가 발굴 (M1~M12)

| # | 항목 | 왜 필요한가 | 비용 |
|---|---|---|---|
| M1 | **거래 중복도 분석** — 후보와 시드의 (종목,매수시각) Jaccard 중복률 | V6 결정("대체 vs 보완")의 직접 입력 — 중복 90%면 보완이 무의미, 중복 낮으면 포트폴리오 가치 | 백테0회 |
| M2 | **실거래 무결성 감사** — VI(변동성완화)·거래정지·상장폐지(생존편향) 처리 여부 | backtest 코드에서 해당 키워드 미검출(이번 세션 실측). 시가 급등 단타는 VI 빈발 영역 — VI 정지 중 체결을 허용하면 수익 과대평가. 틱 DB에 상폐 종목 포함 여부도 미확인 | 감사(읽기) |
| M3 | 용량(capacity) 한계 분석 — 주문 크기 vs 초당거래대금 비율로 실배포 가능 자본 추정 | "수익 +X만"이 베팅 1단위 기준 — 자본을 늘리면 어디서 엣지가 죽는지 모름 | 백테0회 |
| M4 | **챔피언-챌린저 운용 모니터링** — 승격 후 시드/후보 롤링 동시 측정·감쇠 경보 | 프로세스가 V6 결정에서 끝남 — 운용 "후" 단계 부재. 알파 감쇠가 근본 원인 #5였는데 감쇠 감지 체계가 없음 | 코드만 |
| M5 | 다중 시드 발굴 — 전략 DB 452+ 매수식을 3년 train으로 일괄 재평가, 제2·제3의 산 후보 | 전 시스템이 시드 1개에 앵커 — 집중 리스크. zero-LLM 배치도구로 가능 | 머신 대량 |
| M6 | **좌표 하강 2라운드** — θ* 채택점을 새 중심으로 2차 스윕 | 1-D 지도의 반복 적용 = 고차원 탐색의 저비용 근사(고원 규율 유지) | 머신 중간 |
| M7 | 파이프라인 1-커맨드화 — 스윕→θ*→재평가→동결→OOS 체인 자동화+체크포인트 | 현재 체인은 수동 연쇄 — 세션 중단 시 사람이 이어야 함(오늘 실제 발생) | 코드만 |
| M8 | **매도 구조 템플릿** — 청산 로직 자체(트레일링 형태·시간 청산)를 θ로 모수화한 지도 | **W1 실측 근거: 우세 고원 3개 중 2개(take_hard·trail_start)가 매도 다이얼** — 청산이 수익을 지배하는데 구조 탐색은 매수에 편중 | 템플릿+머신 |
| M9 | window_start 슬롯 추가 — 진입 창 시작(09:02)도 다이얼로 | 창 종료만 모수화돼 있음 — 시작 이동은 다른 유동성 레짐 | 코드 소량+머신 |
| M10 | 일중 서킷브레이커 반사실 — "연속 N패 시 당일 중단" 규칙의 CSV 사후 검증 | 운용 리스크 규칙을 백테 0회로 사전 평가(반사실 도구 패턴 재사용) | 백테0회 |
| M11 | 포지션 사이징 advisory — MC 분포 기반 베팅 배수(Kelly 분수) 제안 | 같은 조건식도 사이징이 파산/복리를 가름 — 현재 고정 베팅만 | 백테0회 |
| M12 | 지도 비교 대시보드 뷰 — 같은 슬롯의 마이크로/본/연도별 곡선 오버레이 | window_end 발산(분기 +61% vs 3년 +12%)을 즉시 가시화했을 도구 | 코드만 |

## B. 비판 에이전트 교차 검증 발굴 (N1~N10) — 파일·라인 근거 인용

| # | 항목 | 핵심 (요약) | 비용 |
|---|---|---|---|
| N1 | 체결가능성 모델 부재 | slippage_stress는 가격만 불리하게 조정 — 시초 변동성 구간의 진짜 위험은 "체결 자체가 안 됨"(호가 공백·큐 위치). 신호=100% 체결 가정 | 백테0회~소량 |
| N2 | **PBO 입력 풀 독립성 위반** | 1-D 변형들은 일별손익 상관 0.9+의 "쌍둥이" — CSCV가 함께 오르내려 PBO가 과적합을 과소평가. 유효표본수 N/(1+(N-1)ρ) 보정 병기 필요 | 백테0회 |
| N3 | 유니버스 선택 편의 | moneytop(거래대금 상위)은 그날 결과로 정의되는 룩백 필터 — 알파 중 유니버스 몫이 미측정. 대체 유니버스 플라시보 검정 | 백테 소량 |
| N4 | **미래참조 정적 검사 부재** | 계산예산은 막는데 시간무결성은 안 막음 — 진입식의 고가/최고가류 참조, 윈도우 함수 시프트 인자 감사 표 필요 | 백테0회 |
| N5 | **DSR n_trials가 스윕 56점 누락** | n_trials를 CLDGEN_%만 카운트(select_and_freeze.py) — 최대 다중성 원천인 TMAP 그리드가 빠짐. 재설계 문서 T3와 코드 불일치 | 백테0회 |
| N6 | 포트폴리오 단일 템플릿 갇힘 | 전 후보가 같은 09:00~09:05 종목군 — 저상관이 구조적으로 불가. 진입 시간대 분포 게이트 추가 + A4 우선순위 상향 근거 | 백테0회 |
| N7 | walkforward 경계 누수 | 전일동시간비 등 전일 참조 함수 탓에 fit/eval 창이 데이터 1일 중첩 — 워시아웃 갭 옵션 필요 | 백테0회(옵션) |
| N8 | 측정 재현성 미검증 | 같은 전략 2회 실행이 비트 동일한지 확인된 적 없음 — 측정 노이즈 폭을 절벽(cliff) 임계 하한으로 써야 함 | 백테 소량 |
| N9 | **plateau_score 부호 함정** | 베이스라인 음수 구간에서 "덜 나쁜 점"이 개선으로 통과(select_theta가 mean>base만 체크) — 시드 2025 쇠퇴로 임박한 현실. 절대 흑자 하한 추가 | 백테0회 |
| N10 | **결정 카드 생존자 편향** | 사용자에게 동결 1후보만 제시 — 기각 후보·차점·약세연도 거동 비교군 없이는 닻내림 유발. 최소 비교군 3개 의무화 | 백테0회 |

## C. 통합 우선순위 — 승인 패키지

### 패키지 1: 백테 0회·코드만 — **백테스트(스윕·배치) 도는 동안 병행 개발** ← 승인 시 즉시

| 순서 | 항목 | 한 줄 이유 |
|---|---|---|
| 1 | N5 n_trials 스윕 포함 | 설계-구현 불일치 — DSR 신뢰성 직격, 다음 동결 전 필수 |
| 2 | N9 절대 흑자 하한 | walkforward 오선택 방지 — V4 가동 전 필수 |
| 3 | N2 PBO 상관 경고+유효표본 | 핵심 검정의 낙관 편향 공시 — 기존 daily_correlation_matrix 재사용 |
| 4 | P2 연도분해 적격성 | 알파 감쇠를 후보 선정 단계에서 차단 |
| 5 | P3 곡선 형태 지표 | 우상향 직관의 정량화 (advisory) |
| 6 | M1 거래 중복도 | V6 결정의 직접 입력 |
| 7 | N10 결정 카드 비교군 | 의사결정 인터페이스 정직성 |
| 8 | N4 미래참조 정적 검사 | 백테-실거래 괴리의 근원 차단 |
| 9 | M2 실거래 무결성 감사(VI·생존편향) | 읽기 전용 감사 — 결과는 advisory 공시 |
| 10 | M12 지도 비교 뷰 + N6 시간분산 게이트 | 가시화·포트폴리오 정직성 |

### 패키지 2: 백테 소량 — 본 체인(A3~V5) 사이 틈에

N8 재현성 자가진단(베이스라인 3회) → P1 2-D 지도(상위 2슬롯 5×5) → N3 유니버스 플라시보 → N1 체결가능성 시나리오 → N7 워시아웃 갭 재실행 → M10 서킷브레이커 반사실

### 패키지 3: 머신 대량/구조 확장 — A4 이후 주간 계획

M8 매도 구조 템플릿(W1 근거로 우선순위 상향) → A4 min 풀세션(N6 근거로 P4보다 우선) → M6 좌표 하강 2라운드 → M5 다중 시드 발굴 → P4/P5 → M4 챔피언-챌린저(운용 진입 시) → M9/M11/M3/P6

### 불변식 (전 패키지 공통)

엔진·하드게이트·backtest_graph 무수정 / 신규 기능 토글 기본 OFF·바이트 동일 /
모든 신규 지표는 advisory — 판정 규칙(OOS) 불변 / 각 항목 완료 시 테스트+문서 동반.
