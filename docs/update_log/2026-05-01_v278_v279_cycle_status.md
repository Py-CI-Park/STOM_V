# 2026-05-01 V2.78-V2.79 공식 업데이트 사이클 상태

## 결론

V2.78과 V2.79 공식 업데이트는 `STOM_Version_2`에 순서대로 반영되었고, 동일 변경은 `STOM_Version_2U`와 `STOM_Version_2U_C`까지 전파되었다.

이번 사이클의 필수 GUI 기준은 오프라인 스모크와 pyd GUI 계약 검증으로 확인했다. 확인 범위는 메인 실행, 주요 탭 전환, 전략 편집/최적화 버튼, 주요 설정/백테스트 다이얼로그다.

- `trade/strategy_base.py`를 `trade/base_strategy.py`로 이름 변경했다.
- `pyupbit` 의존 제거 흐름에 맞춰 `trade/upbit/upbit_restapi.py`를 추가하고 기존 `trade/upbit/upbit_websocket.py`를 제거했다.
- `trade/stock_korea/kiwoom_rest.py` 제거를 반영했다.
- UI 코드 간소화 및 일부 위젯 설명 추가 변경을 반영했다.
- 2U/2U_C의 비정식 워크트리 보호 정책은 `utility/database_check.py`에 유지했다.

V2, 2U, 2U_C가 모두 V2.79 기준으로 닫혔으므로 다음 작업은 V3 업데이트 아이디어 협의로 전환할 수 있다. V3 논의 전에는 이번 pyd 대체 검증 매니페스트를 기준선으로 고정하고, V3 후보 변경이 GUI 버튼 계약을 줄이거나 우회하지 않는지 먼저 비교하는 것을 추천한다.
