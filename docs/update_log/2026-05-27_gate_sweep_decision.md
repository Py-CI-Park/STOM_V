## 판정

**1) min_daily_trades=0.40은 너무 빡빡하다 — 취약한 winner를 강제한다.**
0.40에서 유일하게 졸업하는 gen2는 **MDD 32.62로 cap(35)의 93%**에 붙어 있어 취약하고
수익도 +4.96%로 낮다. 임계값을 조금만 낮춰도 위험/수익이 급격히 좋아진다.

**2) 빈도-수익은 급경사 트레이드오프다.**
- 0.40 → gen2: +4.96% / MDD 32.6
- 0.30 → gen3: **+10.90% / MDD 12.1** (수익 2.2배, MDD 1/3, 거래 72)
- 0.20 → gen5: **+26.10% / MDD 4.5** (수익 5.3배, MDD 1/7, 거래 44)

**3) 사용자 기준("못해도 2~3일에 한번") = 0.33~0.50/day.**
- gen2(0.40)=2.5일1회: 기준 내. 단 품질 취약.
- gen3(0.30)=3.3일1회: 기준 하단을 10% 밑돎. 품질 월등.
- gen5(0.20)=5일1회: 기준 미달(너무 희소). 품질 압도적이나 "일일 트레이딩" 취지엔 부적합.

## 권고

**min_daily_trades를 0.40 → 0.30으로 현실화** 권고.
- 근거: 사용자 "3일1회"(0.33) 하단과 사실상 동일(10% 차)하면서, **gen3(+10.90%·MDD12·72거래)**
  라는 현 winner(gen2) 대비 **수익 2.2배·MDD 1/3**의 견고한 전략을 졸업시킨다.
- gen2(0.40)는 MDD가 cap에 붙은 취약한 통과라, 0.40 고수는 "빈도 기준은 지키되 품질을 희생"하는 선택.
- **gen5(0.20)는 채택 비권고**: 5일1회는 일일 시스템 트레이딩 취지에 맞지 않음. 단 "고품질 알파가
  희소 구간에 존재"한다는 증거이므로, 빈도+품질 동시 달성을 위한 **Track B(더 넓은 알파)** 의 동기.

**다음**: 사용자가 0.30 채택 승인 시 → config `min_daily_trades=0.30`로 재실행(또는 기존 gen3를
winner로 승격). 0.40 유지 선택 시 → gen2 winner 확정 + Track B로 고품질·고빈도 알파 탐색.
