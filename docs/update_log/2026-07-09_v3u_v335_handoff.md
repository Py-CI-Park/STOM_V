## 0. 문서 목적

이 문서는 Codex, Claude Code, GJC 등 AI code agent가 다음 세션에서 즉시 작업 흐름을 복구할 수 있도록 작성한 상세 핸드오프다. 핵심 목적은 다음 네 가지다.

1. 직전 완료 작업(V3.33 → V3.34 흡수)의 전체 흐름과 증거를 한눈에 복원한다.
2. 현재 worktree/branch/head/untracked 상태를 명확히 고정한다.
3. 2026-07-09 기준 upstream V3.00에 새 V3.35가 존재함을 기록한다.
4. 다음 작업자가 `V3 공식 → V3U → 3U_C` 순서를 틀리지 않고 이어갈 수 있게 실행 순서, 검증 게이트, 금지 사항을 표로 제공한다.

| 공식 lane | `STOM_Version_3`에서는 upstream 파일과 `.pyd`를 보존한다. pyd 제거 금지 |
