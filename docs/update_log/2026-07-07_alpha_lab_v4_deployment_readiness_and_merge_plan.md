# 알파 랩 v4 배포 준비·머지 계획 (2026-07-07)

> **결론**: 알파 랩이 **배포 가능한 첫 성과**에 도달했다 — 검증 챔피언 4종의 **무파라미터 등가중 앙상블**이 OOS 블라인드에서 위험조정 +38%, 강화 검증에서 다각화 효과가 4/4 창 전부 견고. 관리자 방침("성과→머지")과 결정("강화 후 머지")을 충족. 본 문서는 배포 대상과 머지 절차를 확정한다.

## 1. 배포 대상 (deliverable)

**구성**: RR8_12 · RR8_0 · RR8_21 · GPTAUTH_G8 를 **각 1/4 등가중** 운용. 파라미터 0개(적응형·로테이션 아님 — 순수 등가중).

**근거 수치**:
- OOS 봉인창(2025-01~2026-02) 블라인드: profit 2,608,362 / MDD 493,591 / **calmar 5.28** vs 최선 단일 RR8_0 3.83 = **위험조정 +38%** (절대수익 −10%·MDD −35%).
- 강화(v4.1, 봉인 db829ed9): **T1 다각화 4/4창 전부**(1/N MDD < 단일 평균) + T3 몬테카를로 OOS P(1/N>중앙값)=0.7536.
- 무파라미터 → 과적합 구조적 불가. 발견창 8위→OOS 1위 flip = 1/N robustness 정상 패턴.

## 2. 정직한 한계 (배포 전 관리자 인지)

1. **calmar 우위는 OOS 특성**: T2(1/N calmar>중앙값)는 4창 중 1창(OOS)만 통과. in-sample(2022-24)에서는 단일 챔피언이 더 강함 = 1/N이 out-of-sample robust하다는 알려진 패턴이나, "항상 최고 수익"은 아님. **확실한 것은 위험(MDD) 감소, 수익은 소폭 희생.**
2. **T4 OOS 후반 MDD 역전**: OOS 전반은 1/N MDD 우위(438k<607k), 후반은 열위(494k>349k). 특정 반기엔 단일이 나을 수 있음.
3. **상관 0.816**: 챔피언 4종이 rr8 계보로 높게 상관 → 다각화 이득이 비상관 포트폴리오보다 작음. (v5에서 비상관 전략 추가 시 개선 여지)
4. **데이터 최신 2026-02**: 미래 OOS 창 부재 → walk-forward·MC로 대체 검증. 실배포는 **감독형**(롤링 성과 모니터링·킬스위치) 전제.
