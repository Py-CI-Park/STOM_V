# TMAP 원리 타당성 검토와 프로세스 개선 제안 (2026-06-11)

> 사용자 질문(상시 검토 요청)에 대한 정직한 답: ① 드론(지도) 원리가 올바르게
> 작동하는가 ② 현행 프로세스가 타당한가, 더 나은 프로세스는 ③ 우상향 곡선의
> 상세(그림) 분석이 도움이 되는가 ④ 오더플로우 원리(v5.0 F01~F20)가 모두
> 반영돼 있는가 ⑤ AI로 좋은 조건식을 "생성"하는 방법론(프롬프팅) 상세 검토.
> 본 문서는 **제안 단계**다 — 코드 변경은 사용자 승인 후 진행한다.

---

## 0. 결론 요약

1. TMAP 원리는 **주장하는 범위 안에서는 올바르게 작동 중**이다 — 단일 분기
   신호의 과대평가를 이미 두 번 교정했다(§1.1). 그러나 1차원 단면이라는
   구조적 한계가 있고(§1.2), 그 한계는 A2 조합점·V트랙·A6가 메우도록
   설계돼 있다.
2. 프로세스의 뼈대(지도→고원→동결→분포검증→OOS→결정)는 타당하다. 다만
   **백테 추가 0회로 가능한 강한 개선 2건(P2 연도분해 적격성, P3 곡선 형태
   지표)**과 LLM 분업 재설계(P5)가 비어 있다 — §2 표.
3. 우상향 곡선의 상세 분석은 **도움이 된다**. 사람이 곡선을 보고 고른 행위가
   암묵적으로 최적화한 것(기울기 일관성·짧은 정체·분산된 낙폭)을 지표화해
   지도에 얹을 수 있고, 이미 있는 자산(uptrend_r2, equity_points)으로 백테
   0회에 가능하다. 단, 형태 선택은 곡선적합 위험이 커서 advisory 한정(§3).
4. 오더플로우 원리는 **부분 반영**이다 — 프롬프트 주입은 구현됐으나 실가동
   0회, 원리 기반 "템플릿"은 미구현(P4). 정직한 현황 맵은 §4.
5. AI 생성 방법론의 핵심 격차: 실패 환류는 강하나 **성공 패턴 few-shot이
   없고**, LLM이 코드 1개를 내면 백테 1회로 평가하는 구조다. **LLM=구조 가설
   생성기, TMAP=가설 평가기**로 분업을 바꾸면 가설당 증거가 1점→56점 응답
   곡면이 된다(P5, 프롬프트 예시 §5.4).

## 1. 드론(TMAP) 원리는 올바르게 작동하는가

### 1.1 작동 증거 (이번 사이클 실측)

| 증거 | 내용 | 의미 |
|---|---|---|
| 렌즈 무왜곡 | 기본값 포인트가 시드 원본을 정확히 재현(3년 +8,631,199 / MDD 17.44 / 307건 — gen0) | 지도의 좌표계가 신뢰 가능 |
| 과대평가 교정 #1 | window_end 09:07: 2025Q1 마이크로 지도 +61% → 3년 지도 +12% | 단일 분기 우연을 다년 축이 걸러냄 — 지도를 만든 이유 그 자체 |
| 과대평가 교정 #2 | cap_max 축소: 2025Q1에서 불리 → 3년 반사실에선 유리 (구간별 방향 반전 검출) | 1회 백테 기반 그리디 개선이 왜 위험한지 실증 |
| 사전선언 규칙 | 고원 적격(v1/v2)·θ* 선정 규칙이 스윕 **전에** 코드로 고정됨 | 사후 입맛 선택(post-hoc selection) 차단 |

### 1.2 구조적 한계 (정직 공시)

| # | 한계 | 위험 | 현행 방어 | 잔여 리스크 |
|---|---|---|---|---|
| L1 | **1차원 단면** — 다이얼을 하나씩만 돌림 | 슬롯 간 상호작용 비가시(둘 다 좋아도 조합은 나쁠 수 있음) | A2 조합점 4~6개 실측 | 조합점도 점이지 면이 아님 → P1 |
| L2 | 지도 전체가 인샘플(2023~2025) | 고원 자체가 과거 특화일 수 있음 | V1 분포검증 + V3 고정 OOS + V4 전진분석 | OOS 합격 전엔 모든 지도 수치는 advisory |
| L3 | 선택 다중성 — 56점을 보고 최선을 고름 | "많이 보면 우연히 좋은 게 나옴" | V1 PBO(시도 집합=그리드)·DSR(n_trials 보정) | 보정은 완화지 면제가 아님 |
| L4 | MDD 분모가 동시보유 수에 비례(B2 감사) | 거래수가 크게 다른 점들 간 MDD 비교 왜곡 | 측정 프레임 문서화·동결은 동일창 재평가로 | 지도 위 MDD는 참고 지표로만 |
| L5 | **시드 구조 안에서만 탐색** — 다이얼로는 구조가 안 바뀜 | 시드 밖의 엣지(예: 미반영 F원리) 영구 비가시 | A6 GPT 구조 변이 + A4 신규 템플릿 | 템플릿 패밀리가 늘어야 해소 → P4·P5 |

결론: "드론 촬영" 비유는 정확히는 **시드라는 산 하나의 주변 지형 촬영**이다.
산맥 전체(조건식 공간)를 찍는 게 아니다 — 그래서 새 산(템플릿)을 세우는
P4/P5가 같은 방법론의 자연스러운 다음 단계다.

## 2. 프로세스 타당성과 개선 제안 (P1~P6)

현행 체인의 논리는 건전하다: 대량 관측(지도) → 안정 지대 선택(고원) →
동일 자로 재측정(동결) → 운/다중성 보정(V1) → 미관측 데이터 시험(V3/V4)
→ 인간 결정(V6). 부족한 부분과 개선:

| # | 제안 | 무엇이 좋아지나 | 비용 | 우선순위 |
|---|---|---|---|---|
| **P2** | **연도분해 적격성** — 지도 각 점의 per-trade CSV를 연도별로 분해, θ* 적격 조건에 "3년 중 2년 이상 흑자 + 치명 연도 없음" 추가 | 합산 수익이 가리는 **알파 감쇠(2023 좋음→2025 나쁨) 검출** — 시드 자체의 알려진 문제를 후보 선정 단계에서 차단 | **백테 0회** (CSV 재처리) | ★ 1순위 |
| **P3** | **곡선 형태 지표** — 점별 우상향 품질(uptrend R²·최장 정체일·ulcer·월간 흑자율)을 /tmap_map과 θ* 근거에 병기 | 같은 수익이라도 "한 달에 다 번 곡선"과 "꾸준한 곡선"을 구분 — 사람의 우상향 직관을 정량화 | **백테 0회** (equity_points/CSV 재처리) | ★ 2순위 |
| **P1** | **2-D 국소 지도** — 상위 2슬롯(예: window_end×cap_max) 5×5 격자 | L1(상호작용 비가시)의 직접 해소 — 두 1-D 고원의 교차점이 실제 "고원 면(mesa)"인지 확인 | 백테 25회 ≈ 1h 머신 | 3순위 |
| **P5** | **LLM 분업 재설계** — LLM이 코드 1개가 아니라 "템플릿+θ범위+근거" 가설을 산출, TMAP이 평가(§5) | 가설당 증거 1점→56점, LLM의 강점(구조·원리)과 기계의 강점(대량 측정) 분리 | 프롬프트 +얇은 파서 | 4순위 (A6 합류 시) |
| **P4** | **오더플로우 원리 템플릿** — F원리 기반 신규 템플릿 1~2종(예: 체결강도 폭발+호가 불균형 창) 작성 → 지도 | L5 해소 시작 — 보고서를 "임계 이식"이 아니라 "구조 차용"으로 활용(이식 실패 5/5의 교훈) | 템플릿 작성 + 스윕 ~2h | 5순위 |
| P6 | 레짐 라벨 분해 — 거래일을 시장 레짐별로 태깅, 지도 응답을 레짐별 분해 | "왜 작동하나"의 설명력·감쇠 예측 | 중간 (지표 데이터 필요) | 후순위 |

P2·P3는 백테 없이 기존 산출물 재처리만으로 가능하므로, 승인 시 본 스윕이
도는 동안에도 개발할 수 있다.

## 3. "항상 수익을 볼 수는 없다" — 기대값 프레임과 우상향 곡선 분석

맞는 말이며, 시스템도 이미 그 전제 위에 있다: 목표는 "모든 구간 흑자"가
아니라 **양의 기대값 + 통제된 낙폭 + 실거래 비용 내성**이고, 그래서 판정이
점추정이 아닌 분포(MC P(흑자), MDD 분포)로 내려진다.

사람이 우상향 그림을 보고 시드를 고른 행위는 암묵적으로 다음을 최적화한 것
이다 — 이를 지표화하면 기계가 같은 눈을 갖는다(P3):

| 사람의 직관 | 정량 지표 | 현행 자산 |
|---|---|---|
| "꾸준히 오른다" | 누적곡선의 uptrend R² | fitness에 이미 존재(uptrend_r2) — 지도에 미병기 |
| "오래 멈추지 않는다" | 최장 정체(신고점 미갱신) 일수 | equity_points(v10)·CSV에서 산출 가능 |
| "깊게 꺼지지 않는다" | ulcer index / MDD 분포 | MC 팬차트 존재 — 점별 병기는 미구현 |
| "특정 달 운빨이 아니다" | 월간/연간 흑자 비율 | /run_yearly 존재 — θ* 적격성과 미연결(P2) |

경고(정직): 형태 지표로 **선택**하는 순간 곡선적합 위험이 커진다 — 매끈한
과거 곡선은 만들기 쉽다. 그래서 P3는 advisory(근거 병기·동순위 타이브레이크)
로 한정하고, 합격 판정은 변함없이 V3/V4(미관측 데이터)가 한다.

## 4. 오더플로우(v5.0 F01~F20) 반영 현황 — 정직한 맵

| 경로 | 상태 | 비고 |
|---|---|---|
| 원리 텍스트의 생성 프롬프트 주입 | ✅ 구현(B군, report_principles_enabled) | **실가동 0회** — GPT 오늘 충전 확인, A6에서 ON |
| 보고서 임계값 직접 이식 | ❌ 실패 기록(5/5 음수) | 교훈 문서화 — "숫자가 아니라 구조를 가져와라" |
| 원리 기반 후보 생성(Claude, 6/10) | ✅ 1회 수행 | C7이 그 산물(최초 대형 OOS 흑자, 판정 REJECT) |
| 원리 기반 **템플릿**(TMAP 패밀리) | ❌ 미구현 | P4 제안 — 보고서 활용의 다음 단계 |
| 측정 단위/프레임 감사 | ✅ 완료 | 시가총액=억, 백만원 단위, MDD 분모 정의 |

답: "모두 고려"는 아니다 — **주입 경로는 준비됐으나 가동 전이고, 템플릿
경로는 비어 있다.** P4·A6가 그 갭을 메운다.

## 5. AI로 좋은 조건식을 만드는 방법론 — 상세 검토 (P5)

### 5.1 현행 프롬프트 자산 인벤토리

| 자산 | 상태 |
|---|---|
| 엔진 계약(무인자 Buy/Sell·한글 변수·단위) 명세 | ✅ |
| 실패 부검 환류(진입/청산 NL 요약) | ✅ + R1 분위수(승자 Q25/중앙값/Q75 임계 후보) |
| 반사실 필터 제안(백테 0회 검증 통과분만) | ✅ (counterfactual_feedback) |
| 계산예산 가드 프롬프트(무한 역스캔 금지) | ✅ (exec_budget) |
| 오더플로우 원리 주입 | ✅ 구현·미가동 |
| **성공 패턴 few-shot** | ❌ 없음 — 실패만 가르치고 성공을 안 가르침 |
| **구조(템플릿) 산출 모드** | ❌ 없음 — 항상 완성 코드 1개를 요구 |

### 5.2 핵심 격차와 재설계

현행: LLM이 코드 1개 산출 → 백테 1회 → 부검 → 다음 코드. 가설당 증거가
1점이라 운과 실력이 분리되지 않는다(이 약점이 6/10 근본 원인 보고서의
인샘플 단발 환류 문제와 동일 뿌리).

재설계(P5): **LLM은 "구조 가설"을 산출하고, 기계가 지도로 평가한다.**

```
[현행]  LLM → 코드 1개 → 백테 1점 → 부검 → 반복
[제안]  LLM → 템플릿(구조) + θ슬롯 + 탐색범위 + 원리 근거
            → tmap_sweep (1가설 = 응답곡면 수십 점)
            → 고원 있으면 살리고, 없으면 가설 기각 근거가 데이터로 남음
```

이점: ① 가설 채택/기각이 1점 운이 아니라 곡면 형태로 판정됨 ② LLM이 약한
"숫자 고르기"를 기계가 대신함 ③ 기각된 가설도 응답곡면이 남아 다음 프롬프트
의 few-shot 음성 예시가 됨.

### 5.3 성공 패턴 few-shot (즉시 적용 가능)

프롬프트에 "잘된 예 + 왜 잘됐는지"를 넣는다 — 현재 보유한 성공 사례:
시드(3년 +863만), C7(최초 OOS 흑자), θ* 우세점(window_end=90700,
cap_max=2000~2500, turnover_min=1.5 등 스윕 완료 후 확정). 각 예시에
원리 주석(어느 F원리/어느 메커니즘으로 수익이 났는지 — 부검·반사실 데이터
기반)을 달아 "구조→성과" 연결을 학습시킨다.

### 5.4 프롬프트 예시 2종

**(a) 템플릿 가설 생성(신규 — P5 핵심):**

```
[역할] 너는 한국 주식 틱 단위 오더플로우 단타 전략 설계자다.
[원리] F07: 시가 직후 체결강도 폭발은 단기 추세 지속 신호다. (보고서 발췌 요약)
[성공 예] 시드 902/905: 09:02~09:05 창에서 등락율각도·초당거래대금 폭발 조합
  → 3년 +863만. 지도 측정 결과 창을 09:07로 늘리면 +12%(거래 +45%, MDD ↓).
[과제] F07을 표현하되 시드와 "다른 구조"의 매수 템플릿 1개를 제안하라.
  - 고정 숫자 금지: {burst_min}, {window_end}처럼 θ 슬롯으로.
  - 슬롯마다 (기본값, 후보 4~6개, 왜 그 범위인지)를 명시.
[제약] self.Buy() 무인자 / 시가총액 단위=억 / 당일거래대금 단위=백만원
  / 매도식에 고가미갱신지속틱수·저가미갱신지속틱수 사용 금지(계산예산).
[출력 JSON] {"buy_template": "...", "slots": [{"name","default","candidates","rationale"}],
  "principle_map": {"F07": "이 조건이 F07을 어떻게 표현하는지"}}
```

**(b) 부검 환류 변이(현행 강화 — 분위수·반사실 숫자 활용):**

