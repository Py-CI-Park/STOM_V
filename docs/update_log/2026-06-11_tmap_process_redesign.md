# TMAP — 경향성 지도 기반 조건식 발굴 프로세스 재설계 (2026-06-11)

> **출발점(사용자 재정의)**: 시드 DB·연구 문서에서 출발해, **시간창과 매매 횟수를
> 최대로 늘려** 최대 수익을 내는 조건식을 찾는다. 기존 개발에 얽매이지 않고 처음부터
> 프로세스를 다시 설계하되, DB·조건식 생성·백테스트 CLI·기개발 도구는 전부 사용 가능.
> **사용자 핵심 통찰**: "백테→분석→개선" 단방향 루프는 항상 개선 방향이 아니다.
> 거래 하나를 안 하면 미래의 다른 거래가 생기는 등 경로 의존성과 불확실 요인이 많다.
> → **큰 범위에서 백테스트를 대량 생산하고, 조건 변경에 따른 결과 경향성을 분석**하라.

---

## 0. 한 줄 설계

**조건식을 '점(한 개의 코드)'이 아니라 '모수화된 패밀리(템플릿×θ)'로 다루고, 엔진의
대량 평가 능력으로 θ-공간의 '경향성 지도'를 그려, 피크가 아닌 '고원(plateau)'을 골라
저상관 니치 포트폴리오로 조립한 뒤, 전진분석(재적합 정책)으로 시간 축을 검증한다.**

기존 루프와의 근본 차이:

| | 기존(그리디 개선 루프) | TMAP(경향성 지도) |
|---|---|---|
| 탐색 단위 | 조건식 1개씩 생성·개선 | 템플릿 1개 = 변형 수십~수천 동시 평가 |
| 선택 기준 | 최고 점수(피크) | **고원**(이웃 θ도 흑자인 넓은 영역) |
| 경로 의존성 | 단일 경로 결과에 휘둘림 | 이웃 평균·MC 분산으로 흡수 |
| 개선 방향성 | 항상 개선된다는 가정(취약) | 가정 없음 — 지도는 방향과 무관하게 누적 |
| LLM 역할 | 숫자(임계값)까지 작성 | **구조(템플릿) 설계·변이·해석** — 숫자는 엔진이 탐색 |
| 시간 축 | 고정 전략의 OOS 1회 | **전진분석**: 재적합 '정책'의 누적 성과 |

왜 이것이 사용자 통찰의 정답인가: ①"대량 백테스트"는 엔진 최적화 모드(1회 데이터
로드로 변수 스윕)와 zero-LLM 배치도구(코드 그리드 일괄 평가)로 이미 물리적으로 가능
하다. ②"경향성 분석"은 변수별 응답 곡선·plateau 점수·절벽 감지로 형식화된다.
③"항상 개선되지 않는다"는 비단조성은 고원 선택이 구조적으로 면역이다 — 거래 하나가
경로를 바꿔도 이웃 θ들이 같이 흑자면 그 영역은 진짜다.

## 1. 목표의 4번째 시나리오 (기존 A/B/C에 추가)

| 시나리오 | 내용 | TMAP에서의 위치 |
|---|---|---|
| A. 검증된 수익 조건식 | 단일/소수 전략 | T3 산출물(고원 후보) |
| B. 시드+AI 팀 | 앙상블/적응형 | T4 산출물(포트폴리오) |
| C. 단일 AI 시드 초월 | 북극성(낮음) | D의 특수해로 재해석 |
| **D. 운용 정책(신규)** | **전진 재적합 + 니치 포트폴리오 '정책'의 누적 수익** | **T5의 주 타깃** — "어떤 고정 전략도 영원하지 않다"(시드 쇠퇴 실측)를 받아들이면, 검증 대상은 전략이 아니라 **정책**이다. 100%에 가장 가까운 길 |

"100% 달성"에 대한 정직한 정의: 미래 레짐 보장은 불가능하므로, **프로세스 100%**를
목표로 한다 — 모든 채택이 (고원·분포·전진검증) 위에서 내려지고, 사이클마다 지도가
단조 누적되며(틀린 가설도 지도에 남아 재탐색 방지), 운용은 정책 수준에서 검증된다.

## 3. 파이프라인 T1~T5

### T1. 시드 마이닝 & 템플릿화 (구조의 모수화)
- 시드 452종+리포트 원리를 구조 클러스터링(시간창/시총/스타일/사용 변수군) →
  대표 구조를 **템플릿**으로 추출: 조건 구조는 고정, 임계값은 θ 슬롯.
  예) 시드 902/905 템플릿: θ=(시총상한, 전일동시간비 하한, 체결강도 밴드, 시간창 경계,
  손절, 트레일링 시작/폭, 보유시간 상한) — 8θ.
- θ 범위 시드: v5.0 §9 최적화 범위 + 부검 분위수(R1) + **counterfactual 사전 스크리닝**
  (백테 0회로 명백히 나쁜 영역 제거 — 탐색 공간 절감).
- LLM(GPT/Claude) 역할: 템플릿 설계·변이(새 구조 가설). 숫자는 쓰지 않는다.

### T2. 경향성 지도 (대량 백테스트 — 사용자 아이디어의 본체)
- **러너 2종**(병행):
  (a) 엔진 최적화 모드 — 1회 데이터 로드로 변수별 좌표 스윕(변수당 ~20값) →
      변수별 응답 곡선이 네이티브로 나온다(가장 싼 대량 백테).
  (b) zero-LLM 배치 그리드 — 템플릿×θ 조합을 코드로 생성·일괄 주입·배치 평가
      (조합 탐색·교차 검증용; 3년 tick run당 ~90초 실측 → 160변형 ≈ 4시간/야간).
- **경향성 분석 산출물**(신규 분석기):
  - 변수별 응답 곡선: profit(θᵢ)·MDD(θᵢ)·trades(θᵢ), 이웃 스무딩.
  - **plateau score = 이웃 흑자율 × 고원 폭 × 다년 일관성** — 채택 1순위 지표.
  - 절벽 감지(|Δprofit/Δθ| 급변 = 과적합 경계), 상위 변수쌍 상호작용 히트맵.
  - 경로 민감도: 동일 θ에서 block MC 분산 = "운"의 크기 정량화.
- 모든 결과는 loop_runs.db에 기록 → 대시보드 지도 뷰로 시각화.

### T3. 고원 후보 동결 + 3중 분포 검증
- plateau 중심(피크 아님)을 후보로 동결(seed_relative 규율 그대로).
- **PBO/CSCV의 본고장**: 그리드 전체가 시도 집합 — PBO·DSR(n_trials=그리드 크기)이
  비로소 충분한 통계력을 갖는다. + block MC + 플라시보(무작위 진입 대비).
- 고정 2022/2026 OOS는 동결 후보만(기존 규율 불변).

### T4. 포트폴리오 조립 (시간·횟수 확대의 실행)
- 저상관 고원 후보들 결합(R7 일별손익 상관) — 시간대 커버 최대화:
  tick 시초 니치들 + min 오전/오후 니치들 → 합산 일평균 거래수·시간 커버 ↑, MDD% ↓.
- 1차 근사는 일별손익 합산(백테 0회), 채택 조합만 동시보유 실백테 확인.
- 적응형 레짐타이밍(기검증 3.5×)을 정책 레이어로.

### T5. 전진분석 운용 검증 (시나리오 D의 판정)
- rolling walk-forward: 창 N개월 재적합(T2 지도 갱신→T3 재동결) → 다음 창 성과만
  누적 = **"이 정책으로 운용했으면 벌었을 돈"** — 시드 쇠퇴 같은 레짐 드리프트를
  정책 수준에서 흡수하는지의 직접 측정.
- 슬리피지 스트레스 + 결정 카드. 실운용 승격은 기존 별도 관문(V3K) 유지.
