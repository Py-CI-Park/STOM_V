## 1. 최종 목적 (방향성 고정 — 사용자 명시 2026-05-26)
사람이 GUI에서 수동으로 조건식을 만들고 계속 수정하던 작업을, **AI가 더 많은 반복 + 더 좋은 두뇌 + 데이터 분석**으로 대체해 **수익 내는 조건식**을 생산하는 것. 나아가:
- 백테 **결과 분석**(부검)
- **전략 기록**(세대별 조건식 보존)
- **전략 변경에 따른 경과 비교 분석**(버전 diff/추이)
- **데이터 누적**(run·세대 가로질러)
- **누적 데이터의 추후 메타분석**(방법 고안 필요)

→ 일회성 "좋은 전략 1개"가 아니라 **지속 관리되는 연구 파이프라인**을 목표로 한다.

## 3. 연구 프로세스 플로우 (루프 = 연구 사이클)
```
[0] 준비(1회): warm 엔진풀+전체유니버스 로딩, best←시드
 └ 세대 루프:
    (a) 가설 생성   best 코드 + 부검 + 이력 → 개선안 (가드: compile/토큰/스코프/중복)
    (b) 실험        warm.run → 전체유니버스 백테 (견고성: 타임아웃→리셋+재로딩)
    (c) 측정        하드게이트(MDD≤35·수익>0·거래≥30=우승) + graded(선택압력)
    (d) 분석        진입 B_* Cohen's d + 청산 give-back/MAE/매도규칙 → NL 피드백
    (e) 기록        loop_runs.db(SQLite) + 누적이력 + 대시보드 실시간
    (f) 선택        graded>best면 best·base 갱신(hill-climb); 게이트통과면 winner
    (g) 종료        목표·예산·세대 상한
[H] 사람 승인 → winner export(production strategy.db)
```
매핑: 생성=가설, 백테=실험, 부검=분석, 기록=연구저널, 선택=수렴. (d)·(f)가 현재 가장 얕은 고리.
