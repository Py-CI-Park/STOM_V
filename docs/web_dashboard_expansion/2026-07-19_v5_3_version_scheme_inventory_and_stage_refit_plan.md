## 5. v5.3.2 Live 스테이지 재편 설계 (사장님 지시 상세)

### 5.1 스테이지 4탭 (5→4, N6)
```
① 생성          — Hypothesis·ActiveStrategy·ConditionDiscovery (CurrentGen 은 상황판으로)
② 백테스트      — EnginePanel(재디자인)·BacktestDetailChart·EvolutionGuiParityPanel(이동 편입)
③ 채점·부검(통합) — 게이트 fold·GenerationsTable·탐색 히트맵(이동)·엣지/상관·Autopsy·Lineage·Meta·Holdout·Feedback
④ 반복·성과      — Best/Winner·Population·EvolutionAnalysis (ProcessFlow 제거)
```
- phaseIndex 매핑: 0→①, 1→②, 2·3→③, complete/generation_done→④ 자동 포커스.

### 5.2 상황판 1줄화 (N3·N4)
- 사이클 원형 → **수평 파이프라인 벨트**: 8노드를 가로 배치(시드→프롬프트→AI생성→게이트→공식백테→채점→부검→환류↩), 활성 노드 pulse·완료 dim·환류 화살표 회전 아이콘. 높이 356→**약 90px**.
- PhaseTimeline 제거(벨트의 4구간 하이라이트가 대체). 스테이지 클릭 pin 은 벨트 노드 클릭으로 승계.
- KPI 행: 현재세대(구 CurrentGenPanel 핵심 수치 통합)·best fitness·best MDD·tokens/cost·게이트 3값.
- 목표: 상황판 442→**≤220px**, idle Live 전체 ≤ 0.8화면.

### 5.3 EnginePanel 재디자인 (N5)
- 상단: 상태 대형 칩(실행중/대기/완료/오류) + **진행 대형 바(높이 14px)** + "gen X/Y · 경과 mm:ss · ETA mm:ss" 16px.
- 하단: 워커/CPU/메모리/throughput 을 아이콘+수치 4칸 그리드(글자 12.5px+), 로그성 소자 제거.
