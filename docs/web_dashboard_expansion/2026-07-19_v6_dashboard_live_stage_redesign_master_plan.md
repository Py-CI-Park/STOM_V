## 4. V6 로드맵 (각 릴리스 = 브랜치 → 검증 → 라인연결 merge)

### V6.0 — Live 스테이지 구동 재설계 (최우선·핵심 · L1·L2·L3·L4·L5·L6·L7·L8·L10·G6·G9·G2·G4·W1)
사장님 최우선. Live를 **"스테이지 구동 단일 포커스 뷰"** 로 재구조화한다.
- **상단 통합 상황판**: 반복세대 사이클 + 현재세대 + 백테엔진 상태 + 진행률을 한 줄 상황판(애니메이션 진행 pulse)으로 통합(L3·L5). 글자블록(단계시간·차단·로그)은 미니 바/배지/1줄+펼침으로 시각화(L2).
- **프로세스 스테이지 탭바**: `generate → backtest → score → autopsy → iterate` 를 `tablist`로 배치. 라이브 진행 시 **현재 단계 탭으로 자동전환**(user-pin 시 고정), 키보드/reduced-motion 지원(L4·G11).
- **스테이지별 단일 포커스 뷰**: 각 탭은 그 단계 시각화만 크게 보여준다.
  - generate: 생성 중 조건식·프롬프트·후보.
  - backtest: 매수/매도 조건식(잘 보이게) + 엔진 진행률 + 실시간 곡선(L6). **Lab 히트맵/엣지 분석이 이 스테이지에 통합(W1)**.
  - score: 채점·게이트 통과/탈락 시각화 + 분석 결과(Lab 엣지·상관·안정성).
  - autopsy: 실패/부검·계보.
  - iterate: 세대 요약·다음 반복.
- **울트라와이드 밀도**: hero 단일 1382px 그래프를 **스테이지 컨텍스트 멀티그래프(2~3열)** 로 대체. 폭을 여러 과정 동시 노출에 쓴다. 그래프 최대 높이 CSS px 제한(G6·G9).
- **버튼/폴드 병합**: 7 fold를 스테이지 뷰로 흡수·병합, 중복 패널 제거(L7). 게이트/채점은 각 단계 inline click 상세(L8).
- **타이포/펼침**: 페이지 제목 22px+, 패널 제목 16px+, 본문 14px+. 우측 패널 펼쳐 확대(expand-to-focus) 인터랙션(G2). 레일 탭 확대(G4).
- **깜빡임**: 재연결 문구 flap 제거(안정 blip debounce, 근본은 세션 유지 유지)(L10).
- **수용 기준(3440·2560·1920 실측 before/after JSON)**: 첫 화면에 상황판+현재 스테이지 핵심 시각화가 DOM rect 90%+, hero 그래프 폭 ≤ 화면폭 절반(멀티뷰), scrollHeight/innerHeight ≤ 1.6, 가로 overflow ≤3px, 콘솔/page error 0.
