## §0. 사용자 피드백 원문 요지 (요구사항 SSOT)

### 전역
- **G1** 탭 글자 폰트가 다른 글자와 달라 보임 → 맑은 고딕 또는 전체 폰트와 통일.

### 진화 대시보드 / 리서치랩
- **E1** 최상단 "운영 연구 결과" 류 글자의 의미를 알 수 없음 → 올바른 위치로 재구성하거나 버튼/탭을 체계화(글자만으로는 부족).
- **E2** 리서치랩을 새탭 전체화면으로 열면 화면 전체를 써서 백테스트 탭처럼 화려·상세한 전체 결과 분석 시각화+분석 기능이 모두 들어가야 함. 목적: **유의미한 수치·인사이트 도출과 그 시각화**.
- **E3** "전전략 누적 수익곡선"의 0~100% 의미 불명 → 축 의미 명시, 테스트 기간 출력(현재 연도 미표시).
- **E4** 품질 추이·적합도 추이: 마우스 hover 시 설명 팝업.
- **E5** 성과 명예의 전당: 조건식을 보고 **바로 사용**(백테스트 연동)하는 기능.
- **E6** Run Compare: 좋은 결과를 바로 사용·바로 백테스트로 연동.
- **E7** 시간대×시가총액 탐색 히트맵: 적합도 추이 위에 동일 크기로, 수익 추이 등과 같은 급으로 강화. 새 출력 박스를 리서치랩 탭으로 이동·전체화면 가능하면 더 좋음.
- **E8** 조건식·키워드 표시 기능은 백테스트 탭(변수 칩) 참고해 강화.
- **E9** 히스토리 탭: 과거 연구·과거 사용 조건식을 바로 보고 결과를 아주 상세히 시각화해 재열람.
- **E10** 프로세스 시각화: 현재 세대 등 적절한 위치에서 클릭하면 전체 프로세스가 흐름(진행도)으로 보이는 기능(mermaid 이상의 시각화). 세대·격자 등 새 용어가 많으므로 실시간 진행과 함께 용어가 이해되도록.

### 백테스트 탭
- **B1** 요일·시간대 히트맵이 너무 작음 → 화면을 쓸 수 있는 만큼 모두 사용.
- **B2** 매수/매도 에디터가 작음 → 하위 탭 [조건식 편집 | 결과 분석] 분리(STOM GUI 도 버튼으로 화면 전환).
- **B3** STOM GUI 백테스트 결과 이미지 2장에 포함된 내용 전부 웹에 출력(진화 대시보드에 일부 구현 — 참고).

### 차트 시뮬레이션 탭
- **S1(결함)** LWC 차트에 봉이 1개만 나옴 + 거래량이 안 나옴 → 거래량도 함께 리플레이돼야 함.
- **S2** 차트 동시보기 확대: 개수 선택, 최대 10개.
- **S3** 오더플로우를 footprint 스타일(참고 이미지: 가격 레벨별 bid×ask 체결량 셀) 등으로 시각화 개선.
- **S4** LWC 말고 더 액티브한 라이브 캔들 구현 라이브러리/방법 연구·검토·적용(STOM GUI 시뮬레이션 수준의 라이브감).
- **S5** 호가 시각화를 실제 거래 화면(HTS 호가창)처럼.
- **S6** 이런 대시보드의 특징·설계 원칙을 담은 design.md 생성.

## §1. 사전 조사 결과 (구현 방향 확정)

- **S1 root cause 확정**: `simulation.jsx:565` 가 `barsRef.current[code].push(...)` 로 동일 배열을 mutate, `barsByCode = {...barsRef.current}` 는 외부 객체만 신규 → per-code 배열 참조 불변 → `SimCandleChartLWC` 의 `useEffect [bars]` 가 최초 1회만 실행되어 **첫 프레임 봉 1개로 동결**(거래량 히스토그램도 같은 effect). SVG 경로는 render-time 그리기라 정상이었음. **수정: immutable append**(`store[code] = [...prev, bar]`) — 벤더 업그레이드 불필요.
- **S4 결정**: 외부 라이브러리 추가 대신 **자체 Canvas 라이브 렌더러**(`SimLiveChart`) 신설 — 현재봉 성장 애니메이션·틱 플래시·거래량 동반 리플레이 등 LWC 로 어려운 라이브 연출을 직접 구현(오프라인·in-browser Babel 제약과도 부합). LWC/SVG 경로는 유지, 차트 모드 토글에 "라이브" 추가.
- **B3 원천**: `backtest/back_static.py` PlotShow() 2장 — ①부가정보(2×2): MDD 랜덤 30곡선+메인 / 일별수익+지수 / 시간대별 손익 누적바 / 요일별 손익 누적바 ②결과(2×1): 보유금액 곡선 / 거래별 손익+롤링 평균. 웹 분석 라우트로 동등 데이터 제공 후 차트 추가.
- **B1**: `BtHeatmap` 셀 34×26px 고정 → 컨테이너 폭 추종 동적 셀 크기로.
- **L 충돌 회피**: `research-lab.jsx`·`app.py` 는 부모 핫파일 → 신규 `research-pro.jsx`(풀스크린 랩: E2·E5·E6·E7·E9·E10)를 별도 파일로 만들고, 기존 파일 수정은 외과수술적 최소(라벨 의미·연도 표기·툴팁)로 한정.
