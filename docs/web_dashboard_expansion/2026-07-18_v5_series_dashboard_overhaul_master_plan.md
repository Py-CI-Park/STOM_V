## 4. V5 시리즈 로드맵

### V5.0 — Live 밀도 재설계 (최우선 · G6·G9·L1·L2·L7·L8·G2·G4)
- **스택 → 반응형 그래프 그리드**: `.v4-rlive`/`hero-col` 을 CSS Grid 로 재구조화. 3440: 상단 KPI 바 + 2~3열 그래프 그리드(Fitness·Profit·Quality·Equity 동시 노출), Fitness 높이 520→~340.
- **텍스트 블록 → 상단 compact 상황 바**: _V4WorkflowStrip 의 단계시간(미니 바 차트)·차단사유(배지 그룹)·로그(1줄+펼침).
- **정보 계층화**: 6 Fold 를 "요약 상시 + 상세 클릭"으로 정리, 불필요 병합. 게이트/채점기준 클릭 노출(L8).
- **타이포 확대**: 탭 상단 제목·주요 버튼·우측 패널 본문 글자 상향(G9·G2·G4).
- **목표 수치**: 첫화면 그래프 4→8+, 스크롤 18k→≤2화면.

### V5.1 — 프로세스 스테퍼 & 단계별 뷰 (L3·L4·L5·G11)
- 상단 **단일 프로세스 상황판**: 반복세대 사이클 + 현재세대 + 백테엔진 상태 통합, 애니메이션(진행 pulse).
- **생성/백테/채점/부검 단계별 뷰** + 라이브 진행 시 **자동 포커스**(user-pinned 존중, P5b 승계).

### V5.2 — 백테 단계 시각화 (L6)
