## 1. 이번에 밝혀진 진짜 원인

### 1.1 잡 333건이 즉사한 이유 — 없는 조건식을 참조하고 있었다

앞선 감사는 "잡 333건 전부 취소·실패, 성공 0건"까지만 확인하고 원인을 미규명으로 남겼다.
실제 원인은 단순했다.

```
기록된 잡의 조건식: 기존매수 / 기존매도
strategy.db 의 매수 조건식 102건 중 "기존매수" → 0건 (존재하지 않음)
```

**이미 삭제된 이름을 참조하고 있었다.** 그래서 CLI 가 0.05~0.19초 만에 `exit=1` 로 죽었고,
화면에는 종료 기록만 쌓여 "결과 라이브러리가 왜 비어 있냐"로 읽혔다. 오늘 18:30 에도
같은 실패가 한 건 더 기록됐다.

조치: `/bt/run` 이 조건식 존재를 먼저 확인하고 없으면 `strategy_not_found` 로 즉시 거부한다.
잡을 큐에 넣지 않는다.

검증: 실제로 존재하는 조건식(`20250715_Study` / `20250715_Study_S`)으로 같은 경로를 실행하면
약 60초 실행 후 `no_trades` 로 정상 종결하고 `open_result` 를 제공했다. **엔진과 잡 경로는
정상이었다.**

### 1.2 내가 만든 회귀 — 정본 루트가 세션을 발급하지 않았다

진입점을 `/` 로 통합(`d84012e3`)하면서 `BOOTSTRAP_PATHS` 에 `/` 를 넣지 않았다.
그 결과 `http://127.0.0.1:8771/` 로 **처음** 들어온 방문자는 세션 쿠키 없이 셸을 받고
`/ws` 가 `4401 session_required` 로 거부된다. 이미 `/ui/v4/` 를 방문해 쿠키를 가진
브라우저에서는 증상이 가려져 내 검증에서도 통과했다.

UXR-P2 에서 한 번 잡았던 회귀와 같은 종류다. `0de52380` 에서 수정하고 `/` 를 세션 발급
계약 테스트에 넣었다.

### 1.3 A/B 비교는 데이터가 없어서가 아니라 입력 경로가 없어서 막혀 있었다

세대 결과도 잡과 같은 거래 CSV 를 남기는데 `/bt/compare` 가 `job_id` 만 받았다.
완주한 잡이 0건이었으므로 A/B 비교는 사실상 사용 불가 상태였다.

## 3. 실데이터가 드러낸 연구 사실

새 카드들이 기존 화면이 말해주지 않던 것을 드러냈다. `abmain0716f_p5_typed`:

```
15세대 · 게이트 통과 0건
최고 수익금 +8,266,552원 (g0) · 최고 수익률 164.37% · 연평균 38.27%(3년 환산, 파생값)
최고 기록 갱신: 14세대 전
```

**g0 가 최고였고 이후 14세대가 아무것도 개선하지 못했다.** 게다가:

```
"refine로 직전 세대 대비 graded 개선 기대"  → g1~g14 에서 14번 연속 빗나감
"진입 품질 향상으로 총손익 흑자전환 기대"     → 12번 빗나감
```

**같은 가정을 14세대 동안 반복하고 있었다.** 이 사실은 세대별 가정 기록에 흩어져 있어
어느 화면에도 집계되지 않았다. 이것이 이번 작업에서 가장 값어치 있는 산출물이다.

세대 A/B 비교도 같은 방향을 확인해 준다(g0 ↔ g4):

```
g0  307거래  +8,266,552원
g4 2,363거래 -19,967,388원
delta: 거래수 +2,056 · 승률 -27.72 · 손익 -28,233,940 · MDD -56.3
```

거래를 8배 늘리면서 승률과 손익이 함께 무너졌다.

### 95점에서 멈춘 이유 (남은 5점)

- **결과 소스 운영성 -2**: 실행 경로가 정상임은 확인했지만(60초 완주, `no_trades`),
  **거래가 실제로 발생한 openable artifact** 는 아직 없다. 전 종목 min 백테스트는
  1일 범위도 20분을 넘겨 이 세션에서 마감하지 못했다. 잡 기반 20카드·2·3·4열·잡 리포트는
  여전히 미검증이다.
- **연구 프로세스 서사 -1**: "이 run 이 이전 run 보다 나은가"는 Live 에서 답할 수 없다.
  run 간 비교 축이 History 에만 있다.

이 둘은 UI 결함이 아니라 **아직 만들어지지 않은 데이터**와 **의도적으로 분리한 소유권**의
문제다. 화면을 더 고쳐서 올릴 수 있는 점수가 아니다.
