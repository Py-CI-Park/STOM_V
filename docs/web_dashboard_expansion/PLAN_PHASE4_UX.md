## §0. 사용자 피드백 원문 요지 (요구사항 SSOT)

1. **진화 대시보드/리서치 랩**: 전체 화면에서도 탭·요소가 너무 작고 구분이 안 됨. 전체 화면 시 더 강화된 백테스팅 분석(더 많은 분석 그래프)으로 인사이트를 얻을 수 있어야 함.
2. **백테스트 탭**:
   - 매수+매도 조건식을 **한 화면에 동시** 표시, 사용 변수들을 **키워드(칩)로 추출 표시**
   - 조건식·결과들의 **체계적 관리**(버전/태그/검색/비교 이력)
   - GUI 백테스트 분석 탭의 **최적화·백파인더 등 전 기능**을 웹 탭에 구현
   - 결과 분석이 **기본 화면에 예시(데모)로 표시**되도록(빈 화면 금지)
   - ⚠️ **결함 신고: 백테스트 엔진 실행 버튼이 안 보임 / 매도 조건식 선택이 없음** — 코드상 구현돼 있어야 함(BtRunPanel buy/sell 셀렉터+실행 버튼) → §1에서 재현·원인 확정 필수
   - GUI 대비 부족 기능 전수 재검토
3. **차트 시뮬레이션**: 시작 전에도 **예시가 기본 표시**되거나 `_database`의 준비된 DB로 **즉시 시뮬레이션** 가능. 차트·비주얼 기능 추가.

## §1. 트랙 V — 결함 검증 (최우선, 다른 트랙 선행)

- 8771 실서버를 Playwright(webapp-testing)로 열어 백테스트 탭 스크린샷 → 실행 버튼·매도 셀렉터 실재 여부 확인
- 가설: (a) 브라우저 캐시(구 jsx — no-cache 미들웨어 있으나 확인), (b) 데모/미연결 상태에서 컨트롤 숨김, (c) 레이아웃상 폴드 아래/과소 크기로 인지 불가(피드백 1과 동일 뿌리), (d) 실제 렌더 버그
- 산출: 원인 확정 + 즉시 수정(버그면) 또는 가시성 개선으로 트랙 B에 위임

## §2. 트랙 설계 (V 이후 병렬, 파일 소유 분리)

|------|------|----------|
| **A. 전역 UX 스케일** | 탭 내비 대형화(높이·폰트·활성 강조), 전역 폰트/간격 스케일 업, 패널 구분(보더·배경 대비↑), 섹션 헤더 강화, 와이드(>1800px) 레이아웃 활용. 진화 탭 패널은 **styles.css 추가 클래스+app.jsx 탭바만**(부모 핫파일 최소 접점) | styles.css(추가), app.jsx(탭바 한정) |

| **C. 시뮬레이션 즉시 체험** | ①최초 진입 시 자동 데모: 최신 min DB·등락 1위 종목 자동 선택+자동 재생(배지 '예시') ②원클릭 프리셋(어제/최근 급등일) ③비주얼 추가: 등락율 게이지·세션 진행 링·신호 순간 플래시 효과 | simulation*.{py,jsx} |
