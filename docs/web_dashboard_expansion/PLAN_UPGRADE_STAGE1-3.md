## 1단계 — 즉효 (라이브·인터랙션·모션)

| 항목 | 설계 |
|------|------|
| 라이브 잡 WS | `WS /bt/ws_job?job_id` — 서버가 1초마다 {status,progress,phase,elapsed,log_tail} push, 종결 시 최종 요약 후 close. 프론트는 running 시 WS 우선, 실패 시 기존 폴링 폴백(무예외). 엔진 수정 없음 |
| 수익곡선 드로우인 | 결과 로드 시 곡선 progressive reveal 애니메이션(rAF). ※ 단일 CLI 백테는 CSV 를 종료 시점에 쓰므로 "실행 중 실시간 곡선"은 엔진 변경 없이는 불가 — 이 한계를 명시하고 완료 시 애니메이션으로 체감 제공 |
| 차트 인터랙션 | 수익곡선: 줌(휠)/팬(드래그)/크로스헤어 + **브러시 구간 선택 → `/bt/analysis/*?t_start&t_end`(매수시간 필터) 재계산** → 히트맵·분포·인사이트·메트릭이 선택 구간 기준으로 갱신 |
| 메트릭 모션 | 카운트업(rAF), MDD·승률 SVG 게이지, 일별손익 스파크라인, severity glow(CSS 추가만 — 기존 룰 수정 금지) |
| MAE/MFE 산점도 | x=R_MAE, y=R_MFE, 색=수익률, 사분면 가이드 + 호버 상세. 보너스: 매도조건별 손익 분해 미니 패널 |

## 2단계 — 분석 전문화 (인사이트 깊이)

| 항목 | 설계 |
|------|------|
| A/B 비교 | `GET /bt/compare?job_a&job_b` → 메트릭 나란히 + 수익곡선 오버레이 + 히트맵/분포 병렬. 프론트 잡 이력에서 2개 선택 |
| 몬테카를로 | `backtest_analysis.monte_carlo(df, n=2000)` — 일별 손익 셔플 재배열 → MDD 분포(백분위)·최종자본 히스토그램·파산확률(자본 파라미터) + 팬 차트 |
| 오더플로우 분석 | CSV 의 B_체결강도/B_매수·매도총잔량(불균형비)/B_전일동시간비 를 **승/패 그룹 비교 분포**로 — "이기는 진입의 오더플로우 프로파일" |
| 통계 검정 인사이트 | 요일·시간대 효과 z-검정(scipy 가용 시 t/chi², 아니면 수동 근사) — "유의미(p<0.05)" 표기로 인사이트 신뢰도 구분 |

## 3단계 — 시뮬레이션 고도화

| 항목 | 설계 |
|------|------|
| 차트 엔진 | lightweight-charts standalone 을 vendor 시도(jsdelivr). 다운로드 불가 시 기존 SVG 에 줌/팬/크로스헤어 직접 구현 폴백 — 시도 결과를 문서화 |
| 변수 라이브 뷰 | 리플레이 프레임에 서버 계산 지표 추가(MA5/20/60, 호가불균형=매수총잔량/매도총잔량, 체결강도) → 종목별 현재값 테이블 패널 |
| 히트 스트립 | 차트 하단 체결강도 색 밴드(시간축 정렬) |
| 학습 모드 | 신호 도달 자동 일시정지 토글, 신호 북마크 목록→클릭 시킹, 키보드(Space 재생/일시정지, ←→ 배속) |
