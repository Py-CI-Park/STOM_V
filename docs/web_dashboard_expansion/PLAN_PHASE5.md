## §0. 사용자 피드백 SSOT

1. **(핵심 신고) 차트 시뮬레이션이 시간이 흐르는 리플레이처럼 진행되지 않음** — 1tick=1초, 1min=1분봉 느낌으로 시간 경과에 따라 진행돼야 함(배속 반영한 wall-clock 페이싱).
2. 시뮬레이션에 **보조지표** 표시, **호가·호가 오더플로우**를 (DB 컬럼 상세 조사 기반으로) 시각화, **거래량**도 시뮬레이션.
3. **여러 차트 동시 보기**: ①오버레이(한 차트에 겹쳐) ②분할 보기 — 모두 구현.
4. 진화 대시보드의 **리서치 랩/결과 분석** 기능을 백테스트 탭 시각화 수준으로 강화.
5. **백테스트 탭** 추가 기능 강화 연구·개선(GUI_PARITY_MATRIX 잔여 포함).
