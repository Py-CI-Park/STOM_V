## 3. 공통 계산 지표

```python
# =========================================
# 공통 계산 지표 (조건식 상단에 정의)
# =========================================

# 3.1 가격 관련 지표
고저범위 = 고가 - 저가
고저평균가 = (고가 + 저가) / 2
시가등락율 = (현재가 / 시가 - 1) * 100 if 시가 > 0 else 0
저가대비등락율 = (현재가 / 저가 - 1) * 100 if 저가 > 0 else 0

# 3.2 호가 잔량 금액 환산 (억원 단위)
매도총잔량금액 = 매도총잔량 * 현재가 / 100000000
매수총잔량금액 = 매수총잔량 * 현재가 / 100000000

# 3.3 순매수 관련 지표
초당순매수수량 = 초당매수수량 - 초당매도수량
초당순매수금액 = 초당순매수수량 * 현재가 / 1000000  # 백만원 단위

# 3.4 체결강도 관련
현재가변화율 = (현재가 / 현재가N(1) - 1) * 10000 if 현재가N(1) > 0 else 0

# 3.5 거래대금 관련
평균초당거래대금 = 당일거래대금 / 데이터길이 if 데이터길이 > 0 else 0
초당거래대금비율 = 초당거래대금 / 초당거래대금평균(30) if 초당거래대금평균(30) > 0 else 0

# 3.6 위치 관련 (현재가의 고저대비 위치)
현재가위치 = (현재가 - 저가) / 고저범위 * 100 if 고저범위 > 0 else 50
```
