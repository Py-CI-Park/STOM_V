# Sample Runbook

Use this sequence to inspect the dashboard with dummy data.

1. Open `index.html`.
2. Confirm the global shell appears with REST/WS status and run controls.
3. On `조건식 AI`, click `전략 인스펙터` and confirm code modal opens.
4. Click `설정` and confirm the settings modal shows six groups.
5. Switch to `프로세스` and confirm the Generation → Backtest → Scoring → Autopsy → Repeat map appears.
6. Switch to `히스토리` and confirm archive table and Run Detail drawer appear.
7. Switch to `연구실` and confirm Edge Ratio, variable importance, correlation, combinations, holdout panels render.
8. Switch to `분석 워크벤치` and confirm HOF candidates and evidence notes render.
9. Switch to `결정 감사` and confirm append-only ledger and decision form render.
10. Switch top tab `백테스트` and confirm run panel, code editor, results, report button render.
11. Switch top tab `차트 리플레이` and confirm tick/min source, stock list, replay controls, candle charts, signal log, websocket status, and error banner render.
12. Confirm no live order, broker login, or account trading control is present.
