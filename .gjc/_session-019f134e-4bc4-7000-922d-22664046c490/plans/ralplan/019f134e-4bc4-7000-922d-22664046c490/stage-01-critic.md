**Required fixes before execution approval**:
1. Add a mandatory Phase 0 Process Data-Source Matrix. Rows must include run selector, node status, node drilldown, queue depth, logs, SLA/time, freshness/age, stale/error/loading, boundary contracts, and provenance banner. Each row must name exact read-only endpoint and field, fallback/reference label, DOM selector or assertion target, and how changed payloads and missing fields fail.
2. Add a mandatory Phase 0 Action and WebSocket Safety Matrix. Rows must include global Start, global Stop, /ws inbound messages, final_approval/export, record_decision, Process export, Lab export/save, Audit export, Backtest POST/job metadata, replay /sim/ws controls, settings and localStorage. Each row must classify read-only allowed, user-gated non-protected action, or forbidden protected write, and include network assertions for no page-load POST, no hidden export, no protected runtime writes, no auto /sim/ws, and no live control frames except explicitly approved manual actions.
3. Convert the 100-point rubric into deterministic checks. Keep the weights, but define binary or weighted observable evidence for each bucket, including DOM assertions, interaction traces, screenshots, accessibility checks, payload mutation checks, and reviewer signoff criteria.
4. Tighten acceptance so API 200 cannot pass alone. A 200 response with missing required fields must fail, changed payloads must change visible DOM and provenance, stale data must show stale state, fallback must be labelled, and fixture-only live claims must fail.
5. Preserve the explicit V2/V3 safety invariant in verification. Include assertions that /ui defaults to V2, /ui/remodel and dashboard_version=v3 select V3, V2 files are reference-only unless deliberately changed, and no safety copy implies broker login, account trading, or live order authority.

**Verdict**: ITERATE. This is not a rejection of the architecture. The plan becomes approvable once the architect WATCH items are incorporated as hard Phase 0 gates with concrete acceptance and network evidence.
