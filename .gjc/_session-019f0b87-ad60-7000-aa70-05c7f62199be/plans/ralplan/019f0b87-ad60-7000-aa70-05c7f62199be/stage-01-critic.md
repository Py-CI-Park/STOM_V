## Required revisions
1. Choose and bound the adapter seam. State the allowed implementation shape: either endpoint-derived view models plus small imperative controllers inside the zip shell, or explicit React islands with fixed mount points and visual contract tests. Forbid unbounded reimplementation of production React state machines. Define the invalidation trigger that routes to the React rebuild fallback.
2. Add a fail-closed mode matrix. For `reference`, require frozen fixtures only: no REST, no WS, no timers/reconnect loops, no random values, no localStorage mutation or base URL override, and all mutating actions disabled or inert with visible reference-mode messaging. For `demo`, allow local fixtures/fallback with a banner. For `live`, allow real REST/WS with visible loading/error/fallback states. Capture scoring must run only in `reference`.
3. Add `/bt/*` endpoint/action/evidence matrix. Include every real route and production action owner: health; strategies; strategy get/validate/save/delete; variables and extract_vars; legacy/self_vars; backfinder/preflight; data_range; run/jobs/job/cancel/job_meta; result/evo_gens; all analysis routes; compare; overlay; portfolio; report; ws_job. For each row include UI control, method, reference behavior, live behavior, error state, and required artifact.
4. Add `/sim/*` endpoint/action/WS matrix. Include `/sim/health`, `/sim/days`, `/sim/demo`, `/sim/stocks`, `/sim/signals`, `/sim/ws`, and `/bt/strategies` usage. Include WS client actions `start/pause/resume/speed/seek/stop`, server messages `meta/bars/history/done/error`, and evidence for playback, pause/resume, speed, seek/history, stop, error display, and recovery.
5. Define the artifact manifest schema. Require per page: route, mode, viewport, screenshot path, diff path, weighted visual score, corrected total score, console status, modal coverage, API calls, WS transcript, forbidden scan result, timestamp, worktree/commit metadata, and pass/fail thresholds. Include all 8 pages and modal states.
6. Strengthen the deliberate-mode test plan. Expand the pre-mortem into concrete gates for fixture masking, adapter duplication, API secondary endpoint omission, WS flakiness, safety regression, and score inflation. State that no 100-point or completion claim is allowed unless all manifest rows and score thresholds pass with evidence.
7. Clarify local research mutations versus prohibited safety controls. Reference mode must disable save/delete/run/cancel/job_meta/portfolio mutation paths. Live mode may expose local research/backtest mutations only with visible confirmation and non-export semantics. It must still forbid live order, broker login, account/balance trading controls, hidden/automatic production export, and mutable audit edits/deletes.
