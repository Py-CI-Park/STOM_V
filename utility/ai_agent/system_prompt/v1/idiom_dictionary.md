# 원리 개념 → STOM 변수 관용구 사전 (idiom dictionary v1)

> **본 문서는 개인 트레이더 구조론(백테스트 미검증 가설 체계)의 개념을 STOM 조건식 변수 관용구로 변환한 사전이다.**
> 출처: `chart_sulsa_stom_quant_insight_report_v7_0.html` §2 "이론을 수식으로 바꾸는 원칙" + §4~6 조건식(CSS_V7 계열).
> 각 관용구의 **모든 수치 임계값(예시 값)은 무근거 가설**이다 — 그대로 이식하지 말고 부검/분위수 피드백으로 보정하라.
> 표기: [tick] = 1초 스냅샷 변수(09:00~09:30 전용), [min] = 1분봉 변수(09:00~15:18, 현재가=1분봉 종가).

## 1. 박스 (box)

### 1.1 박스 상단/하단/폭
- [tick] `박스상단 = 최고현재가(박스틱수, 1)`, `박스하단 = 최저현재가(박스틱수, 1)` — shift=1로 현재 틱 제외. 박스틱수 예시 30 (가설).
- [min] `박스상단 = 최고현재가(박스봉수, 1)`, `박스하단 = 최저현재가(박스봉수, 1)` — 박스봉수 예시 60 (가설).
- 공통 `박스폭율 = ((박스상단 - 박스하단) / 박스하단) * 100` — 압축 판정용. 상한 예시: tick 1.2, min 7.0~8.0 (가설).

### 1.2 박스 상단 돌파 (추세매매 진입)
- 공통 관용구: `돌파율 = ((현재가 - 박스상단) / 박스상단) * 100` 후 `돌파율 >= k`.
- [tick] `박스폭율 <= 1.2 and 돌파율 >= 0.25` + 사건거래대금 + 체결강도 (예시 값 전부 가설).
- [min] `박스폭율 <= 7.0 and 돌파율 >= 0.4` + 사건거래대금(2.0배) + `분당매수수량 >= 분당매도수량 * 1.1` (가설).
- 주의: 돌파 판정 좌변은 반드시 `현재가`(CSC-02), 거래대금 조건 동반 필수(CSC-06).

### 1.3 박스 하단 지지 (박스매매 진입) [min]
- `하단근접율 = ((현재가 - 박스하단) / 박스하단) * 100` 후 `-0.4 <= 하단근접율 <= 1.8 and 현재가 >= 박스하단` (가설).
- 반등 확인: `하단꼬리반등위치 = (현재가 - 분봉저가) / (분봉고가 - 분봉저가)` 후 `>= 0.55` (가설).
- 거래대금은 과열이 아닌 정상 범위 확인: `0.5 <= 거래대금비율 <= 2.5` (상한이 있는 게 특징, 가설).

### 1.4 장기 박스 급등주 후보 [min]
- `장기상단 = 최고현재가(120, 1)`, `장기폭율 <= 12.0 and 장기돌파율 >= 0.6 and 거래대금비율 >= 2.5 and 체결강도 >= 115` + 추세정렬 `현재가 > 이동평균(20) and 이동평균(20) >= 이동평균(60) * 0.995` (전부 가설).

## 2. 사건거래대금 (event turnover)

- 원리: 절대량이 아니라 **주변 평균 대비 비율**로 사건봉을 정의.
- [tick] `거래대금비율 = 초당거래대금 / 초당거래대금평균(평균틱수)` — 돌파 확인 하한 예시 1.8~2.0, 리테스트는 상하한 밴드 `0.6 <= 비율 <= 4.0` (가설).
- [min] `거래대금비율 = 분당거래대금 / 분당거래대금평균(평균봉수)` — 돌파 하한 예시 1.5~2.5, 지지/리테스트 밴드 예시 0.45~2.8 (가설).
- 눌림 국면은 거래대금 **감소**(매도 압력 약화)가 정상: 상한 조건이 관용구에 포함된다.
- 유동성 기초 필터: [min] `당일거래대금 >= 100` (단위: 백만원 계열, 값은 가설).

## 3. 수급 우위 (order-flow dominance)

### 3.1 매수우위 (진입 확인)
- [tick] `초당매수수량 >= 초당매도수량 * k` (k 예시 1.0~1.1, 가설), `순매수수량 = 초당매수수량 - 초당매도수량 > 0`.
- [min] `분당매수수량 >= 분당매도수량 * k` (k 예시 1.1, 가설).

### 3.2 매도우위 (청산 트리거)
- [tick] `매도우위 = 초당매도수량 > 초당매수수량 * k and 체결강도비율 <= m` (k 예시 1.3~1.5, m 예시 0.9 — 체결강도 하락 동반, 가설).
- [min] `매도우위 = 분당매도수량 > 분당매수수량 * k and 체결강도비율 <= m` (k 예시 1.2, m 예시 0.9, 가설).
- 관용구 핵심: 수량 역전 **and** 체결강도 약화의 이중 확인.

### 3.3 체결강도 관용구
- 공통 `체결강도비율 = 체결강도 / 체결강도평균(N)` — 절대 하한(예시 95~115)과 비율 하한(예시 0.9~1.05)을 함께 쓴다 (가설).

### 3.4 호가압력 [tick 전용]
- `호가압력 = 매수총잔량 / (매수총잔량 + 매도총잔량)` — 진입 하한 예시 0.43~0.45, 청산 경보 예시 <= 0.35 (가설). min에는 사용하지 않는 관용구.

## 4. 도지 = 압축 박스 (doji as compressed box)

### 4.1 캔들형 도지 판정 [min]
- `전봉몸통 = abs(현재가N(1) - 분봉시가N(1))`, `전봉범위 = 분봉고가N(1) - 분봉저가N(1)`, `도지비율 = 전봉몸통 / 전봉범위`.
- 도지 = `전봉범위 > 0 and 도지비율 <= 0.25` (0.25는 가설).
- 도지 3선: `도지상단 = 분봉고가N(1)`, `도지하단 = 분봉저가N(1)`, `도지종가 = 현재가N(1)`.

### 4.2 도지 압축 대체 정의 [tick] — 폭·중심괴리
- tick에는 캔들 도지가 없으므로 **미세 횡보 압축**으로 근사:
  - `도지상단 = 최고현재가(압축틱수, 1)`, `도지하단 = 최저현재가(압축틱수, 1)`, `도지중심 = 이동평균(압축틱수, 1)` (압축틱수 예시 30, 가설).
  - `압축폭율 = ((도지상단 - 도지하단) / 도지중심) * 100` — 압축 판정 `<= 0.8` (가설).
  - `중심괴리율 = abs(현재가N(1) - 도지중심) / 도지중심 * 100` — `<= 0.25` (가설).
- 압축 돌파 매수: `압축폭율 <= 0.8 and 중심괴리율 <= 0.25 and 돌파율 >= 0.2` + 사건거래대금 (전부 가설).

### 4.3 도지 내부 지지 매수 [min]
- `내부위치 = (현재가 - 도지하단) / (도지상단 - 도지하단)` 후 `0.0 <= 내부위치 <= 0.55` (매수 우위 구간, 가설).
- 하단 이탈 실패 확인: `분봉저가 <= 도지하단 * 1.002 and 현재가 >= 도지하단 * 1.003` (가설).

### 4.4 도지 상단 돌파 매수 [min]
- `현재가 >= 도지상단 * 1.0025 and 현재가 >= 도지종가` + 거래대금비율 >= 1.5 (가설).

### 4.5 도지 하단 이탈 청산
- [min] `현재가 < 도지하단 * 0.997 and 매도우위`, 보조로 `현재가 < 도지종가 * 0.995 and 수익률 <= 0 and 매도우위` (가설).
- [tick] `하단이탈율 = ((현재가 - 도지하단) / 도지하단) * 100 <= -0.25 and 매도우위`, 중심 이탈 `현재가 < 도지중심 * 0.997` (가설).

## 5. 리테스트 / 저항→지지 스위치 (retest)

### 5.1 기준선(과거 저항) 정의 — 이중 shift 관용구
- 공통: `기준상단 = 최고현재가(기준N, 돌파확인N)` — 돌파확인N만큼 과거로 밀어 "돌파 이전의 저항"을 잡는다.
  - [tick] 기준틱수 60, 돌파확인틱수 20 (가설). [min] 기준봉수 60, 돌파확인봉수 10 (가설).

### 5.2 최근 돌파 전제 확인
- `최근돌파율 = ((최고현재가(돌파확인N, 1) - 기준상단) / 기준상단) * 100 >= k` — "직전 구간에 돌파가 실제로 있었다"의 확인. k 예시: tick 0.5, min 0.8 (가설).

### 5.3 기준상단 근접율 (리테스트 존)
- `현재위치율 = ((현재가 - 기준상단) / 기준상단) * 100` 후 밴드 판정:
  - [tick] `-0.35 <= 현재위치율 <= 0.45` + 바닥 방어 `현재가 >= 기준상단 * 0.996` (가설).
  - [min] `-0.7 <= 현재위치율 <= 1.0` + `현재가 >= 기준상단 * 0.993` (가설).
- 눌림 국면 거래대금은 과열 금지 밴드(§2 참조)와 결합한다.

### 5.4 지지→저항 전환 청산 [min]
- `과거지지 = 최저현재가(60, 10)` (이중 shift로 과거 지지선), `최근이탈 = 최저현재가(10, 1) < 과거지지 * 0.995`, `반등저항 = 현재가 <= 과거지지 * 1.005 and 분봉고가 >= 과거지지 * 0.998` — 셋 다 만족 + 매도우위 시 청산 (전부 가설).

## 6. 기능선 상실 / 손절 (invalidation)

- 매수가 기능선 이탈: `현재가 < 매수가 * k` — k 예시: tick 0.992, min 0.985 (가설).
- 단기저점 이탈: `보유시간 >= t and 현재가 < 최저현재가(N, 1) * k` — 예시: tick t=10초·N=20·k=0.998, min t=3분·N=10·k=0.995 (가설).
- 이동평균 이탈: [tick] `현재가 < 이동평균(30) * 0.995 and 체결강도비율 <= 0.9`; [min] `현재가 < 이동평균(20) and 이동평균(5) < 이동평균(20)` (가설).
- 하드 스톱: `수익률 <= -k` — 예시: tick -2.0~-2.2, min -3.0 (가설). CSC-07의 최소 요건.
- 박스 하단 이탈 청산 [min]: `박스이탈율 = ((현재가 - 최저현재가(60,1)) / 최저현재가(60,1)) * 100 <= -0.5 and 매도우위` (가설).

## 7. 익절 = 다음 기능선 / 트레일링 (profit-taking)

- 목표선 돌파 실패: [min] `수익률 >= 3.0 and 현재가 < 최고현재가(20, 1) and 분당매도수량 > 분당매수수량` (가설).
- 트레일링 반납: 공통 `최고수익률 >= a and 수익률 <= 최고수익률 * b` — 예시: tick a=1.5·b=0.45, min a=4.0·b=0.55 (가설).
- 거래대금 소멸 익절 [min]: `수익률 > 1.0 and 분당거래대금 < 분당거래대금평균(20) * 0.5 and 체결강도 < 체결강도평균(20)` (가설).
- 시간정체 청산: `보유시간 >= t and 수익률 < c` — 예시: tick t=240초·c=0.3, min t=90분·c=1.0 (가설).

## 8. 갭 (gap)

- 전일종가 역산 [min]: `전일종가 = 현재가 / (1 + 등락율 / 100)`.
- `갭등락율 = ((시가 - 전일종가) / 전일종가) * 100` — 밴드 예시 `1.0 <= 갭등락율 <= 8.0` (가설).
- 기능선 결합(CSC-05 필수): `시가 >= 기준상단 * 1.003`(핵심 저항 위 갭) + 눌림 존 `-0.5 <= 현재위치율 <= 1.2 and 현재가 >= 기준상단 * 0.995` (가설).

## 9. 공통 방어 필터 (base filter)

- 가격대: `1000 <= 현재가 <= 100000` (가설).
- 등락율 밴드: 돌파형 `2 <= 등락율 <= 25`, 지지형 `-3 <= 등락율 <= 18` 등 (가설).
- VI 가드: `현재가 < VI가격`. 라운드피겨 가드: `not 라운드피겨위5호가이내`.
- 시간창(CSC-10/11): [tick] `90000 <= 시분초 < 93000` + 매도식 `시분초 >= 93000` 강제 종료; [min] `90000 <= 시분초 <= 151800` + 매도식 `시분초 >= 151800` 종료.
- 상한가 접근 청산: `등락율 >= 29.5` (가설).
- 워밍업: `데이터길이 >= (사용하는 최대 윈도우 + 여유)` — 예: 윈도우 합산 기반 `데이터길이 >= 박스N + 확인N + 30` (가설).

## 10. 최적화 관용구 (self.vars)

- 최적화형 조건식은 임계값을 `self.vars[i]`로 치환하고, 변수 정의는 `self.vars[i] = [[하한, 상한, 스텝], 기본값]` 형식을 쓴다.
- 예: `self.vars[0] = [[20, 40, 10], 30]  # 미세박스틱수` — 범위·기본값 모두 가설이며, 탐색 범위는 과최적화 방지를 위해 좁게 유지한다는 것이 원문 지침이다.
- 워밍업 관용구: `데이터길이 >= int(self.vars[0]) + int(self.vars[1]) + 30` 처럼 윈도우 변수 합산으로 동적 계산.
