# 차트술사 구조론 제약 체크리스트 (constraints v1)

> **본 문서는 개인 트레이더 구조론(백테스트 미검증 가설 체계)에서 유래한 제약을 기계 판정 가능한 형태로 재구성한 것이다.**
> 출처: `chart_sulsa_stom_quant_insight_report_v7_0.html` §1.15 원문 26장 "AI 금지사항" 7개조 + §10 "백테스트와 검증 체계" 주의점.
> 각 항목은 **조건식 텍스트에서 확인 가능한 위반 판정 기준**을 가진다. 판정 기준에 포함된 수치(시간창 경계 제외)는 원문 유래의 **무근거 가설**이다.

## A. AI 금지사항 7개조 (원문 26장)

### CSC-01 — 도지를 단순 캔들로만 해석하지 말 것
- **설명**: 도지는 압축된 박스다. 도지 모양(몸통/범위 비율)만으로 매수하면 안 되고, 도지 이후 시장의 선택(상단 돌파 또는 하단 지지 반응)을 함께 확인해야 한다.
- **위반 판정 기준** (조건식 텍스트에서 확인):
  - 매수식에 도지 판정(예: `도지비율 <= k` 형태의 몸통/범위 비율 조건)이 있으면서, 도지 상단 돌파 조건(`현재가 >= 도지상단*k` 또는 돌파율 조건)도 도지 하단 지지 반응 조건(하단 이탈 실패/반등 위치 조건)도 없는 경우 → 위반.

### CSC-02 — 장중 돌파만으로 판단하지 말 것 (종가 우선)
- **설명**: 판정은 종가 기준이 원칙이다. min 조건식은 `현재가`(=1분봉 종가)로 돌파/이탈을 판정해야 하고, 장중 고가(`분봉고가`)나 `최고현재가(...)` 스파이크 단독으로 돌파를 확정하면 안 된다.
- **위반 판정 기준**:
  - min 매수식에서 돌파 판정 비교식의 좌변이 `분봉고가`(당일봉 고가)인 경우(예: `분봉고가 > 박스상단`) → 위반. 돌파 판정 좌변은 `현재가`여야 한다.
  - tick은 캔들 종가가 없어 `현재가`(초당 스냅샷) 판정을 종가 근사로 허용한다.
  - 참고: `최고현재가(돌파확인N, 1) > 기준상단` 형태는 "과거에 돌파가 있었다"는 리테스트 전제 확인 용도로만 허용(현재 진입 판정은 별도로 `현재가` 기준이어야 함).

### CSC-03 — 박스/추세 구분 없이 분석하지 말 것
- **설명**: 매수 근거는 박스매매(하단 지지), 추세매매(상단 돌파), 눌림매매(리테스트) 중 어느 국면인지 구조 문맥이 조건식에 존재해야 한다.
- **위반 판정 기준**:
  - 매수식에 구간 구조 참조가 전혀 없는 경우 → 위반. 구간 구조 참조 = `최고현재가(N, shift)`/`최저현재가(N, shift)` 기반 상단·하단(박스/기준선) 또는 전봉 고저(`분봉고가N(1)`/`분봉저가N(1)`) 기반 도지 상단·하단 중 최소 1개.
  - 등락율/체결강도/거래대금 조건만으로 구성된 매수식(구조 없는 모멘텀 추격) → 위반.

### CSC-04 — 기능선이 깨졌는데 새로운 이유를 붙이지 말 것
- **설명**: 진입 근거가 사라지면 청산해야 한다. 매도식에는 진입 근거 상실(구조 무효화) 분기가 있어야 하고, 근거 상실 조건에 보유 연장성 예외(수익률이 회복될 때까지 대기 등)를 덧붙이면 안 된다.
- **위반 판정 기준**:
  - 매도식에 구조 무효화 분기(예: `현재가 < 매수가*k`, `현재가 < 최저현재가(N,1)*k`, 박스/도지 하단 이탈)가 전혀 없고 트레일링/고정 익절만 있는 경우 → 위반.
  - 구조 무효화 분기가 `수익률 >= 0` 같은 조건과 AND로 묶여 손실 중에는 무효화 청산이 발동 불가능한 형태 → 위반.

### CSC-05 — 갭 자체만 보지 말 것
- **설명**: 갭은 어떤 기능선을 넘었는지와 함께 해석해야 한다. 갭 등락율 단독 조건으로 매수하면 안 된다.
- **위반 판정 기준**:
  - 매수식에 갭 조건(시가 대 전일종가 비교, `갭등락율` 류)이 있으면서 기준선 비교(예: `시가 >= 기준상단*k` 또는 `현재가 >= 기준상단*k`)가 없는 경우 → 위반.

### CSC-06 — 거래량 없는 돌파를 높게 평가하지 말 것
- **설명**: 돌파 매수는 사건거래대금(평균 대비 거래대금/거래량 증가) 확인을 동반해야 한다.
- **위반 판정 기준**:
  - 돌파형 매수식(상단 돌파율/돌파 비교 조건 존재)에 거래량·거래대금 조건이 전혀 없는 경우 → 위반. 인정되는 조건 예: tick `초당거래대금`/`초당거래대금평균(N)` 비율, min `분당거래대금`/`분당거래대금평균(N)` 비율, `당일거래대금` 하한, 매수/매도 수량 비교.
  - 즉 "**거래량/거래대금 조건 없는 돌파 매수**"는 그 자체로 위반이다.

### CSC-07 — 손절/익절 없이 매매 판단하지 말 것
- **설명**: 매수식에는 반드시 대응 매도식(손절 + 익절 경로)이 짝으로 존재해야 한다.
- **위반 판정 기준**:
  - **매수식에 대응 손절 매도조건 부재** → 위반. 손절로 인정: `수익률 <= -k` 하드 스톱, 매수가 기준 이탈(`현재가 < 매수가*k`), 구조 하단 이탈 청산.
  - 매도식에 익절 경로 부재 → 위반. 익절로 인정: 트레일링(`최고수익률 >= a and 수익률 <= 최고수익률*b`), 목표선 돌파 실패 청산, 시간 정체 청산.

## B. 검증 주의점 (원문 §10 — 조건식/검증 설정에서 판정)

### CSC-10 — tick 조건식 시간창 강제 (09:00~09:30)
- **설명**: 1tick 시스템은 09:00~09:30 장초반 전용이다. tick 조건식을 장중 전체에 사용하면 안 된다.
- **위반 판정 기준**:
  - **tick 조건식의 시간창이 09:00~09:30 밖** → 위반. tick 매수식에 `90000 <= 시분초 < 93000`(또는 동등 범위 이내) 필터가 없거나, 93000 초과 구간을 허용하는 경우.
  - tick 매도식에 `시분초 >= 93000` 강제 종료 분기가 없는 경우 → 위반.

### CSC-11 — min 조건식 시간창 (09:00~15:18)
- **설명**: 1min 시스템은 09:00~15:18 장중 전용이며 현재가=1분봉 종가 전제를 쓴다.
- **위반 판정 기준**:
  - min 조건식이 `시분초` 상한 없이 장 마감 후까지 신호를 허용하거나, `151800` 초과 구간을 매수 허용 → 위반.
  - min 매도식에 `시분초 >= 151800` 종료 분기가 없는 경우 → 위반.

### CSC-12 — tick 검증 시 초단위 슬리피지·호가 리스크 인지
- **설명**: tick 백테스트(09:00~09:30)는 초단위 슬리피지와 호가 리스크가 결과를 왜곡할 수 있다.
- **위반 판정 기준**:
  - tick 매수식이 호가 스프레드/유동성 방어 조건(예: 가격대 필터 `1000 <= 현재가 <= k`, 호가잔량 참조, VI/라운드피겨 가드) 없이 시장가성 진입만 기술 → 위반(주의 등급).

### CSC-13 — min 검증 시 "종가 신호의 다음 체결 가정" 준수
- **설명**: min 백테스트는 종가 기준 신호가 다음 체결에서 실행된다고 가정한다. 신호 봉 자신의 가격으로 체결을 가정하는 수식을 만들면 안 된다.
- **위반 판정 기준**:
  - 조건식이 미래 참조 형태(`현재가N(-1)` 등 음수 시프트, 당일봉 완성 정보를 진입 판정에 선반영)를 포함 → 위반.

### CSC-14 — 일봉 검증 시 미래 데이터 차단·생존 편향 인지
- **설명**: 일봉 검증은 walk-forward/TimeSeriesSplit으로 시간 순서를 보존하고, 미래 데이터 누출과 survivorship bias를 차단해야 한다.
- **위반 판정 기준**:
  - 롤링 기준선 계산에 `shift(1)`(직전까지의 데이터) 없이 당일 값을 포함(예: `rolling_high`에 당일 종가 포함 후 그 값과 당일 종가를 비교) → 위반.
