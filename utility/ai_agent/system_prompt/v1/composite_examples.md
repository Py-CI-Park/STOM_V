# STOM 복합 조건식 구조 예제집 (composite_examples v1)

> **목적**: 생성 LLM이 단조로운 `not(...)` 필터 체인 하나에 갇히지 않고, AND/OR/괄호 결합·
> 시간대 국면 분기·구조론 국면(박스 하단 지지 / 상단 돌파 / 눌림 리테스트)·오더플로우 결합·
> 다단 청산 등 **서로 다른 결합 구조**를 탐색하게 하는 구조 카탈로그다.
>
> **⚠️ 모든 수치 임계값은 무근거 가설이다.** 그대로 복제하지 말고 부검/분위수 피드백으로
> 데이터에서 보정하라. 배울 것은 숫자가 아니라 **결합 구조와 엣지 가설의 형태**다.
>
> 표기 규약(기계 검증용): 각 샘플 코드펜스 첫 줄은 `# [BUY|SELL][tick|min] <ID>` 이다.
> tick 샘플은 초당*/누적초당* 계열만, min 샘플은 분당*/분봉* 계열만 쓴다(스코프 가드 준수).
> 매수 샘플은 반드시 대응 손절/강제청산을 가진 매도식과 짝으로 운용한다(CSC-07).

## A. 매수(BUY) — tick 09:00~09:30

### B-T01 · 화이트리스트 not-체인 (기준 구조 — 정규형)
가설: 여러 필터 범주의 AND 결합이 과발화를 막는다. 가장 보수적인 기본 골격.
```python
# [BUY][tick] B-T01
매수 = True
if 관심종목 != 1:
    매수 = False
elif not (90000 <= 시분초 < 93000):
    매수 = False
elif not (1000 < 현재가 <= 50000):
    매수 = False
elif not (1.0 < 등락율 <= 12.0):
    매수 = False
elif not (당일거래대금 > 500):
    매수 = False
elif not (100 <= 체결강도 <= 300):
    매수 = False
elif 라운드피겨위5호가이내:
    매수 = False
if 매수:
    self.Buy()
```

### B-T02 · 양성 집합식 + OR 결합 (두 셋업 중 하나)
가설: 서로 다른 두 진입 셋업(강돌파 / 수급흡수)을 OR로 묶으면 니치 폭이 넓어진다.
공통 안전 게이트는 AND로 앞단에 둔다.
```python
# [BUY][tick] B-T02
매수 = False
if (90000 <= 시분초 < 92000) and (1000 < 현재가 <= 50000) and (당일거래대금 > 1000):
    강돌파 = (현재가 > 최고현재가(30, 1)) and (초당거래대금 > 초당거래대금평균(30) * 2.0)
    수급흡수 = (체결강도 > 130) and (누적초당매수수량(10) > 누적초당매도수량(10) * 1.5) and (현재가 >= 현재가N(1))
    if 강돌파 or 수급흡수:
        매수 = True
if 매수:
    self.Buy()
```

### B-T03 · 시간대 2-국면 분기 (국면별 다른 임계)
가설: 09:00~09:05(개장 충격)와 09:05~09:20(안정화)은 수급 구조가 달라 같은 변수라도
임계가 달라야 한다. elif 국면 분기로 한 전략 안에서 니치를 나눈다.
```python
# [BUY][tick] B-T03
매수 = True
if not (1000 < 현재가 <= 30000):
    매수 = False
elif not (당일거래대금 > 800):
    매수 = False
elif 시분초 < 90000 or 시분초 >= 92000:
    매수 = False
elif 시분초 < 90500:
    전일종가 = 현재가 / (1 + 등락율 / 100)
    if not (시가 >= 전일종가 * 1.02 and 시가 < 전일종가 * 1.06 and 체결강도 >= 150):
        매수 = False
elif not (0.5 <= 등락율 <= 8.0 and 체결강도 >= 110 and 초당거래대금 > 초당거래대금평균(60) * 1.5):
    매수 = False
if 매수:
    self.Buy()
```

### B-T04 · 박스 하단 지지 매수 (구조론 P3/P8)
가설: 시초 미세 박스의 하단(최저현재가 근접)에서 매도 소진 + 매수세 재유입이 확인되면
하단 지지 반등을 산다. 돌파 추격의 반대 국면.
```python
# [BUY][tick] B-T04
매수 = False
if (90200 <= 시분초 < 92500) and (1000 < 현재가 <= 50000) and (당일거래대금 > 500):
    박스하단 = 최저현재가(60, 1)
    하단근접 = 현재가 <= 박스하단 * 1.003
    반등시작 = (현재가 > 현재가N(1)) and (초당매수수량 > 초당매도수량)
    소진확인 = 체결강도 > 체결강도N(1)
    if 하단근접 and 반등시작 and 소진확인:
        매수 = True
if 매수:
    self.Buy()
```

### B-T05 · 박스 상단 돌파 + 사건거래대금 (구조론 P9/P13, CSC-06 준수)
가설: 돌파는 거래량 동반일 때만 진짜다. 상단 갱신 + 평균 대비 거래대금 급증을 AND로 강제.
```python
# [BUY][tick] B-T05
매수 = True
if not (90000 <= 시분초 < 92500):
    매수 = False
elif not (1000 < 현재가 <= 50000 and 시가총액 < 8000):
    매수 = False
elif not (현재가 > 최고현재가(120, 1)):
    매수 = False
elif not (초당거래대금 > 초당거래대금평균(60) * 2.5):
    매수 = False
elif not (체결강도 >= 120 and 체결강도 > 체결강도평균(30)):
    매수 = False
elif not (당일거래대금각도(30) > 5):
    매수 = False
if 매수:
    self.Buy()
```

### B-T06 · 눌림 리테스트 매수 (구조론 P9 — 돌파 후 되돌림)
가설: 과거 창에서 돌파가 있었고(전제), 현재는 돌파 레벨 근처로 되돌아온 뒤 매수세가
재유입되는 순간이 진짜 기회다. "돌파 순간"이 아니라 "돌파 후 공포"를 산다.
```python
# [BUY][tick] B-T06
매수 = False
if (90300 <= 시분초 < 92800) and (1000 < 현재가 <= 50000) and (당일거래대금 > 800):
    돌파전제 = 최고현재가(60, 1) > 최고현재가(180, 61)
    되돌림위치 = (현재가 < 최고현재가(60, 1) * 0.995) and (현재가 > 최저현재가(30, 1) * 1.002)
    재유입 = (초당매수금액 > 초당매도금액 * 1.2) and (현재가 > 현재가N(1))
    if 돌파전제 and 되돌림위치 and 재유입:
        매수 = True
if 매수:
    self.Buy()
```

### B-T07 · 오더플로우 결합 (호가잔량 x 체결 흐름)
가설: 가격보다 호가/체결 흐름이 먼저 움직인다. 잔량 불균형 + 누적 체결 우위 + 즉시 체결
우위 세 층을 AND로 겹친다.
```python
# [BUY][tick] B-T07
매수 = True
if not (90000 <= 시분초 < 92000):
    매수 = False
elif not (1000 < 현재가 <= 30000 and 1.0 < 등락율 < 10.0):
    매수 = False
elif not (매수총잔량 > 매도총잔량 * 1.2):
    매수 = False
elif not (누적초당매수수량(20) > 누적초당매도수량(20) * 1.3):
    매수 = False
elif not (초당매수수량 > 초당매도수량 * 1.5):
    매수 = False
elif not (당일거래대금 > 500):
    매수 = False
if 매수:
    self.Buy()
```

### B-T08 · 갭 + 기준선 결합 (구조론 P12, CSC-05 준수)
가설: 갭 자체가 아니라 "갭이 어디 위에서 열렸고 시가를 지키는가"가 중요. 갭 밴드 +
시가 회복 유지 + 상대 활성도(전일동시간비)를 결합.
```python
# [BUY][tick] B-T08
매수 = False
if (90100 <= 시분초 < 91500) and (1000 < 현재가 <= 50000):
    전일종가 = 현재가 / (1 + 등락율 / 100)
    갭밴드 = (시가 >= 전일종가 * 1.02) and (시가 < 전일종가 * 1.07)
    시가지킴 = (현재가 >= 시가) and (((현재가 - 시가) / 시가) * 100 >= 0.3)
    활성도 = (전일동시간비 > 100) and (회전율 > 1.0) and (당일거래대금 > 700)
    if 갭밴드 and 시가지킴 and 활성도:
        매수 = True
if 매수:
    self.Buy()
```

### B-T09 · 이동평균 정배열 + 각도 추세 (추세매매)
가설: 초단기 이평 위 + 거래대금 가속 각도 양수 = 추세 지속 구간만 탄다.

```python
# [BUY][tick] B-T09
매수 = True
if not (90200 <= 시분초 < 92800):

elif not (등락율각도(30) > 0 and 당일거래대금각도(30) > 3):
    매수 = False
elif not (체결강도 >= 110):
    매수 = False
elif not (2.0 < 등락율 <= 15.0 and 당일거래대금 > 1000):

    self.Buy()
```

### B-T10 · VI 가드 + 고가권 유지 (위험 필터 강조)
가설: 진입 신호보다 위험 필터가 수익을 지킨다. VI 근접·라운드피겨·고가 이탈을 전부 차단.
```python
# [BUY][tick] B-T10
매수 = True
if not (90000 <= 시분초 < 92500):
    매수 = False
elif not (1000 < 현재가 <= 50000 and 3.0 <= 등락율 <= 20.0):
    매수 = False
elif not (현재가 < VI가격 - VI호가단위 * 5):
    매수 = False
elif 라운드피겨위5호가이내:
    매수 = False
elif not (현재가 > 고가 - (고가 - 저가) * 0.25):
    매수 = False
elif not (고저평균대비등락율 > 0 and 체결강도 >= 100 and 당일거래대금 > 800):
    매수 = False
if 매수:
    self.Buy()
```

### B-T11 · 신선 이벤트 트리거 (직전 대비 변화율 — 상시참 방지)
가설: 레벨 조건만 있으면 매 틱 항상참으로 과발화한다. "직전 대비 급변"을 트리거로 써서
이벤트 순간에만 발화시킨다.
```python
# [BUY][tick] B-T11
매수 = False
if (90000 <= 시분초 < 92000) and (1000 < 현재가 <= 50000) and (0.5 < 등락율 < 10.0):
    거래급증 = 초당거래대금 > 초당거래대금N(1) * 3.0
    강도점프 = 체결강도 > 체결강도N(1) + 15
    가격확인 = 현재가 > 현재가N(1)
    if 거래급증 and (강도점프 or 가격확인) and 당일거래대금 > 300:
        매수 = True
if 매수:
    self.Buy()
```

### B-T12 · 시총 티어 x 등락 국면 매트릭스 (classification 축 구현)
가설: 소형주 급등 초입과 중형주 완만 상승은 다른 조건이 맞다. 시총으로 분기해 국면별
임계를 다르게 준다(니치 매트릭스를 한 전략에 압축).
```python
# [BUY][tick] B-T12
매수 = False
if (90000 <= 시분초 < 92500) and (당일거래대금 > 500) and (현재가 < VI가격 - VI호가단위 * 5):
    if 시가총액 < 2000:
        if (4.0 <= 등락율 <= 18.0) and (체결강도 >= 140) and (초당거래대금 > 초당거래대금평균(30) * 2.0):
            매수 = True
    elif 시가총액 < 8000:
        if (1.5 <= 등락율 <= 9.0) and (체결강도 >= 115) and (누적초당매수수량(30) > 누적초당매도수량(30)):
            매수 = True
if 매수:
    self.Buy()
```

## B. 매수(BUY) — min 09:00~15:18

### B-M01 · 분봉 박스 상단 돌파 + 분당거래대금 급증 (종가 기준, CSC-02 준수)
가설: min에서 현재가=1분봉 종가. 종가가 전봉 고가(=미세 박스 상단)를 넘고 분당 거래대금이
평균 대비 급증하면 돌파로 본다.
```python
# [BUY][min] B-M01
매수 = True
if not (90100 <= 시분초 <= 151800):
    매수 = False
elif not (1000 < 현재가 <= 100000):
    매수 = False
elif not (현재가 > 분봉고가N(1)):
    매수 = False
elif not (분당거래대금 > 분당거래대금평균(20) * 2.0):
    매수 = False
elif not (1.0 < 등락율 <= 15.0 and 당일거래대금 > 1000):
    매수 = False
elif not (체결강도 >= 100):
    매수 = False
if 매수:
    self.Buy()
```

### B-M02 · 도지 압축 해소 (구조론 P6 — 압축 후 선택)
가설: 전봉이 좁은 범위(도지=압축 박스)였고, 이번 봉이 그 상단을 종가로 넘으면 압축 해소
방향에 올라탄다.
```python
# [BUY][min] B-M02
매수 = False
if (90200 <= 시분초 <= 150000) and (1000 < 현재가 <= 100000) and (당일거래대금 > 800):
    전봉폭 = 분봉고가N(1) - 분봉저가N(1)
    압축 = 전봉폭 <= 현재가 * 0.006
    상방선택 = (현재가 > 분봉고가N(1)) and (분당매수수량 > 분당매도수량)
    if 압축 and 상방선택 and (0.5 < 등락율 <= 12.0):
        매수 = True
if 매수:
    self.Buy()
```

### B-M03 · 눌림 지지 재매수 (min 리테스트)
가설: 당일 상승 후 이동평균 부근까지 눌렸다가 종가가 이평 위에서 다시 서면 눌림 완성.
```python
# [BUY][min] B-M03
매수 = False
if (93000 <= 시분초 <= 145000) and (1000 < 현재가 <= 100000) and (2.0 <= 등락율 <= 18.0):
    눌림위치 = (저가 <= 이동평균(20) * 1.005) and (현재가 >= 이동평균(20))
    수급유지 = (분당거래대금 > 분당거래대금평균(60)) and (체결강도 >= 95)
    추세존속 = 이동평균(20) > 이동평균(60)
    if 눌림위치 and 수급유지 and 추세존속:
        매수 = True
if 매수:
    self.Buy()
```

### B-M04 · 오전/오후 국면 분기 (풀세션 시간 구조)
가설: 오전(추세 형성)과 오후(수렴/재돌파)는 다른 셋업이 맞다. OR로 두 국면 셋업을 병렬.
```python
# [BUY][min] B-M04
매수 = False
if (1000 < 현재가 <= 100000) and (당일거래대금 > 1500) and (체결강도 >= 100):
    오전돌파 = (90500 <= 시분초 < 113000) and (현재가 > 분봉고가N(1)) and (분당거래대금 > 분당거래대금평균(30) * 1.8)
    오후재돌파 = (130000 <= 시분초 <= 150000) and (현재가 > 최고현재가(60, 1)) and (분당매수금액 > 분당매도금액 * 1.3)
    if 오전돌파 or 오후재돌파:
        매수 = True
if 매수:
    self.Buy()
```

## C. 매도(SELL) — tick (매수와 반드시 짝, CSC-07/CSC-10 준수)

### S-T01 · 3중 안전망 (하드스톱 + 트레일링 + 시간 강제청산) — 기준 구조
가설: 어떤 매도식이든 이 3중 안전망이 골격이다. 닫히지 않는 포지션은 없어야 한다.
```python
# [SELL][tick] S-T01
매도 = False
if 시분초 >= 92700:
    매도 = True
elif 수익률 <= -2.0:
    매도 = True
```

## E. 구조 결합 치트시트 (생성 시 참고)

| 구조 | 형태 | 쓰임 |
|---|---|---|
| not-체인 AND | `elif not (A): 매수=False` 반복 | 보수적 필터 누적(기본) |
| 양성 집합 + OR | `if 공통게이트: if 셋업A or 셋업B: 매수=True` | 니치 폭 확장 |
| 국면 분기 | `elif 시분초 < X: ... elif ...` / 시총 분기 | 국면별 임계 차등 |
| 중간변수 명명 | `돌파전제 = ...` 후 `if 돌파전제 and ...` | 가설 가독성/부검 용이 |
| 이벤트 트리거 | `X > XN(1) * k` (직전 대비) | 상시참 과발화 방지 |
| 구조 참조 | `최고현재가/최저현재가/분봉고가N/분봉저가N` | 박스/돌파/눌림 국면 명시(CSC-03) |
| 다단 임계 | 매도에서 이익 크기별 elif 사다리 | give-back 차등 통제 |

금지 재확인: 매수식에 매도 전용 변수(수익률 등) 금지, tick↔min 계열 혼용 금지,
거래량 없는 돌파 매수 금지(CSC-06), 매도식에 손절+강제청산 부재 금지(CSC-07).
