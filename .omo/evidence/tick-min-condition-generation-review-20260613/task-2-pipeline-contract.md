## Key Findings

- `LoopConfig` exposes the required contract fields: `bt_timeframe`, `full_session_enabled`, `bt_min_universe_end_time`, `time_cap_bucket_generation_enabled`, and `time_cap_bucket_end_time`.
- `_generate_pair` passes time-cap and generation-quality toggles into `generate_strategy`; this covers tick LLM prompt construction.
- `time_cap_bucket.py` supports only 09:20 and 09:30 end times. For 09:30 it adds explicit 09:20~09:25 and 09:25~09:30 bucket guidance, including a note to test 09:20~09:25 as a standalone branch.
- The min full-session data window is wired in `_build_warm_btconfig`, but the LLM prompt guidance is not yet a full-session min guide. `encourage_time_dispersion` still says 09:00~09:20 and should not be counted as a 09:00~15:00 exploration policy.
- TMAP generation is stronger than LLM generation for immediate development because the tick/min templates already encode the intended windows explicitly.
