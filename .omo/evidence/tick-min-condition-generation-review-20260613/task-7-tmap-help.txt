usage: tmap_sweep.py [-h] --template TEMPLATE --config-json CONFIG_JSON
                     --run-id RUN_ID [--params PARAMS]
                     [--max-points MAX_POINTS] [--manifest-out MANIFEST_OUT]
                     [--resume] [--grid GRID]
                     [--replicate-baseline REPLICATE_BASELINE]

options:
  -h, --help            show this help message and exit
  --template TEMPLATE
  --config-json CONFIG_JSON
  --run-id RUN_ID
  --params PARAMS       스윕할 슬롯 부분집합(쉼표). 비우면 전체
  --max-points MAX_POINTS
  --manifest-out MANIFEST_OUT
  --resume              같은 run-id의 기존 ok 세대는 건너뛰고 error/누락 포인트만 평가(중단 재개)
  --grid GRID           C6/P1 — 2-D 격자 모드 'paramA,paramB' (--params와 배타)
  --replicate-baseline REPLICATE_BASELINE
                        C5'/N8 — 기본값 점 추가 측정 횟수(노이즈 밴드 산출)
