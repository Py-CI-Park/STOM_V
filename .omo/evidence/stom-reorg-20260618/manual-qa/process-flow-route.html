🎯 목표 & 마인드셋 — 광산에서 수익 나는 매수/매도 조건식(실매매용 per-stock if-Buy)을 캐낸다. 데이터에 알파는 실재한다 — 검증 챔피언이 발굴 게이트로 +9.5~11M을 재현(§1.5). "데이터 천장"이 아니다. 병목은 콜드 LLM 생성이고, 다음은 검증 앵커를 변이하는 v2 레짐인식 루프(§1.6). 엔진/CLI 무수정.

🪙 이게 무슨 연구인가요? (아주 쉬운 설명)

조건식 = 금광맥 ⛏️
"이런 종목을·이 시간에·이 신호가 뜨면 사라(팔아라)"는 매수/매도 규칙(코드). 우리가 캐려는 광석. 실매매 프로그램에 바로 넣는 산출물.
백테스트 = 금 감정사 🔍
그 규칙을 과거 데이터에 적용해 "진짜 돈이 됐나" 계산. 가짜 금(과적합)을 골라냄.
이 시스템 = 자동 채굴기 🤖
AI가 규칙을 만들고 → 백테로 검증하고 → 실패에서 배워 다음엔 더 잘 캐도록 *스스로 반복*.
한눈에 흐름 — ① AI가 규칙을 만든다 → ② 과거 2분기로 빠르게 본다 → ③ 통과하면 3년 전체로 본다 → ④ 다른 해(미래)로도 본다 → ⑤ 가짜면 검문소(게이트)가 막는다 → ⑥ 실패를 기억해 다음엔 안 만든다 → ↻ 반복.
💡 지금 상태(2026-06-16): P0~P5 폐루프 구현완료. 양성대조 진단으로 알파 실재·게이트 정상·병목=콜드 생성 확정(§1.5). 콜드 LLM 신규 발굴은 0이지만 검증 챔피언은 게이트 통과 → 다음 = 앵커 변이(v2)로 ①생성 단계 교체. "없다"가 아니라 "콜드 생성으론 아직".

🔁 1.6 다음 방향 — v2 레짐 인식 폐루프 (콜드 생성 → 앵커 변이)

① 레짐별 분석
변수 영향성을 레짐(연도·변동성·시총/시간)별로
feature_importance/히트맵/상관으로 변수별 영향·안정성·부상/소멸(회전율型) 탐지. 전역 1장이 아니라 레짐별.
↓
② 타겟 결정 = 탐색 + 활용
AI 질문 + 사람 사전지식
활용(영향 크고 안정적 변수→고원 중심) + 탐색(예산 일부를 약하지만 부상 가능·더 넓은 범위·미검증 상호작용·레짐별 경향에 의무 배정).
↓
③ 다축 변이 (mutator + grid)
시간·시총·익절·트레일… 여러 축 동시
앵커(검증 챔피언)에서 출발해 한 칸씩 + 2축 grid. 전 범위 형태 탐색(방향 단정 X). 신규 컬럼·횡단면 항 0.
↓
④ 레짐-robust 게이트
넓힌 만큼 강하게: WF + OOS + 다중검정보정
채택 = 여러 레짐에서 robust한 것만(한 해 최고는 기각). 탐색 폭↑ → 검증 강도↑ (과적합 비례 차단).
↻ ⑤ 반복 — 영향성 지도 갱신(부상 변수 재포착) → ②로. 사장님 수동법("조금씩 바꿔보고 영향 큰 것 찾아 바꾸기")의 자동화.
v2는 별도 프로세스가 아니라 위 폐루프의 ①생성 단계 업그레이드(콜드 LLM → 검증 앵커 변이) — ②~⑥ 게이트·OOS·환류는 그대로 재사용. v1(greedy)과 차이: 분석=레짐별·타겟=탐색+활용·방향=전범위·채택=레짐robust. "넓은 탐색 ↔ 강한 검증"은 한 쌍.

3. 실제 산출물 예시 (탭)

📝 생성 프롬프트
🧬 챔피언 조건식(T2C3)
🤖 최근 생성물
📊 변수→수익 추적(DB)
↻ 환류 피드백
🚦 게이트 판정
LLM에게 주는 실제 지시(시간대 분할·앵커·밀도·비용 규칙). 숫자는 슬롯({})으로 비움.
[역할] 너는 한국 주식 틱 단위 오더플로우 단타 전략 설계자다. 너의 산출물은
완성된 전략 코드가 아니라 **모수화된 템플릿(구조 가설)**이다 — 숫자는 기계가
지도(coordinate sweep)로 측정하므로, 너는 구조와 탐색 범위만 설계한다.

[성공 예시 — 구조→성과 연결]
- 시드 902/905: 09:02~09:05 창에서 거래대금각도·초당거래대금 폭발 조합
  → 3년 +863만. 지도 측정: 익절을 5%→9%로 늦추면 +15%, 시총 상한
  3000→2500이면 MDD -30% (청산 다이얼이 수익 지배).
- THETA 3중 조합(시총2500+익절9%+트레일4%): 3년 +1,097만, 3/3년 흑자,
  OOS 2026에서 시드 적자를 흑자로 반전.
- ★T2C3(다밴드 = 한 조건식에 여러 시간대): THETA(09:00~05 소형주 첫돌파)에
  제3밴드(09:05~{ext_end} 시총 반전 대형주)를 if/elif로 더하니 OOS 2022 +24%·
  OOS 2026 +143%·워크포워드 4창 전부 적격 — 단일밴드 THETA를 일반화에서 능가.
  교훈: **시간대×시총 밴드를 하나 더 더하면 일반화가 좋아질 수 있다. 단 각
  밴드가 독립적으로 깨끗한(자기 강한 게이트를 가진) 전략이어야 한다.**

[실패 예시 — 반복 금지]
- 보고서 임계값 직접 이식 5/5 음수: 숫자는 데이터 창마다 다르다.
  구조를 가져오고 숫자는 슬롯으로 비워라.
- ★점수합산(build_v5): 20개 약한 플래그 점수를 더해 임계 넘으면 매수 →
  -1.11억/4,989건 전멸. **"신호 합의(점수 합산)"는 품질 분별자가 아니다.**
  다밴드는 점수합산이 아니라 if/elif **이산 분기**로 — 한 시점엔 한 밴드만
  발화하고, 각 밴드는 자기 강한 AND 게이트를 갖는다. 약한 신호를 OR/합산으로
  모으지 마라.
- 시간 확장(window_end↑)은 일관되게 악화 — 후반부 밴드일수록 신호 가치가
  낮으니, 후반 밴드는 더 강한 게이트(시총/체결강도/거래대금 폭발)로 좁혀라.
- 고가미갱신지속틱수·저가미갱신지속틱수: 무한 역스캔 — 사용 금지(타임아웃).

[엔진 계약 — 위반 시 자동 기각]
- 매수/매도 코드는 매 틱 평가되고 self.Buy() / self.Sell()을 무인자 호출.
- 단위: 시가총액=억, 당일거래대금·초당거래대금=백만원.
- 윈도우 함수(이동평균/등락율각도/초당거래대금평균 등)는 첫 인자(틱 수) >= 1,
  시프트 인자 >= -1 (그 외 음수는 미래참조로 기각).
- 매도식의 윈도우 집계 호출 총수 8회 이하.
- ★min(분봉) timeframe 전용 어휘만 사용(없는 변수 발명 시 즉시 기각):
  · min 전용: 분당거래대금, 분당거래대금평균(N,1), 분당매수수량, 분당매도수량,
    누적분당매수수량(N), 누적분당매도수량(N), 체결강도평균(N,1), 등락율각도(N), 이동평균(N,1)
  · 공통: 현재가, 고가, 저가, 시가, 등락율, 체결강도, 시가총액, 전일동시간비, 회전율,
    당일거래대금, 시분초, 데이터길이 / 매도: 수익률, 최고수익률, 보유시간
  · **min에 없음(발명 금지)**: 직전분봉고가·누적분당거래대금·보유수익률·초당*(tick 전용).
    "직전 고가 돌파/재가속"은 `현재가 >= 이동평균(N,1) * 배수` 또는
    `분당거래대금 >= 분당거래대금평균(N,1) * 배수`로 표현하라.

[과제] {principle_text} 원리를, 시드 902/905·T2C3처럼 **시간대×시가총액 이산
분기 조건식(다밴드)**으로 설계하라. ★먼저 **가용 시간 전체를 의미 있는 구간으로
나눠 여러 시간대를 적극 고려**하라:
  - tick(09:00~09:30): 시초(09:00~05) / 중반(09:05~15) / 후반(09:15~30)
  - min(09:00~15:00): 개장(09:00~10:00) / 오전(10:00~11:30) / 점심(11:30~13:00) / 오후(13:00~15:00)
그 중 **시간대가 다른 2~3개 밴드**를 골라 한 조건식에 if/elif로 담되, 점수합산이
