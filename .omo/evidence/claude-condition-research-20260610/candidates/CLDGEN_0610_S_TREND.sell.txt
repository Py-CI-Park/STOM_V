# 추세 추종용 청산: 넓은 트레일링 + 이평/체결강도 이탈 + 고가 미갱신
매도 = False

if 등락율 > 29.5:
    매도 = True
elif 시분초 >= 92800:
    매도 = True
elif 수익률 <= -1.2:
    매도 = True
elif 최고수익률 >= 1.5 and 수익률 <= 최고수익률 - 0.7:
    매도 = True
elif 수익률 >= 3.0:
    매도 = True
elif 데이터길이 >= 21 and 수익률 < 0 and 현재가 < 이동평균(20, 1) and 체결강도 < 체결강도평균(20, 1):
    매도 = True
elif 데이터길이 >= 11 and 최고수익률 >= 1.0 and 고가미갱신지속틱수() >= 20 and 체결강도 < 체결강도평균(10, 1):
    매도 = True
elif 보유시간 >= 300:
    매도 = True

if 매도:
    self.Sell()
